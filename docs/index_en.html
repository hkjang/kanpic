Built for controlled environments

The spreadsheet experience, adapted to private infrastructure.

kanpic focuses on deployability, data ownership, and governed access while keeping everyday import, editing, and export workflows familiar.

AIR

Offline-ready packaging

Release bundles include the application image, web assets, CA certificates, time-zone data, and database migrations for disconnected deployment.

GRID

Canvas spreadsheet editor

A React Canvas interface handles workbook editing in the browser while the Go backend remains authoritative for persisted data.

I/O

Practical file exchange

Preview CSV, TSV, or XLSX before atomic import. Export the current workbook to XLSX or CSV through the product interfaces.

OIDC

Keycloak sign-in

Connect public or confidential Keycloak clients with Authorization Code Flow and PKCE, configured from the administration console.

KEY

Scoped API keys

Personal keys are shown once, stored as SHA-256 hashes, and checked for both mcp.use and each tool's required scope.

CFG

Versioned administration

Manage service settings, validate connections, inspect logs, review API keys, and restore earlier configuration versions from /admin.

Simple deployment model

Fewer moving parts inside the network boundary.

Quick start

Bring up a protected local instance.

Set the initial administrator credentials together, start the Compose stack, then open the browser. Additional identity and service configuration is managed from the admin console.

FAQ

What to know before evaluation.

The essentials for infrastructure and security teams.

Does kanpic require internet access at runtime?

No. The release image is designed to include the web assets, certificate bundle, time-zone data, and migrations needed for disconnected operation. Your deployment still needs access to its configured PostgreSQL service and any internal identity provider you choose.

Does it require Redis or a message broker?

The current architecture uses PostgreSQL as the server-authoritative store and does not require Redis at runtime. Review the release documentation for the exact version you plan to deploy.

How is MCP access controlled?

The Streamable HTTP endpoint requires an authorized identity or API key. Calls are checked for the general mcp.use permission as well as the scope required by the specific tool.

What formats can I exchange?

kanpic can preview and import CSV, TSV, and XLSX. The active workbook can be exported to XLSX or CSV through the supported product interfaces.
