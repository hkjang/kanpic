# kanpic 사용자 가이드 (User Guide)

kanpic은 온프레미스 및 폐쇄망 환경을 우선 지원하는 웹 기반 AI 스프레드시트 및 데이터 협업 플랫폼입니다. 본 가이드는 kanpic의 주요 기능과 사용법을 상세히 안내합니다.

---

## 1. 시작하기

### 1.1 로그인 및 대시보드
- **로그인**: 관리자가 설정한 ID/비밀번호 또는 기관 Keycloak OIDC 간편 통합 로그인을 사용하여 접속합니다.
- **홈 대시보드 (`/`)**:
  - **새 워크북 생성**: `빈 워크북 생성` 버튼을 클릭하여 새 스프레드시트를 시작합니다.
  - **파일 가져오기**: CSV, TSV, XLSX 파일을 업로드하고 미리보기 후 원자적으로 가져옵니다.
  - **워크북 목록**: 최근 편집한 워크북, 즐겨찾기(⭐) 워크북 목록을 조회할 수 있습니다.

---

## 2. 워크북 편집기 (Canvas Editor)

kanpic은 Canvas 기반의 초고속 그리드 엔진을 사용하여 대용량 셀 데이터도 부드럽게 렌더링하고 편집합니다.

### 2.1 셀 편집 및 수식 (Formula)
- **셀 선택 및 편집**: 원하는 셀을 클릭하거나 방향키로 이동한 후 `Enter` 또는 문자 입력으로 데이터 편집을 시작합니다.
- **수식 입력**: `=` 기호로 시작하여 수식을 입력할 수 있습니다.
  - 예시: `=SUM(A1:A10)`, `=AVERAGE(B1:B20)`, `=CONCAT(A1, " ", B1)`
  - 수식 입력 시 관련 셀이 자동으로 상호 참조되며 재계산됩니다.

### 2.2 셀 서식 및 스타일링
- **툴바 옵션**:
  - **글꼴 & 크기**: Font Family 및 Size 조정
  - **스타일**: 굵게(`Bold`), 이탈릭(`Italics`), 밑줄(`Underline`)
  - **정렬**: 좌측 정렬, 중앙 정렬, 우측 정렬
  - **색상**: 글자 색상 및 셀 배경색 지정

### 2.3 시트(Sheet) 관리
- 하단 시트 탭 영역에서 `+` 버튼으로 새 시트를 추가할 수 있습니다.
- 시트 이름 변경, 색상 태그 지정, 시트 복사 및 삭제 기능을 지원합니다.

## 3. 고급 데이터 관리 기능

### 3.1 데이터 유효성 검사 (Data Validation)
셀에 입력 가능한 데이터 형식을 제한하고, 잘못된 입력 시 경고를 표시하거나 입력을 차단합니다.

- **유효성 규칙 설정**:
  1. 셀 또는 범위를 선택 후 상단 메뉴의 **데이터 유효성 검사** 아이콘을 클릭합니다.
  2. **규칙 유형** 선택:
     - **목록 (List)**: 지정한 항목 목록(예: `승인, 대기, 거절`) 중 선택
     - **숫자 (Number)**: 최소/최대값 범위 조건 지정 (예: 1~100 사이)
     - **날짜 (Date)**: 유효한 날짜 범위 검증
     - **사용자 지정 수식 (Custom Formula)**: 특정 수식 조건 만족 여부 검증
  3. **표시 스타일**: 드롭다운 화살표, 칩(Chip) 스타일 중 선택
  4. **입력 거부 (Reject Input)**: 조건 미만족 시 입력 자체를 차단할지 경고 뱃지만 표시할지 설정합니다.

### 3.2 필터 뷰 (Filter Views)
다른 사용자에게 영향을 주지 않고 나만의 필터링 조건을 적용하여 데이터를 탐색합니다.

- **필터 생성**: 툴바의 **필터** 아이콘을 클릭하여 조건 추가
- **조건 설정**: 특정 열의 값 일치, 포함/미포함, 색상 기준 필터링
- 비파괴 방식(Non-destructive)으로 행을 숨기므로 원본 데이터는 안전하게 유지됩니다.

### 3.3 버전 이력 및 복원 (Version History)
- **버전 저장**: 주요 작업 시점마다 버전을 저장하고 이름을 부여할 수 있습니다.
- **시점 복원**: 우측 **버전 패널**에서 과거 변경 이력을 확인하고 원하는 버전으로 복원(Rollback)할 수 있습니다.

### 3.4 내보내기 (Export)
- **XLSX / CSV 내보내기**: 상단 내보내기 메뉴를 통해 현재 작업 중인 워크북을 XLSX 또는 CSV 포맷으로 다운로드할 수 있습니다.

---

## 4. 개인 설정 및 API 키 (`/preferences`)

- **개인화 설정**: 다크 모드 / 라이트 모드 테마 변경
- **개인 API 키 발급**:
  - 외부 파이썬 스크립트나 자동화 도구에서 kanpic API를 호출할 수 있는 API 키를 발급/회전/폐기할 수 있습니다.
  - API 키 원문은 발급 직후 1회만 표시되므로 안전한 곳에 보관해야 합니다.
