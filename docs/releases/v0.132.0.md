## 릴리즈 요약

v0.132.0은 **워크북 목록 화면에서 빠른 이동이 열리지 않던 것** 과 **프레젠테이션 디자인을 고르기 어렵던 것** 을 고칩니다.

## 목록 화면에서 Ctrl/⌘+K 가 먹통이었다

빠른 이동 창은 **편집기에만** 붙어 있었습니다. 워크북 목록에서 `Ctrl/⌘ + K`를 누르면 아무 일도 일어나지 않아, 단축키가 고장 난 것처럼 보였습니다.

목록 화면에도 붙였습니다. 그곳에서 찾는 것은 이렇습니다.

| 무엇 | 예 |
| --- | --- |
| 워크북 | 이름으로 찾아 바로 열기 |
| 명령 | 새 워크북, 파일 가져오기, 템플릿 갤러리 |
| 목록 | 최근 · 내 소유 · 나와 공유됨 · 즐겨찾기 · 휴지통 |

시트와 셀 주소는 워크북을 연 뒤에야 뜻이 생기므로 편집기에서만 나옵니다.

받아 온 페이지에 **없는** 워크북도 이름으로 찾아 닿습니다.

## 쉰 가지가 한 줄로 늘어서 있었다

디자인 선택기는 **이미 있었습니다.** 다만 쉰 가지가 한 줄로 늘어서 있었습니다. 그러면 고르기가 아니라 훑기가 되고, 결국 아무도 바꾸지 않습니다.

바꾸지 않으면 **기본 디자인** 으로 남는데, 이는 "아무것도 보내지 않는다"는 뜻입니다. 서비스가 정한 한 가지 모습으로만 만들어지니, 여러 개를 만들수록 다 같아 보입니다.

```
Ptium Plum Wash        색 계열 열 묶음 × 배치 다섯 가지
Ptium Forest Orbit     →  색으로 묶어 목록을 접었습니다
Ptium Slate Classic
```

한 번 고른 디자인은 **다음에 만들 때도 그대로 남습니다.** 고르는 순간 기억합니다 — 만들 때만 기억하면, 골라 두고 닫았다가 다시 연 사람에게는 아무것도 남지 않습니다.

## 고칠 것이 없던 곳

확인했지만 멀쩡했던 것도 적어 둡니다.

- 고른 템플릿은 **이미 서비스까지 제대로 전달** 되고 있었습니다.
- **다시 만들기** 는 같은 덱을 고쳐 쓰므로 디자인이 그대로 남습니다.
