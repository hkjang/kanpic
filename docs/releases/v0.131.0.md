## 릴리즈 요약

v0.131.0은 **만든 프레젠테이션 목록에 닿기 어렵던 것** 과 **"편집기에서 열기" 가 편집 화면으로 가지 않던 것** 을 고칩니다.

## 아이콘이 없어 없는 기능처럼 보였다

만든 프레젠테이션 목록은 오른쪽 패널에 있는데 도구 모음에 아이콘이 없었습니다. 차트·피벗·자동화는 모두 아이콘이 있으므로, **이것만 없으면** 데이터 메뉴를 두 번 들어가야 한다는 것을 알기 전까지는 없는 기능처럼 보입니다.

네 곳에서 열 수 있게 했습니다.

| 어디 | 무엇 |
| --- | --- |
| 도구 모음 | 프레젠테이션 아이콘 (차트·피벗·자동화 옆). 한 번 더 누르면 닫힙니다 |
| 도구 메뉴 | 프레젠테이션 목록 |
| 추가 도구 `⋯` | 프레젠테이션 목록 |
| `Ctrl/⌘ + K` | "프레젠테이션"으로 찾기 |

프레젠테이션 설정이 꺼져 있으면 **넷 다 나오지 않습니다.** 눌러도 아무 일도 일어나지 않는 단추는 없는 것만 못합니다.

## 편집 링크가 보기 화면으로 갔다

목록의 **편집기에서 열기** 가 `/presentations/{id}`로만 가고 있었습니다. 고치려고 눌렀는데 **고칠 수 없는 화면** 이 뜹니다. 화면은 떴으니 링크가 잘못됐다는 것도 알기 어렵습니다.

```
고치기 전   …/presentations/{id}
지금        …/presentations/{id}/editor
```

아이디를 주소에 안전하게 넣도록 함께 고쳤습니다.

## 검증 결과

- 편집 주소 시험은 고치기 전 코드에서 걸립니다.
- 아이콘과 메뉴 항목이 실제로 보이고 눌리는지 e2e로 봅니다. **설정이 꺼진 경우** 도 함께 봅니다.
- e2e 190개를 통째로 돌렸습니다.
- Go 시험 전체와 웹 시험 379개가 통과합니다.
