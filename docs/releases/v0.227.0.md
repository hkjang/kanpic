# v0.227.0

## 그림이 XLSX 를 따라간다

지난 판(v0.226.0)에서 "XLSX 로 내보내고 가져올 때 그림은 아직 따라가지 않는다" 고
적었습니다. 이제 따라갑니다. 차트가 이미 가던 길입니다.

**내보내기.** 시트에 떠 있는 그림을 파일에 담습니다. 엑셀에는 픽셀 좌표가 없으므로
자리는 차트처럼 셀 닻(열 108px, 행 27px 기준)에 남는 픽셀을 오프셋으로 근사하고,
크기는 원본 대비 배율로 **정확히** 남깁니다. 담지 못한 그림이 있으면 응답 머리글
`X-Kanpic-Skipped-Images` 에 수를 적습니다 — 차트의 `X-Kanpic-Skipped-Charts` 와
같은 자리입니다.

**가져오기.** 파일의 그림을 셀 닻과 배율에서 다시 픽셀 자리와 크기로 되돌립니다.
바이트는 올릴 때와 같은 검사를 거칩니다 — 종류를 바이트에서 읽고, 그림이 아니면
버립니다. 파일에 든 SVG 는 여기서도 들어오지 못합니다.

## 확인

- `internal/importexport/image_roundtrip_test.go` — 메모리 저장소에 그림을 넣고 내보낸 뒤 다시 들여와, 바이트가 한 자도 바뀌지 않고 자리(250, 70, 240×120)가 그대로 돌아오는지
- `web/e2e/image-xlsx.spec.ts` — 실제 서버로 올리고 → 내보내고 → 들여와, 새 워크북에 같은 그림이 같은 바이트로 있는지
