## 릴리즈 요약

v0.38.0은 **셀 메모**를 추가합니다. 셀에 마우스를 올렸을 때 보이는 짧은 설명으로, 답글이 오가는 댓글과 달리 "이 숫자는 어디서 왔는지"를 셀 옆에 적어 두는 용도입니다.

마이그레이션은 없습니다. 메모는 셀과 같은 자리에 저장되므로 기존 데이터베이스도 그대로 동작합니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 셀 메모

- 셀을 오른쪽 클릭하고 **삽입 › 메모 삽입…** 을 고릅니다. 최대 1,000자까지 쓸 수 있고 `Ctrl+Enter` 로 저장합니다.
- 메모가 있는 셀은 오른쪽 위 모서리에 작은 표시가 생기고, 마우스를 올리면 내용이 나타납니다. 화면 낭독기에는 셀을 선택할 때 메모가 함께 읽힙니다.
- **댓글과 다릅니다.** 답글이 달리지 않고 댓글 패널에도 나타나지 않으며 알림 메일도 가지 않습니다.
- 메모는 값·수식·서식을 건드리지 않고 저장되며, 반대로 값을 고쳐도 메모는 남습니다. 행과 열을 넣고 지우면 셀과 함께 따라 움직입니다.
- 메모만 있고 값이 없는 셀도 유지되고, 메모를 지우면 그 셀은 다시 빈 셀이 됩니다.

```http
PATCH /api/v1/sheets/{sheetId}/ranges:note
{"range":"B2:B2","note":"협력사 확정 단가","base_version":12,"idempotency_key":"..."}
```

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. 메모가 값과 서식을 건드리지 않는지, 메모만 있는 셀이 살아남고 지우면 사라지는지, 행 삽입에 따라 함께 움직이는지 검사합니다.
- React/Vitest 35개 테스트 파일, 176개 테스트를 통과했습니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 91건을 통과했습니다. 실제 브라우저에서 메뉴로 메모를 달고, 마우스를 올렸을 때 나타나고 벗어나면 사라지며, 삭제한 뒤에도 값과 굵게 서식이 그대로인지 확인했습니다.
