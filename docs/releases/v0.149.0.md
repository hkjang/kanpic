## A4 세로 고정이었습니다

여백은 14mm, 방향은 세로로 박혀 있었습니다. 열이 많은 표는 자꾸 다음 장으로 넘어가는데, **가로로 놓거나 줄여 담을 방법이 없었습니다.**

**파일 › 페이지 설정…** 에서 고릅니다.

```
방향     세로 · 가로
여백     좁게(8mm) · 보통(14mm) · 넓게(22mm)
넓은 표  열을 다음 장으로 넘기기 · 한 장 너비에 맞추기
```

## 줄일 때는 zoom 을 씁니다

"한 장 너비에 맞추기" 는 열을 나누는 대신 표 전체를 줄입니다. 이때 `transform: scale()` 이 아니라 `zoom` 을 씁니다.

`zoom` 은 줄인 크기로 **다시 흘려 주므로** 장 나눔이 그대로 살아 있습니다. `transform` 은 그린 것을 자리만 옮기므로 둘째 장부터 내용이 어긋납니다.

맞추면 글자가 작아지므로, 열이 아주 많을 때는 가로 방향과 함께 쓰는 편이 좋습니다.

## 고른 것을 기억합니다

같은 표를 여러 번 찍는 일이 흔한데 매번 다시 고르게 하는 것은 일을 늘리는 것입니다. 이 브라우저에 기억해 두고, `Ctrl/⌘ + P` 는 기억해 둔 설정으로 바로 찍습니다.

## 이름을 "페이지 설정" 으로 지은 까닭

`인쇄` 로 시작하는 이름을 메뉴에 더하면 기존 e2e 시험 일곱 개가 쓰는 `/^인쇄(?!\s*영역)/` 에 **함께 걸립니다.** 예전에 인쇄 영역을 더하면서 같은 실수로 일곱 개를 깨뜨린 적이 있습니다.

그래서 표준 용어인 **페이지 설정** 을 골랐고, 그 아홉 개가 그대로 지나는지 실제로 확인했습니다.

## 검증 결과

- 가로가 세로보다 한 장에 더 담고, 여백을 좁히면 더 담는지 확인합니다.
- 종이 크기와 여백이 실제로 CSS 에 적히는지 확인합니다.
- 맞추면 표가 하나로 남고 `zoom` 이 붙는지, 표가 종이보다 좁으면 붙지 않는지 확인합니다.
- 브라우저에서 고른 것이 다음에 다시 열 때 남아 있는지 확인합니다.
- 기존 인쇄 시험 아홉 개가 그대로 지납니다.
