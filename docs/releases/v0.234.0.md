# v0.234.0

## 분수 서식이 분수로 그려진다

엑셀의 기본 표시 형식 12·13 번은 `# ?/?` 와 `# ??/??` 입니다. 값을 소수가
아니라 분수로 적으라는 뜻이라, 치수·배합비·시간 지분처럼 분수로 읽는 것이
자연스러운 자료에 붙어 XLSX 로 그냥 들어옵니다.

kanpic 은 자리 기호만 세고 빗금은 그냥 글자로 흘려 보냈습니다. 그래서 `0.5`
가 담긴 칸이 `1/2` 가 아니라 **`1/`** 로 보였습니다 — 값을 정수로 반올림한
뒤에 빗금만 남은 꼴입니다. `2.75` 는 `3/`, `0.3125` 는 `0/` 이었습니다. 값이
달라 보이는 것을 넘어 무엇이 잘못됐는지도 읽히지 않았습니다.

이제 빗금 양쪽에 자리 기호가 붙은 서식은 분수로 그립니다.

- 자리 기호 개수가 분모의 상한입니다. `?` 는 9, `??` 는 99, `???` 는 999 입니다.
  - `# ?/?` → `0.3125` 는 **1/3**, `# ??/??` 는 **5/16**, `# ???/???` 는
    `3.14159` 를 **3 16/113** 으로 적습니다.
  - 같은 만큼 어긋나면 분모가 작은 쪽입니다. `0.5` 는 `# ??/??` 에서도 **1/2** 입니다.
- 빈칸으로 가른 정수 자리가 있으면 대분수, 없으면 가분수입니다.
  - `# ?/?` → `2.75` 는 **2 3/4**, `#/#` → `5.25` 는 **21/4** 입니다.
- 분모를 숫자로 못 박으면 약분하지 않습니다. `?/8` → `0.5` 는 **4/8** 입니다.
- 분자가 분모까지 올라가면 정수 자리로 올립니다. `# ?/?` → `0.99` 는 **1** 입니다.
- `#` 은 0 인 정수 자리를 감추고 `0` 은 적습니다. `0 ?/?` → `0.5` 는 **0 1/2**,
  `#,##0 ?/?` → `1234.5` 는 **1,234 1/2** 입니다.
- 부호와 적어 둔 글자는 그대로 따라옵니다. `# ?/?" 개"` → `2.75` 는 **2 3/4 개**,
  `-2.75` 는 **-2 3/4** 입니다. 분수가 0 으로 내려앉으면 `-0` 이라고 적지 않습니다.

날짜 서식의 빗금은 자리 기호 사이에 있지 않으므로 분수로 읽지 않습니다.
`m/d/yyyy` 는 그대로 날짜입니다.
