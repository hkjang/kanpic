## 핵심 변경

- 원본 셀을 수정하지 않는 서버 권위 관리형 피벗 테이블을 추가했습니다.
- 행과 열 차원, 합계·평균·개수·최소·최대 값 집계, 다중 필터와 전체 합계를 지원합니다.
- 날짜 필드는 연도·분기·월·일로, 숫자는 지정 간격으로 그룹화할 수 있으며 값 목록을 이름 있는 사용자 그룹으로 묶을 수 있습니다.
- `=V1/V2` 형식으로 앞서 정의한 값 집계를 참조하는 계산 필드를 지원하고 계산 오류를 셀 오류 코드로 반환합니다.
- 집계 결과 셀에서 실제로 기여한 원본 행을 최대 500개씩 페이지 단위로 드릴다운할 수 있습니다.
- 자동 갱신은 조회 시 최신 서버 셀과 계산 결과를 사용하고, 수동 갱신은 명시적으로 갱신하기 전까지 PostgreSQL 캐시를 안정적으로 재사용합니다.

## 데이터 내구성과 버전 관리

- 피벗 정의는 `pivots` 테이블에 JSONB 구성, source/workbook version, revision, 생성·수정 작업자와 시각을 함께 저장합니다.
- 생성 요청에는 idempotency key가 필수이며 같은 사용자·워크북·키의 재전송은 중복 피벗을 만들지 않습니다.
- 수정과 삭제는 expected revision을 검사하고 정의 변경은 워크북 서버 버전을 증가시켜 공동 편집자에게 전파합니다.
- 피벗 정의는 워크북 스냅샷과 범위·전체 복원, 워크북 복제와 시트 복제에 포함됩니다. 파생 캐시는 복원·복제 후 최신 원본으로 다시 계산합니다.
- 행·열 삽입 또는 삭제 시 원본 A1 범위가 함께 이동하고 기존 수동 캐시는 무효화됩니다. 원본 범위 전체나 원본 시트가 삭제되면 정의를 `#REF!` 상태로 보존합니다.
- 워크북당 피벗 50개, 원본 100,000셀, 결과 20,000셀, 행·열 차원 합계 6개, 값 10개, 필터 10개, 계산 필드 5개 제한을 적용했습니다.

## 사용자 화면

- 편집기 오른쪽 아래에 차트와 분리된 **피벗** 진입 버튼과 현재 시트의 피벗 목록 패널을 추가했습니다.
- 피벗 설정 화면에서 원본 시트·범위, 머리글, 자동·수동 갱신, 행·열 그룹, 값 집계, 필터와 계산 필드를 한 번에 편집할 수 있습니다.
- 원본 첫 행을 읽어 필드 이름으로 표시하며 각 정의의 원본 범위, 갱신 방식과 revision을 목록에서 확인할 수 있습니다.
- 결과 화면은 행 그룹과 열 그룹을 접근 가능한 HTML 표로 표시하고 숫자를 지역 형식으로 포맷합니다.
- 결과 셀을 선택하면 별도 원본 행 표가 열리며 이전·다음 페이지로 탐색할 수 있습니다.
- 개인화 화면의 새 에이전트 키 기본 scope에 `pivot.*`를 추가했습니다.

## REST API 및 MCP

- REST: `GET|POST /api/v1/workbooks/{workbookId}/pivots`
- REST: `GET|PATCH|DELETE /api/v1/pivots/{pivotId}`
- REST: `GET /api/v1/pivots/{pivotId}/data`
- REST: `POST /api/v1/pivots/{pivotId}/refresh`
- REST: `GET /api/v1/pivots/{pivotId}/drilldown`
- MCP: `spreadsheet.pivot.list|get|data|drilldown`
- MCP: `spreadsheet.pivot.create|update|refresh|delete`
- 조회 작업은 `pivot.read`, 변경 작업은 `pivot.write` scope를 검사하며 API 키에는 MCP 호출 시 `mcp.use`도 필요합니다.
- REST와 MCP는 동일한 저장소, 유효성 검사, revision, idempotency, 갱신과 드릴다운 계약을 공유합니다.

## 검증

- 전체 Go 단위 테스트와 실제 PostgreSQL 5432 통합 테스트를 통과했습니다.
- 메모리·PostgreSQL 저장소에서 집계, 필터, 계산 필드, 날짜·숫자·사용자 그룹, 수동 캐시, 갱신과 드릴다운을 검증했습니다.
- 피벗의 멱등성, revision 충돌, 행·열 구조 변경, 워크북 스냅샷 복원, 워크북·시트 복제와 삭제된 원본의 `#REF!` 보존을 검증했습니다.
- REST와 MCP의 피벗 도구 8개, 입력 스키마와 `pivot.read`/`pivot.write` scope 계약을 검증했습니다.
- React/Vitest 53개 테스트와 TypeScript/Vite 프로덕션 빌드를 통과했습니다.
- Playwright 브라우저 E2E에서 피벗 생성, 집계 결과, 원본 행 드릴다운, REST 정의·결과 일치를 검증했습니다.
- 열 차원을 생략한 피벗도 빈 `labels` 배열을 반환하고 안전하게 렌더링하는 회귀 테스트를 추가했습니다.

## 업그레이드 참고

- 서버 시작 시 `009_pivots.sql`이 자동 적용되어 피벗 정의, 수동 계산 캐시와 조회용 인덱스를 생성합니다.
- 필수 런타임 환경 변수는 기존과 동일하게 `POSTGRES_DSN` 하나이며 Redis와 외부 인터넷은 필요하지 않습니다.
- 기존 API 키로 피벗 REST 또는 MCP 도구를 사용하려면 개인화 화면에서 `pivot.read` 또는 `pivot.write` scope를 추가하거나 키를 회전해야 합니다.
- 피벗 수동 캐시는 데이터베이스에 저장되므로 서버 재시작 후에도 유지되며, 정의·구조·복원 변경 시 안전하게 폐기됩니다.
- 오프라인 번들은 `kanpic-v0.11.0.tar.gz`와 SHA-256 파일로 제공되며 Docker에 로드한 뒤 기존 PostgreSQL 5432 인스턴스에 연결하면 됩니다.
