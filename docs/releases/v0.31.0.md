## 릴리즈 요약

v0.31.0은 **수식**에 집중했습니다. 함수는 55개에서 **205개**로 늘어 재무·통계·조회·배열·정규식까지 다루고, `=SUM(A:A)` 같은 열 전체 참조가 새로 동작합니다. 셀에서 함수 이름을 치면 후보와 인수 안내가 따라오고, 행과 열을 넣고 지울 때 참조가 깨지지 않는 규칙을 실제 브라우저 시나리오로 검증했습니다. 템플릿 갤러리에는 함수를 배우면서 그대로 복사해 쓸 수 있는 **수식·함수** 분류 9종이 추가됐습니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 행·열을 바꿔도 수식이 깨지지 않습니다

- 범위 안쪽에 행을 넣으면 범위가 늘어나고(`=SUM(A1:A5)` → `=SUM(A1:A6)`), 위쪽에 넣으면 통째로 밀려 내려갑니다. `$` 고정 표시는 유지됩니다.
- 참조하던 셀이 삭제된 자리만 `#REF!`가 되므로 어디를 고쳐야 하는지 바로 보입니다.
- 다른 시트를 가리키는 참조는 그 시트가 바뀔 때만 움직입니다. 병합 범위, 조건부 서식, 데이터 유효성, 필터 뷰, 차트 원본, 이름 지정 범위, 댓글 위치도 같은 규칙으로 함께 이동합니다.

### 열 전체 참조

- `A:A`, `A:C`, `2:5`, 그리고 머리글을 뺀 `A2:A` 형태를 모두 지원합니다.
- 계산은 시트에 실제로 값이 있는 범위까지만 이뤄지므로 빈 100만 행을 훑지 않습니다. 표 아래에 행을 추가하면 별도 수정 없이 합계에 포함되고, 마지막 행을 지워도 합계가 즉시 따라옵니다.
- 열을 삽입하면 `A:A`도 `B:B`로 함께 이동하고, 행 삽입으로는 움직이지 않습니다.

- 재무 함수는 Excel·Google 스프레드시트와 같은 부호 규칙을 씁니다. 나가는 돈은 음수이므로 대출의 `PMT`는 음수로 나옵니다.
- `ROW()`와 `COLUMN()`은 수식이 놓인 셀을 압니다. `OFFSET`과 `INDIRECT`는 인수가 고정 값이면 일반 참조와 똑같이 의존성을 등록하고, 계산식이면 워크북이 바뀔 때마다 다시 계산합니다. `TODAY`·`NOW`·`RAND` 계열도 같은 규칙으로 갱신됩니다.
- 날짜는 텍스트로 저장되므로 `=MIN(날짜 범위)`와 `=MAX(날짜 범위)`가 가장 이르거나 늦은 날짜를 돌려주도록 했습니다.
- `UNIQUE`·`SEQUENCE` 같은 배열 함수의 결과가 펼쳐질 자리에 값이 있으면 `#SPILL!`이 표시됩니다.

## 함수 자동완성

- 셀에서 `=`를 치고 이름을 몇 글자 입력하면 후보 목록이 뜹니다. `↑`·`↓`로 옮기고 `Tab`이나 `Enter`로 넣으면 괄호까지 열립니다.
- 괄호 안에서는 지금 입력 중인 인수가 강조된 사용법과 한 줄 설명이 따라옵니다. `Esc`는 제안만 닫고 편집은 이어집니다.
- 후보는 서버 카탈로그에서 오므로 목록에 보이는 함수는 반드시 계산됩니다.

## 수식·함수 템플릿 9종

조회 함수 모음, 조건부 집계 모음, 텍스트 정리 도구, 날짜 계산 도구, 재무 함수 계산기, 통계 분석 기초, 동적 배열 수식, 자동 확장 범위, 논리·오류 처리를 추가해 템플릿은 71종이 되었습니다. 예시 데이터가 들어 있어 열자마자 계산되어 있고, 옆 칸에 그 수식이 무엇을 하는지 적혀 있습니다. 재무 함수 계산기는 원금·이율·기간만 바꾸면 회차별 원금과 이자가 다시 계산되고, 자동 확장 범위는 `A:A` 참조로 행을 추가해도 집계가 따라오는 구성을 보여 줍니다.
