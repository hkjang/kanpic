## 릴리즈 요약

v0.39.0은 **체크박스**를 추가합니다. 할 일 목록이나 확인 열처럼 켜고 끄는 값에 쓰는 셀 안의 상자로, 클릭이나 스페이스바 한 번이면 바뀝니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 체크박스

- 데이터 검증의 규칙 유형에 **체크박스** 가 생겼습니다. 범위를 고르고 유형만 바꾸면 그 범위의 셀이 상자로 그려집니다.
- 상자를 **클릭** 하거나 셀을 고른 뒤 **스페이스바 또는 Enter** 로 켜고 끕니다. 편집기가 열리지 않으므로 타이핑 없이 열을 훑어 내려갈 수 있습니다.
- 저장되는 값은 기본이 `TRUE`/`FALSE`라 `=COUNTIF(B2:B20,TRUE)` 로 세고 `=IF(B2,"완료","진행 중")` 처럼 조건에 그대로 씁니다.
- **체크했을 때 / 해제했을 때 저장할 값** 을 바꾸면 `예`/`아니오` 같은 자체 값도 쓸 수 있습니다. 값은 반드시 두 개여야 하고 서로 달라야 하며, 그 외의 값이 셀에 들어오면 검증에서 걸립니다.
- 체크박스는 값이 두 개인 목록이므로 드롭다운을 그리지 않고, 기존 목록 검증의 색 칩 설정과 섞이지 않습니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. 기본값 `TRUE`/`FALSE` 생성, 자체 값 쌍, 값이 하나·셋이거나 서로 같을 때의 거부, 두 값만 통과시키는 검사를 확인합니다.
- React/Vitest 35개 테스트 파일, 180개 테스트를 통과했습니다. 체크 상태 판정과 다음 상태 계산을 단위 테스트로 검사합니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 93건을 통과했습니다. 실제 브라우저에서 상자를 눌러 켜고 끄고, 스페이스바로 바꾸고, 체크박스가 아닌 셀은 평소대로 편집기가 열리는지 확인했습니다.
