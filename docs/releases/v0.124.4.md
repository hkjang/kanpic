## 릴리즈 요약

v0.124.4는 **날짜 서식이 양쪽 모두 깨져 있던 것** 을 고칩니다. 특히 `yyyy년 m월 d일` 같은 한국어 날짜 서식이 격자에서 `2024년 m월 d일`로 그려지고 있었습니다.

## m은 앞뒤를 봐야 뜻이 정해진다

표 서식에서 `m`은 자리에 따라 **달** 이기도 하고 **분** 이기도 합니다.

```
mm/dd/yyyy   달
hh:mm        분   — 시 뒤에 오면 분
h:mm:ss      분   — 초 앞에 와도 분
```

양쪽 다 이것을 가려내지 못하고 있었는데, 못 하는 모양이 서로 달랐습니다.

## 서버: 달이 시각 자리에 들어갔다

서버는 서식을 Go의 시각 표기로 **바꿔치기** 하고 있었습니다. `mm`을 `01`로 먼저 바꾸고 `hh`를 `15`로 바꾸니, `"hh:mm"`이 `"15:01"` — 시와 **달** 이 되었습니다.

```
=TEXT(0.5,"hh:mm")     12:12      12:00 이어야 합니다
=TEXT(0.5,"h:mm:ss")   1          12:00:00 이어야 합니다
```

## 격자: 앞 토막만 그렸다

격자는 서식을 공백으로 잘라 "날짜 한 토막"과 "시각 한 토막"만 그렸습니다. 그래서 토막이 셋인 서식은 앞 토막만 그려졌습니다.

```
"yyyy년 m월 d일"  →  2024년 m월 d일
"dddd"            →  1515
"mmmm"            →  45306
```

한국어 날짜 서식이 그대로 깨져 있었습니다. 요일과 달 이름만 적은 서식도 그리지 못했습니다.

## 양쪽을 같은 방식으로

양쪽 모두 서식 기호를 **하나씩 읽어 그대로 적도록** 고쳤습니다. 같은 규칙을 같은 차례로 봅니다.

```
=TEXT(45306,"yyyy년 m월 d일")   2024년 1월 15일
=TEXT(45306,"dddd")             Monday
=TEXT(0.5,"h:mm:ss")            12:00:00
=TEXT(45306.75,"h:mm am/pm")    6:00 PM
```

`m` 하나만으로는 날짜 서식으로 보지 않습니다. `"0.0 m"`처럼 단위로 적은 것을 달로 읽으면 안 되기 때문입니다. `mmm`과 `mmmm`은 달 이름이므로 봅니다.

## 검증 결과

- 열여덟 가지 서식에서 격자와 `TEXT`가 **글자 하나까지 같은 답** 을 냅니다.
- 고치기 전 서버에서 열 가지, 격자에서 한국어 날짜 서식이 걸립니다.
- 숫자 서식(`#,##0.00`, `0.0%`)은 그대로입니다.
- Go 시험 전체, 웹 시험 374개, e2e가 통과합니다.
