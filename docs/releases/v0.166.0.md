## 릴리즈 요약

v0.166.0은 어제 넣은 표 색이 **나가기만 하고 들어오지 않던 것** 을 고칩니다.

## 초록으로 내보낸 표가 파랑으로 돌아왔습니다

색을 엑셀의 표 서식으로 내보내는 자리는 있었는데, 가져오는 쪽이 그것을 읽지 않았습니다. 사람은 자기가 고른 것이 사라진 줄 압니다.

## 두 방향을 한 표에서 뽑습니다

```
blue   ↔ TableStyleMedium2
green  ↔ TableStyleMedium4
orange ↔ TableStyleMedium3
red    ↔ TableStyleMedium10
```

따로 적으면 한쪽만 고쳤을 때 조용히 어긋납니다 — **그 어긋남이 바로 이번 결함입니다.** 이제 네 색이 모두 두 방향을 오가는지 시험이 지킵니다.

엑셀에서 만든 표는 kanpic 이 모르는 서식을 씁니다. 아무 색이나 골라 주는 것보다 기본색으로 그리는 편이 덜 놀라우므로 비워 둡니다.

## 검증 결과

- 초록으로 내보내 초록으로 돌아오는지, 모르는 서식은 비워 두는지, 네 색이 모두 두 방향을 오가는지 확인합니다.
- Go 시험 전체와 통합 시험 전체가 통과합니다.
