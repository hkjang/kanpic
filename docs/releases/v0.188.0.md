## 릴리즈 요약

v0.188.0은 **엑셀에서 온 표시 형식** 을 제대로 읽습니다. 원화 장부가 달러로 보이던 것을 고칩니다.

## 자리 기호만 적혀 있지 않습니다

엑셀에서 받은 파일의 표시 형식에는 나라 코드, 통화 기호, 색 이름, 따옴표로 묶은 글자가 함께 들어 있습니다. 두 곳 다 그것을 읽을 줄 몰랐습니다.

| 서식 | `=TEXT` 가 내던 것 | 격자가 그리던 것 | 이제 |
| --- | --- | --- | --- |
| `[$-409]#,##0` | `[$-45` | `$05` | `5` |
| `[$₩-412]#,##0` | `[$₩-412]5` | `$5` | `₩5` |
| `"₩"#,##0` | `"₩"5` | `₩5` | `₩5` |
| `#,##0"원"` | `5"원"` | `5` | `5원` |
| `#,##0 ;[red](#,##0)` | `[red](5)` | `(5)` | `(5)` |

`=TEXT` 는 **서식 조각을 값인 것처럼 적어 냈습니다.** 격자는 나라 코드 `409` 의 `0` 을 자릿수로 세어 5를 `05` 로 그렸고, 문자열에서 **처음 만난 기호** 를 집어 원화 파일을 달러로 그렸습니다. 원화 장부가 달러로 보이는 것은 값을 잘못 적는 것입니다.

## 두 곳을 같은 규칙으로 고칩니다

대괄호 안은 `[$기호-나라코드]` 에서 기호만 꺼내고, 따옴표 안은 그대로 적고, `_` 와 `*` 는 자리를 다루는 기호이므로 그리지 않습니다.

**빼기 부호는 기호 앞에 옵니다.** 엑셀은 `-₩5` 로 적지 `₩-5` 로 적지 않습니다. 붙잡아 두던 값 아홉 개를 고쳤습니다.

자리 기호가 하나도 없는 구역은 수를 적는 서식이 아닙니다. 날짜 서식에 날짜가 될 수 없는 수가 들어오면 여기까지 흘러오는데, 그때 `y` 나 `m` 을 글자로 적으면 `-yyyy-mm-dd1` 이 됩니다.

## 시험이 왜 못 잡았는가

`testdata/cell-formats.json` 은 격자와 `=TEXT` 를 함께 붙잡는 목록입니다. 840줄이 있었는데 **대괄호도 따옴표도 한 줄이 없었습니다.** 둘 다 틀린 채로 서로 맞으니 붙잡히지 않았습니다. 실제로 오는 서식 말을 스물두 줄 더했습니다.

## 덤

이제 따옴표로 묶은 글자를 그리므로, **텍스트로 저장된 숫자** 가 `£` 와 `"원"` 을 놓아줄 이유도 없습니다. 함께 표시 형식으로 옮깁니다.
