## 릴리즈 요약

v0.19.0은 편집기의 조작 계층을 Google Sheets 수준으로 끌어올립니다. **셀·행 머리글·열 머리글·모서리 컨텍스트 메뉴**, **머리글 드래그 크기 조절과 자동 맞춤**, **동작하는 워크북 메뉴 막대**, **확장된 단축키**, **옵션 기반 검색과 찾기·바꾸기**를 추가했습니다.

바꾸기는 서버가 미리보기로 대상 셀 수를 계산한 뒤 시트별 하나의 원자적 작업으로 반영되므로 기존 실행 취소, 충돌 감지, 수식 재계산, 워크북 버전과 협업 동기화 계약을 그대로 사용합니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나이며 새 마이그레이션은 없습니다.

## 핵심 변경

- 그리드에서 마우스 오른쪽 버튼 또는 `Shift + F10`으로 위치별 컨텍스트 메뉴를 엽니다. 셀 메뉴는 클립보드, 행·열 삽입·삭제, 내용·서식 지우기, 셀 병합, 정렬·필터·검증·조건부 서식·이름 범위, 차트·피벗·댓글 만들기, 선택 범위 링크 복사를 제공합니다.
- 열 머리글 메뉴는 좌우 삽입, 삭제, 너비 자동 맞춤·지정, 숨기기와 모두 표시, 해당 열까지 고정, 이 열 기준 오름차순·내림차순 정렬과 필터 보기를 제공합니다. 행 머리글 메뉴는 같은 구성을 행 기준으로 제공합니다.
- 머리글 클릭·드래그·`Shift + 클릭`으로 행과 열 전체를 선택하고 왼쪽 위 모서리로 시트 전체를 선택합니다. 선택된 머리글은 Canvas에서 강조 표시됩니다.
- 머리글 경계 드래그로 행 높이와 열 너비를 실시간 안내선과 픽셀 값을 보며 조절하고, 더블클릭으로 셀 내용에 맞춰 자동 맞춤합니다. 여러 행·열을 선택하면 삽입·삭제·숨기기·크기 조절이 선택 개수만큼 한 번에 적용됩니다.
- 상단 메뉴 막대의 파일·수정·보기·삽입·서식·데이터·도구·도움말이 실제 명령으로 채워졌습니다. 방향키 이동, 서브메뉴, 단축키 힌트와 켜짐·꺼짐 상태 표시를 지원합니다.
- 도구 모음의 남아 있던 자리 표시 버튼을 선택 범위 링크 복사와 추가 도구 메뉴로 채우고, 셀 병합 버튼을 주변과 동일한 아이콘 표현으로 교체했습니다.
- 값 대신 저장된 수식을 표시하는 수식 보기를 추가했습니다.

## 검색과 찾기·바꾸기

- 검색에 대소문자 구분, 셀 전체 일치, 정규식, 수식 제외와 현재 시트 범위 옵션을 추가했습니다. 기본값은 기존과 동일한 워크북 전체·대소문자 무시·값과 수식 검색입니다.
- `Ctrl/⌘ + H`는 바꾸기 입력이 열린 상태로 검색 창을 엽니다. **바꾸기**는 선택한 결과 한 셀만, **모두 바꾸기**는 조건에 맞는 모든 셀을 바꿉니다.
- 바꾸기는 항상 서버 미리보기로 변경 대상 셀 수를 먼저 계산하고 사용자 확인을 받은 뒤 실행합니다.
- 수식 셀은 값이 아닌 수식 문자열을 바꾸고 서버가 다시 계산합니다. 배열 수식 결과 셀과 변경이 없는 셀은 건너뛴 수로 보고합니다.
- 숫자와 참·거짓 셀은 바꾼 결과가 다시 같은 형식으로 해석되면 원래 형식을 유지합니다. 대소문자를 구분하지 않는 바꾸기는 일치하지 않은 나머지 텍스트의 원문 대소문자를 보존합니다.
- 한 번에 5,000셀을 넘는 바꾸기는 부분 반영 없이 거부하고 범위를 좁히도록 안내합니다. 정규식은 바꿀 내용에서 `$1` 형태의 그룹 참조를 지원합니다.
- 셀 서식은 바꾸기에서 보존됩니다.

## 단축키

- `Ctrl/⌘ + H` 찾기 및 바꾸기, `Ctrl/⌘ + \`` 수식 보기, `Ctrl/⌘ + \` 서식 지우기를 추가했습니다.
- `Alt + =` 자동 합계는 활성 셀 위쪽 또는 왼쪽의 연속된 숫자 범위를 계산해 `=SUM()` 수식을 편집 상태로 제안합니다.
- `Ctrl/⌘ + ;`와 `Ctrl/⌘ + Shift + ;`로 오늘 날짜와 현재 시간을 입력합니다.
- `Ctrl/⌘ + Alt + =`와 `Ctrl/⌘ + Alt + -`로 선택한 행·열을 삽입·삭제합니다. 행·열 전체 선택이 아니면 행과 열 관리 창을 엽니다.
- `Ctrl/⌘ + Alt + 9`·`0`으로 선택 행·열을 숨기고 `Ctrl/⌘ + Shift + 9`·`0`으로 모두 표시합니다.
- `PageUp`·`PageDown`과 `Alt` 조합으로 한 화면씩 이동하고 `Shift`로 범위를 확장합니다. `Ctrl/⌘ + PageUp`·`PageDown`은 시트를 전환합니다.
- `Ctrl/⌘ + Shift + A`는 활성 셀을 포함한 연속 데이터 영역을 선택하고, `Home`과 `End`는 행의 처음과 데이터 끝으로 이동합니다.
- `Ctrl/⌘ + /` 단축키 목록에 새 항목과 머리글 조작 안내를 추가했습니다.

## 수정된 문제

- 이름 상자에 범위를 입력하는 동안 직전 셀 입력의 저장이 완료되면 입력 중인 텍스트가 선택 주소로 덮어써지던 문제를 수정했습니다. 이제 이름 상자에 포커스가 있는 동안에는 선택 주소를 반영하지 않고, 이동에 성공하면 확정된 범위를 표시한 뒤 그리드로 포커스를 돌려줍니다.
- 셀 입력을 `Enter`로 확정한 직후 다른 범위를 선택하면 비동기 저장이 끝나며 커서가 되돌아가던 문제를 수정했습니다.
- `Ctrl/⌘ + Space`, `Shift + Space`와 `Ctrl/⌘ + A`가 활성 셀을 시트 끝으로 옮겨 화면이 최하단으로 스크롤되던 문제를 수정했습니다. 전체 행·열 선택의 활성 셀은 선택 시작 위치에 유지됩니다.
- 머리글 경계를 드래그 없이 클릭했을 때 불필요한 레이아웃 revision이 기록되던 문제를 수정했습니다.
- 연속된 레이아웃 변경(드래그 직후 자동 맞춤 등)이 서로의 revision을 앞질러 `409`로 실패하던 문제를 수정했습니다. 레이아웃 변경은 순차 실행됩니다.
- `Alt`가 포함된 단축키가 셀 입력으로 처리되어 페이지 단축키가 무시되던 문제를 수정했습니다.

## REST API

```http
GET /api/v1/workbooks/{workbookId}/search?q=서울&match_case=true&whole_cell=true&regex=false&skip_formulas=false&sheet_id=<uuid>&limit=50&offset=0

POST /api/v1/workbooks/{workbookId}/search:replace
Idempotency-Key: replace-20260803-001
Content-Type: application/json

{"query":"구 사명","replacement":"새 사명","match_case":false,"whole_cell":false,"use_regex":false,"skip_formulas":false,"preview":false}
```

- 검색 응답의 각 항목에 셀 서식과 배열 수식 원본 정보를 추가했습니다.
- 바꾸기 응답은 `matched_cells`, `planned_cells`, `replaced_cells`, `skipped_cells`, 최대 200건의 변경 미리보기 `items`와 시트별 작업 결과 `sheets`를 반환합니다.
- `preview=true`는 워크북을 변경하지 않으며 `idempotency_key`도 필요하지 않습니다. 실제 반영에는 `idempotency_key`가 필수입니다.
- `sheet_id`와 함께 `range`를 지정하면 해당 A1 범위 안의 셀만 바꿉니다. 편집기의 단일 셀 바꾸기가 이 계약을 사용합니다.
- 검색 endpoint의 필요 scope는 `workbook.read`, 바꾸기 endpoint는 `range.write`입니다.
- 잘못된 정규식, 256자를 넘는 검색어·바꿀 내용, `sheet_id` 없는 `range`와 5,000셀 초과 변경은 `400`으로 거부합니다.

## MCP 도구

- `spreadsheet.workbook.search` 입력 schema에 `sheet_id`, `match_case`, `whole_cell`, `use_regex`, `skip_formulas`를 추가했습니다.
- `range.write` scope를 사용하는 `spreadsheet.workbook.replace`를 추가했습니다. REST와 동일한 미리보기·멱등·범위 계약을 제공하고 반영 결과는 협업 채널로 전파됩니다.
