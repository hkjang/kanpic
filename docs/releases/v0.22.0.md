## 릴리즈 요약

v0.22.0은 사람과 이동, 그리고 관리자 통제를 다듬습니다. 화면 곳곳에 노출되던 **계정 ID를 표시 이름으로** 바꾸고, `Ctrl/⌘ + K` **빠른 이동**을 추가했으며, 모든 대화상자에 **공통 UX 규칙**(Esc 닫기, 포커스 트랩, 포커스 복원)을 적용했습니다.

관리자 콘솔에는 **개요 대시보드**와 **워크북 거버넌스**가 생겼고, 콘솔에서 **관리자 지정**이 가능해졌습니다. 조직 차원의 **공유 상한 정책**도 서버에서 강제합니다.

필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나이며 새 마이그레이션은 없습니다.

## 사람 이름 표시

- 댓글 작성자와 멘션, 멘션 알림, 편집 충돌 상대와 해결자, 버전 이력 작성자, 접속자 커서와 접속자 목록, 공유 대상과 소유자, 홈 화면의 소유자 표시가 모두 디렉터리의 표시 이름을 사용합니다.
- 표시 이름이 없으면 이메일 앞부분처럼 읽기 쉬운 형태로 줄여 보여 주고, 정확한 계정은 툴팁에 표시합니다. 본인의 댓글에는 `(나)`를 붙입니다.
- 공유 창의 사용자 입력에 디렉터리 자동 완성을 추가했습니다. 이름이나 이메일 일부만 입력해도 대상을 고를 수 있습니다.
- 새 endpoint `GET /api/v1/users:lookup?ids=…` 와 `?q=` 는 로그인한 사용자면 호출할 수 있고 사용자 ID, 표시 이름, 이메일만 반환합니다. 계정 상태나 관리자 메모는 노출하지 않습니다.

## 빠른 이동 (Ctrl/⌘ + K)

- 현재 워크북의 시트, 이름 범위, `C7`·`A1:D9` 같은 셀 주소, 접근 권한이 있는 다른 워크북, 그리고 25개 이상의 편집기 명령을 한 목록에서 검색해 실행합니다.
- 부분 일치와 순서 매칭을 함께 사용해 이름 일부만 입력해도 찾을 수 있고, 방향키·`Enter`·`Esc`로 조작합니다.
- `Ctrl/⌘ + K`는 이제 빠른 이동입니다. 워크북 값·수식 검색은 `Ctrl/⌘ + F`, 찾기 및 바꾸기는 `Ctrl/⌘ + H`를 계속 사용합니다.

## 대화상자 UX 통일

- 공유, 시트 관리, 다른 워크북으로 복사, 정렬, 필터, 서식, 레이아웃, 행과 열 관리, 데이터 검증, 조건부 서식, 이름 범위, 차트, 피벗, 피벗 결과, 단축키, 워크북 이름 변경, 빠른 이동까지 모든 대화상자가 같은 규칙을 따릅니다.
- `Esc` 또는 배경 클릭으로 닫고, `Tab` 포커스가 창 안에서 순환하며, 열리면 첫 입력 항목에 포커스가 가고, 닫으면 열었던 버튼으로 포커스가 돌아갑니다. 열려 있는 동안 뒤쪽 화면은 스크롤되지 않습니다.

## 관리자 개요와 워크북 거버넌스

- `/admin`이 **개요** 화면으로 시작합니다. 사용자·부서·워크북·공유 규모를 카드로 보여 주고, 점검이 필요한 항목(링크 공개, 조직 전체 공개, 소유자가 없거나 정지된 워크북, 대기 중 액세스 요청)에서 해당 목록으로 바로 이동합니다.
- **워크북 거버넌스** 화면은 관리자가 소유하지 않은 워크북까지 포함해 소유자, 소유자 상태, 링크 액세스, 공유 수, 시트 수, 최근 수정을 보여 주고 전체·링크 공개·조직 전체·소유자 문제·휴지통 필터를 제공합니다.
- 각 행에서 링크 공개 되돌리기, 소유권 이전, 휴지통 이동, 휴지통 항목 복원을 실행합니다.

## 관리자 지정과 공유 상한 정책

- 콘솔에서 **관리자로 지정**하면 `kanpic-admin` 역할(또는 `auth.oidc.admin_roles`의 첫 역할)을 부여합니다. 이제 kanpic 디렉터리 역할도 관리자 판정에 포함되므로, IdP 설정 없이도 콘솔에서 관리자를 늘릴 수 있습니다.
- 자신의 관리자 역할은 잠금 방지를 위해 스스로 회수할 수 없습니다.
- 새 시스템 설정 `sharing.max_link_access`와 `sharing.default_link_access`를 추가했습니다. 상한을 넘는 링크 액세스 요청은 REST와 MCP 모두에서 거부됩니다.

## 수정된 문제

- 댓글·알림·충돌·버전·접속자 목록에 원본 계정 ID가 그대로 나와 누가 작성했는지 알아보기 어려웠습니다.
- 콘솔에서 역할을 부여해도 관리자 판정에 반영되지 않아 관리자를 추가할 방법이 IdP 설정뿐이었습니다.
- 대화상자 대부분이 `Esc`로 닫히지 않고 포커스가 뒤 화면으로 빠져나갔습니다.
- 사용자 조회 응답이 비정상일 때 화면이 깨질 수 있던 방어 코드를 보강했습니다.

## 업그레이드 참고

- `Ctrl/⌘ + K`의 동작이 워크북 검색에서 빠른 이동으로 바뀌었습니다. 검색은 `Ctrl/⌘ + F`를 사용합니다.
- `/admin`의 기본 화면이 시스템 설정에서 개요로 바뀌었습니다. 설정은 `/admin?tab=settings`입니다.
- `sharing.max_link_access` 기본값은 `anyone`이라 기존 동작이 유지됩니다. 조직 정책에 맞게 좁히십시오.
