## 릴리즈 요약

v0.156.0은 **진짜 표** 를 넣습니다. 구글 시트가 잘 하는 것 가운데 kanpic에 가장 크게 비어 있던 자리입니다.

지금까지 kanpic의 "테이블 서식" 은 **색만 칠하는 것** 이었습니다. 표를 만들어도 수식에서 그것을 가리킬 방법이 없었습니다.

## 열 이름으로 가리킵니다

**삽입 › 표…** 에서 범위에 이름을 붙입니다.

```
=SUM(매출표[금액])       금액 열의 자료 줄
=SUM(매출표)            표 전체 (머리글 제외)
=COUNTA(매출표[#전체])   머리글까지
=COUNTA(매출표[#머리글])  머리글 줄만
```

**이것이 범위로 적는 것과 다른 점입니다.** `=SUM(C2:C50)` 은 위에 행을 하나 끼우면 사람이 옮겨 적어야 하고, **잊으면 조용히 틀린 값** 을 냅니다. 표는 행과 열을 따라 움직이므로 수식이 그대로 맞습니다. 조건부 서식, 보호 범위, 이름 범위가 옮겨지는 그 자리입니다.

머리글이 없는 표는 `열1`, `열2` 로 셉니다. 머리글에 같은 글자가 둘이면 뒤엣것에 번호를 붙입니다 — 그대로 두면 `매출표[금액]` 이 어느 열인지 정해지지 않습니다.

## 만들면서 걸린 것

머리글을 `금액` 에서 `매출액` 으로 고쳤는데 `=SUM(매출표[금액])` 이 **300을 그대로 들고 있었습니다.**

풀리지 않는 수식은 의존성 그래프에 오르지 못합니다 — 무엇에 기대는지 알아내려면 **먼저 풀려야** 하기 때문입니다. 그래서 다시 셈할 계기를 영영 얻지 못하고, 없어진 열의 옛 답이 맞는 답인 양 남습니다. 틀린 값이 조용히 남는 것이 가장 나쁩니다.

머리글을 건드렸으면 표를 가리키는 수식을 모두 다시 셉니다. 머리글을 고치는 일은 드무므로 비싸지 않습니다. 이제 그 자리에서 `#REF!` 가 되고, **어느 표의 무슨 열이 없는지** 말해 줍니다.

## 일부러 막는 것

이름이 겹치거나 표끼리 서로 걸치면 **만들 때** 막습니다. 겹친 이름은 어느 것을 가리키는지 사람도 기계도 모르고, 걸친 표는 한쪽에서 행을 지우면 다른 쪽이 조용히 어그러집니다. 그때 가서 고치는 것보다 쌉니다.

머리글만 있고 자료가 없는 표도 막습니다. 빈 것을 내는 것보다, 자료 줄을 넣어 달라고 말해 주는 편이 낫습니다.

## 파일로 나가고 들어옵니다

XLSX 로는 엑셀의 표로 나가고, 가져올 때 다시 표가 됩니다. 엑셀에서도 같은 이름으로 가리킬 수 있습니다.

## 검증 결과

- 엔진: 열 이름, 맨 이름, 지정자 넷, 겹친 머리글 번호 매기기, 없는 열, 닫히지 않은 대괄호.
- 메모리와 Postgres 양쪽: 행 끼우기, 머리글 고치기, 겹친 이름, 걸친 표, 파일 왕복, 표를 지우면 `#NAME?`.
- 브라우저: 메뉴에서 만들고 셀에서 부르고 행을 끼워도 맞는지 통째로 돌립니다.
- Go 시험 전체, 통합 시험 전체, 웹 시험 390개가 통과합니다.

## 시험을 쓰며 만난 것

행·열을 넣는 엔드포인트를 `POST /structure` 로 적었더니 `405` 였습니다. 실제로는 `PATCH /structure:apply` 입니다. 상태 코드를 확인하지 않았으면 아무 일도 일어나지 않은 채 시험이 통과했을 것입니다 — 지난 판에 셀 넣기에서 똑같이 당한 자리라 이번에는 처음부터 확인하게 적었습니다.
