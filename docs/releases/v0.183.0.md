## 릴리즈 요약

v0.183.0은 지난 판의 인쇄 미리보기가 **인쇄와 같은 범위** 를 세게 합니다.

## 규칙만 모으고 입력을 모으지 않았습니다

v0.182.0에서 열을 끊는 규칙을 밖으로 꺼내 인쇄와 나눠 쓰게 했습니다. 규칙은 같아졌는데 **그 규칙에 넣는 범위는 여전히 둘이었습니다.**

미리보기는 값싸게 하려고 시트 크기만 물었습니다. 그 수는 가장 큰 행과 열만 알려 줍니다.

```
자료가 D열에서 시작해도  →  A열부터 셌다
값 없이 서식만 든 칸도    →  세었다
```

인쇄는 `usedRegion` 으로 값이 든 칸의 최소 사각형을 씁니다. 둘이 다르므로 **미리보기가 네 장이라고 하고 세 장이 나올 수 있었습니다** — 지난 판에서 막았다고 적어 둔 바로 그 일입니다.

## 인쇄가 읽는 칸을 그대로 읽습니다

같은 칸에서 같은 함수로 범위를 구합니다. 페이지 설정을 열 때 인쇄만큼 걸리지만, **값싸고 틀린 수보다 낫습니다.** 미리보기가 틀리면 볼 이유가 없고, 볼 이유가 없는 것을 보여 주는 것은 값싸지 않습니다.

행이 많아 앞부분만 찍히는 경우도 그 자리에 적습니다. 인쇄를 누른 뒤에야 묻는 것보다 고르기 전에 아는 편이 낫습니다.

## 검증 결과

- **D열에서 시작하는 표** 로 시험합니다. A열부터 세면 깨집니다.
- 서식만 든 칸을 범위에 넣지 않는지 따로 봅니다.
- 브라우저 시험도 D열에서 시작하도록 고쳤습니다. 예전 코드였다면 `A` 가 나옵니다.
- 웹 시험 419개와 Go 시험 전체가 통과합니다.
