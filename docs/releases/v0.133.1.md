## 릴리즈 요약

v0.133.1은 **차트 제목이 실제로 그린 것과 달랐던 것** 을 고칩니다. 앞 판의 핵심 지표와 같은 종류의 어긋남입니다.

## 글과 그림이 다른 말을 했다

```
그린 것   분기 축 + 매출, 비용, 이익 세 줄
적은 것   "매출 추이"  ·  캡션 "매출"
```

선 그래프는 잴 것을 **모두** 그리는데, 제목과 캡션은 첫 열 하나만 쓰고 있었습니다. 읽는 사람은 나머지 두 줄이 무엇인지 범례를 뒤져야 합니다.

그린 것을 그대로 적습니다.

```
매출·비용·이익 추이
```

## 반대쪽으로 어긋나지 않도록

고치기 전에 **무엇을 그리는지** 부터 확인했습니다. 모두 복수로 바꿨다면 이번에는 반대로 어긋났을 것입니다.

| 그림 | 그리는 것 | 제목 |
| --- | --- | --- |
| 추이(선) | 잴 것을 모두 | **복수로** |
| 막대 · 비중 · 비교 | 첫 열 하나만 | 단수 그대로 |
| 묶은 범위 | 묶은 값 한 줄만 | 단수 그대로 |

이름이 넷을 넘으면 다 적는 것이 오히려 읽기 어려우므로 `매출 외 4개`로 줄입니다.

## 검증 결과

- 고치기 전 코드에서 제목과 캡션이 모두 걸립니다. 헬퍼는 남기고 **부르는 자리만** 되돌려 확인했습니다 — 통째로 되돌리면 컴파일이 되지 않아 무엇이 틀렸는지 드러나지 않습니다.
- 막대 그래프가 복수로 바뀌지 않았는지도 함께 봅니다.
- 실제 서버에서 세 가지 표(선·단일·막대)로 확인했습니다.
- Go 시험 전체와 웹 시험 379개가 통과합니다.
