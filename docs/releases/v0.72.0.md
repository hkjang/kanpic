## 릴리즈 요약

v0.72.0은 **최근에 더한 데이터 기능들을 손이 닿는 곳으로 옮깁니다.** 부분합, 슬라이서, 데이터 연결, 열 통계, 범위 보호, 편집 기록은 지난 몇 주 동안 만들어 두고도 특정 패널이나 메뉴 한 곳에서만 열 수 있었습니다. 기능이 있어도 찾지 못하면 없는 것과 같습니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 명령 팔레트

`Ctrl/⌘+K` 로 여는 빠른 이동에 명령 일곱 개를 더했습니다. **부분합**, **부분합 제거**, **슬라이서 추가**, **데이터 연결**, **열 통계**, **시트·범위 보호**, **편집 기록 표시** 입니다. 한글과 영문 검색어를 함께 달아 `subtotal` 로도 `소계` 로도 잡힙니다.

편집 기록은 현재 선택한 셀을 대상으로 엽니다. 팔레트는 셀을 고르는 화면이 아니므로, 열기 전에 보고 싶은 셀에 커서를 두면 됩니다.

## 셀 오른쪽 클릭

셀 메뉴의 **데이터** 하위 메뉴가 정렬·검증·조건부 서식에서 끝나고 있었습니다. 구분선 뒤에 **부분합…**, **중복 항목 삭제…**, **텍스트를 열로 분할…** 을 이어 붙였습니다. 세 가지 모두 선택 범위를 그대로 넘겨받으므로, 오른쪽 클릭한 자리에서 바로 이어집니다.

## 검증 결과

- 새 E2E 시나리오 하나를 더했습니다. 셀 오른쪽 클릭 → 데이터에서 세 항목이 보이는지, 부분합을 고르면 그 대화상자가 뜨는지, 같은 명령이 팔레트 검색으로도 잡히고 실행되는지 확인합니다. **고치기 전 번들로 빌드해 이 테스트가 실패하는 것을 먼저 확인**했습니다(`부분합…` 항목을 찾지 못함).
- `go vet ./...`, `go test ./...`, React/Vitest 234개 테스트, TypeScript 타입 검사, Vite 프로덕션 빌드, Playwright E2E 131건을 통과했습니다.
