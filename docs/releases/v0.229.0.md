# v0.229.0

## CEILING·FLOOR 이 음수를 양의 배수로 맞춘다

`=CEILING(-4.5, 2)` 가 `#NUM!` 이었습니다. 엑셀과 구글 시트는 `-4` 를 냅니다.

수와 배수의 부호가 어긋나면 무조건 답이 없다고 본 것이 잘못이었습니다. 그것은
MROUND 의 규칙입니다. CEILING·FLOOR 에서 답이 없는 것은 **양수를 음의 배수로**
맞추는 쪽 하나뿐입니다.

| 수식 | 그동안 | 이제 |
| --- | --- | --- |
| `=CEILING(-4.5, 2)` | `#NUM!` | `-4` |
| `=FLOOR(-4.5, 2)` | `#NUM!` | `-6` |
| `=CEILING(-2.5)` | `#NUM!` | `-2` |
| `=FLOOR(-2.5)` | `#NUM!` | `-3` |
| `=CEILING(2.5, -2)` | `#NUM!` | `#NUM!` |
| `=MROUND(-4.5, 2)` | `#NUM!` | `#NUM!` |

몫이 음수이면 "0 에서 멀어지는 쪽" 과 "위쪽" 이 서로 반대입니다. CEILING 은 배수의
부호와 상관없이 언제나 몫을 위로, FLOOR 는 언제나 아래로 보냅니다. 그래서
`CEILING(-2.5, -2)` 는 `-4` 이고 `CEILING(-2.5, 2)` 는 `-2` 입니다. 부호가 같은
쪽의 답은 그대로입니다.

십진 셈은 그대로 따라갑니다. `=CEILING(-0.1-0.2, 0.1)` 은 `-0.4` 가 아니라 `-0.3`
입니다.

- `internal/formula/library_extended_test.go` 의 `TestCeilingAndFloorFollowExcelSignRules` — 엑셀 도움말의 부호 표를 그대로 옮겨, 네 부호 조합의 답과 `#NUM!` 을 내야 하는 두 자리를 함께 고정합니다.
