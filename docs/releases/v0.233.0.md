# v0.233.0

## 백만 원 단위 표가 백만 배로 보이지 않는다

재무 자료의 표시 형식에는 `#,##0,,` 처럼 자리 기호 **뒤** 에 쉼표를 붙인 것이
흔합니다. 그 쉼표는 자릿점이 아니라 "천 단위로 줄여 적으라" 는 뜻입니다.
쉼표 하나면 천 단위, 둘이면 백만 단위입니다.

kanpic 은 쉼표가 있기만 하면 자릿점으로 보았습니다. 그래서 `1234567` 이 담긴
칸이 `1` 이 아니라 `1,234,567` 로 보였습니다. 표 머리에는 "(백만 원)" 이라고
적혀 있는데 값은 원 단위로 그려져 있으니, 읽는 사람은 백만 배 큰 금액으로
읽습니다. 엑셀에서 만든 표를 가져오면 늘 그렇게 보였습니다.

이제 자리 기호 뒤의 쉼표만 세어 그만큼 줄여 적습니다.

- `#,##0,` → **1,235**, `#,##0,,` → **1**, `0.0,,` → **1.2** (값은 모두 `1234567`)
- `0.0,,"백만"` → **1.2백만**
- 자리 기호 **사이** 의 쉼표는 그대로 자릿점입니다. `#,##0` 은 `1,234,567` 입니다.

## 회계 서식의 0 이 "-" 로 그려진다

엑셀 서식은 `;` 로 구역을 나눠 값의 부호마다 다르게 적습니다. 구역이 셋이면
**양수 ; 음수 ; 0** 이고, 넷째 구역은 글자입니다. kanpic 은 구역이 둘뿐인 줄
알고 0 을 늘 양수 구역으로 보냈습니다. 회계 서식 `#,##0;(#,##0);"-"` 의 0 은
`-` 여야 하는데 `0` 이라고 적혀 있었고, 합계 행이 있는 표에서 눈에 띄었습니다.

- `=TEXT(0,"#,##0;(#,##0);""-""")` → **-**
- 비워 둔 구역은 아무것도 적지 않습니다. `0;;` 은 음수와 0 을 감추라는 뜻이라
  `=TEXT(-5,"0;;")` 은 **빈 글자** 입니다. 예전에는 음수 구역이 없는 줄 알고
  `5` 라고 적었습니다 — 부호까지 사라진 채로 보였습니다.
- 자리 기호가 없는 구역은 적어 둔 글자만 적습니다. `"판매"` 는 `판매` 입니다.
- 따옴표 안의 `;` 는 구역을 가르지 않습니다. `#,##0;"내려감;"` 은 구역이 둘입니다.

날짜 서식에 날짜가 될 수 없는 수가 들어왔을 때 수만 적던 것은 그대로입니다.
