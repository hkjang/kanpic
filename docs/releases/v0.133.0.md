## 릴리즈 요약

v0.133.0은 **핵심 지표 슬라이드가 첫 열 하나만 말하던 것** 을 고칩니다.

## 템플릿이 아니라 내용이었다

프레젠테이션 품질이 낮게 느껴진다는 이야기에 앞 판에서는 **템플릿** 을 손봤습니다. 이번에는 덱 내용 자체를 실제로 만들어 보았습니다.

```
분기 / 매출 / 비용 / 이익  →  최고 매출, 최저 매출, 합계 매출
```

**이익이 얼마인지 한 장도 말하지 않습니다.** 요약을 만드는 자리가 첫 번째 측정 열 하나만 깊이 파고, 나머지 열은 증감률이나 달성률 같은 특별한 역할일 때만 언급하기 때문입니다. 매출·비용·이익처럼 평범한 숫자 열은 통째로 조용합니다.

## 깊이보다 넓이

핵심 지표 슬라이드에 들어가는 칸은 넷입니다. 그 중 셋을 한 열에 쓰는 것보다 **열마다 합계를 하나씩** 두는 편이 낫습니다.

| | |
| --- | --- |
| 고치기 전 | 최고 매출 · 최저 매출 · 합계 매출 |
| 지금 | 최고 매출 · **합계 매출** · **합계 비용** · **합계 이익** |

잴 것이 하나뿐이면 그 열을 깊이 파는 것이 맞으므로 최고·최저·합계를 그대로 보여 줍니다.

## 더하면 뜻이 없는 열

달성률 `90%`, `120%`, `80%`를 더해 `290%`라고 적으면 슬라이드가 거짓말을 합니다. 증감률과 달성률처럼 비율인 열은 합계를 내지 않습니다.

## 검증 결과

- 고치기 전 코드에서 합계 비용과 합계 이익이 없어 걸립니다.
- 잴 것이 하나일 때 예전 모습이 그대로인지도 함께 봅니다.
- 비율 열의 합계가 나오지 않는지 확인합니다.
- 실제 서버에서 두 가지 표로 확인했습니다.
- Go 시험 전체와 웹 시험 379개가 통과합니다.
