## 릴리즈 요약

v0.28.0은 템플릿 갤러리를 **30종에서 62종으로** 늘립니다. **부동산 10종, 주식·투자 10종, 신용평가 6종, 금융 6종**을 새 분류로 추가했고, 단순한 관리대장부터 원리금 상환·DCF·복리·가중 스코어링처럼 계산이 필요한 모형까지 함께 담았습니다.

필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나이며 새 마이그레이션은 없습니다.

## 계산이 실제로 맞는지 확인합니다

- 새 템플릿도 kanpic 수식 엔진이 지원하는 함수만 사용합니다. 대출 상환액은 `POWER`로 원리금 균등 상환식을, 복리 계산은 `POWER`를, 등급 판정은 중첩 `IF`를 사용합니다.
- 손으로 계산한 값과 비교하는 테스트를 추가했습니다. 3억 원을 연 4.5%로 120개월 상환하면 월 3,109,152원, 첫 달 이자 1,125,000원, 잔액 298,015,848원이 나오는지 확인합니다. 대출 비교, DCF 할인계수, 스코어카드 가중 합계, 임대 수익률도 같은 방식으로 검증합니다.
- 분류마다 템플릿이 2개 이상인지 검사해, 카드 하나만 있는 빈 필터 칩이 생기지 않도록 했습니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. 62종 전부를 적용해 수식이 오류 코드 없이 계산되는지, 지원하지 않는 함수를 쓰지 않는지 확인하고, 금융 템플릿 5종은 독립적으로 계산한 값과 대조합니다.
- React/Vitest 29개 테스트 파일, 133개 테스트를 통과했습니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 70건을 통과했습니다. 갤러리에 62장이 보이고 새 분류로 필터링되며 템플릿으로 만든 워크북이 바로 계산되는지 확인했습니다.

## 수정된 문제

- 작성 중 발견한 순환 참조 두 건(전세·월세 비교의 차이 열, 재무비율 분석의 자기자본)과 남아 있던 잘못된 함수 이름 한 건을 카탈로그 테스트가 잡아 고쳤습니다.
- 임대 수익률 분석의 실질 수익률이 이자를 뺀 순수익을 총 투자금으로 나눠 차입 효과가 섞여 있었습니다. 무차입 기준(NOI ÷ 총 투자금)으로 바로잡고 레버리지 효과도 그 기준과 비교합니다.
