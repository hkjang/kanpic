## 둘만 만들면 열한 개가 열립니다

카이제곱, t, F, 베타는 겉보기에 다른 분포지만 모두 **정규화된 불완전 감마** 와 **불완전 베타** 두 함수로 풀립니다. 그래서 그 둘을 제대로 만드는 데 힘을 썼습니다.

- 불완전 감마는 `x` 가 작으면 급수가, 크면 연분수가 빨리 모입니다. 경계를 잘못 잡으면 한쪽이 아주 느려집니다.
- 불완전 베타는 `x` 가 가운데를 넘으면 대칭을 써서 반대쪽을 셉니다. 그래야 연분수가 모입니다.

## 어느 꼬리를 재는지가 함수마다 다릅니다

```
CHIDIST, FDIST   오른쪽 꼬리
TDIST            세 번째 인수로 한쪽·양쪽을 고른다
TINV             양측이다
BETADIST         왼쪽 누적
```

`TINV` 를 한쪽 꼬리로 알고 쓰면 **조용히 다른 값** 이 나옵니다. 오류도 나지 않고 그럴듯한 숫자가 나오므로 알아채기 어렵습니다.

## 틀린 기준으로 멀쩡한 코드를 고칠 뻔했습니다

기댓값은 급수·연분수와 **다른 방법** 으로 맞췄습니다. 확률밀도를 수치적분한 값과 교과서 표입니다. 같은 방법으로 검증하면 정의를 잘못 이해한 것을 잡을 수 없습니다.

그런데 `CHITEST` 와 대응표본 `TTEST` 두 값이 여덟째 자리에서 갈렸습니다. 자유도 3의 카이제곱 **닫힌 형태** 와 꼬리 끝까지 세는 **치환 적분** 으로 다시 재 보니 — 엔진 쪽이 맞았습니다. 처음 쓴 적분이 특이점과 잘린 꼬리에서 약했던 것입니다.
