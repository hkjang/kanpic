## 릴리즈 요약

v0.94.0은 **여러 장으로 인쇄할 때 둘째 장부터 열 머리글이 사라지던 문제**를 고칩니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 둘째 장부터 사라지던 머리글

120행짜리 표를 인쇄해 만들어진 문서를 열어 봤습니다. 열 머리글(`A`, `B`, `C`…) 줄이 표 본문의 **첫 줄로** 들어가 있었습니다.

브라우저는 표 머리글을 장마다 다시 그려 주지만, 그것이 `thead` 안에 있을 때만 그렇게 합니다. 본문 첫 줄로 넣으면 첫 장에만 찍히고, 둘째 장부터는 숫자만 늘어선 표가 됩니다. 어느 칸이 무슨 열인지 알 수 없는 인쇄물입니다.

머리글 줄을 `thead` 로 옮기고 본문을 `tbody` 로 감쌌습니다. 행 번호는 원래대로 각 줄 왼쪽에 붙습니다.

## 함께 확인한 것

- 120행 인쇄 문서를 실제로 만들어 구조를 확인했고, 고친 뒤 같은 표가 세 장으로 나뉘는 것도 확인했습니다.
- 열이 서른 개인 표도 인쇄해 봤습니다. 표는 페이지 너비에 맞춰 좁아지며 넘치지는 않습니다. 엑셀처럼 옆으로 장을 나누지는 않는데, 이는 결함이라기보다 다른 선택이라 이번에는 손대지 않았습니다.

## 검증 결과

- 머리글이 `thead` 에, 본문이 `tbody` 에 들어가는지 확인하는 테스트를 더했습니다. 머리글을 끄면 `thead` 자체가 없어야 하는 것도 함께 봅니다. 고치기 전 코드에서 두 테스트 모두 실패합니다.
- `go vet ./...`, `go test ./...`, React/Vitest 265개 테스트, TypeScript 타입 검사, Vite 프로덕션 빌드, Playwright E2E 148건을 통과했습니다.
