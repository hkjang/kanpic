## 릴리즈 요약

v0.22.1은 화면 일관성을 맞춥니다. v0.22.0에서 추가한 관리자 화면 네 개가 기존 관리자 콘솔과 다른 조판을 사용하고 있었고, 편집기의 차트·피벗·자동화 버튼이 그리드 위에 떠 있어 위치가 애매했습니다.

기능 변경은 없으며 마이그레이션도 없습니다.

## 관리자 콘솔 디자인 통일

- 개요, 사용자 및 역할, 부서 및 공유, 워크북 거버넌스 화면을 기존 시스템 설정·서버 로그·API 키 화면과 같은 구성으로 다시 만들었습니다.
- 공통 조판을 사용합니다: 카테고리 라벨(eyebrow)과 제목·설명, 오른쪽 상단 동작 버튼, 3열 지표 카드, 흰색 카드와 카드 헤딩, 공통 테이블 행, 활성·정지 배지, 결과 배너.
- 사용자 등록과 부서 추가는 페이지 하단 폼 대신 표준 모달로 바꿔 목록이 먼저 보이도록 했습니다. 모달은 다른 대화상자와 동일하게 Esc로 닫히고 포커스가 순환합니다.
- 각 화면 상단에 그 화면에 맞는 지표를 넣었습니다. 사용자 화면은 전체·관리자·정지 계정 수, 부서 화면은 부서·구성원 배치·최상위 부서 수, 거버넌스 화면은 표시 중·공개 범위 확장·소유자 문제 수입니다.
- 결과 메시지와 오류 배너에 `status`·`alert` 역할을 부여해 화면 낭독기에서도 결과를 알 수 있습니다.

## 편집기 버튼 위치 정리

- 그리드 오른쪽 아래에 떠 있던 **차트 · 피벗 · 자동화** 버튼을 도구 모음 오른쪽의 패널 버튼 묶음으로 옮겼습니다. AI 도우미, 편집 충돌, 버전 이력, 댓글과 같은 자리에서 같은 방식으로 열고 닫습니다.
- 시트 탭과 상태 표시줄을 가리던 떠 있는 버튼이 사라져 마지막 행과 탭이 항상 보입니다.
- 자동화 버튼은 편집 권한이 있을 때만 나타나는 기존 규칙을 유지합니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다.
- React/Vitest 24개 테스트 파일, 91개 테스트를 통과했습니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 50건을 통과했습니다. 관리자 콘솔의 사용자 등록·역할 부여·계정 정지, 개요에서 거버넌스로 이동해 링크 공개를 되돌리는 흐름, 차트·피벗·자동화 패널 열기를 새 위치에서 확인했습니다.

## 업그레이드 참고

- 데이터베이스 변경이 없습니다. v0.22.0 이미지를 교체하면 됩니다.
- 차트·피벗·자동화 버튼을 화면 좌표로 클릭하던 자동화 스크립트는 도구 모음의 `차트 패널`, `피벗 패널`, `자동화 패널` 버튼을 사용하도록 바꿔야 합니다.
