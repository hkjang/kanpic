## 릴리즈 요약

v0.126.3은 **사용자 가이드가 없는 함수를 설명하지 않는지 지키는 시험** 을 둡니다. 가이드 전체를 훑어본 결과는 **깨끗했습니다.**

## 문서를 시험으로 쓴다

v0.126.2에서 가이드에 적은 수식을 실제로 돌려 보다 버그를 찾았습니다. 그 방법을 가이드 전체로 넓혀 보았습니다.

| 무엇을 보았나 | 결과 |
| --- | --- |
| 가이드가 이름을 대는 함수 **91개** | 모두 있습니다. 없는 것은 없었습니다 |
| 가이드에 적힌 수식 **247개** | 새로 드러난 문제 없음 |

247개 중 33개가 `#ERROR!`였지만 모두 `=AND(조건1, 조건2, ...)`처럼 **뜻을 설명하려고 적은 서식** 이지 돌리려고 적은 예가 아닙니다. 176개의 `#NAME?`도 `=ABS(수치)`처럼 자리를 채우는 말이 이름으로 읽힌 것입니다. 둘 다 버그가 아닙니다.

## 찾은 것이 없어도 남긴다

고칠 것이 없으므로 이번 판에 기능 변경은 없습니다. 대신 91개를 확인한 방법을 **시험으로 남겼습니다.**

함수 이름을 바꾸거나 뺄 때 문서가 함께 고쳐지지 않기 쉽습니다. 그리고 문서를 보고 그대로 적었는데 `#NAME?`이 나면, 무엇이 잘못됐는지 알아낼 방법이 없습니다. 자기 수식을 의심하게 되지, 문서를 의심하지는 않기 때문입니다.

함수 목록이 실제 셈과 맞는지는 이미 다른 시험이 지킵니다. 이쪽은 **문서가 목록과 맞는지** 를 지킵니다.
