# v0.248.0

## MCP 응답을 명세에 맞게 다듬었습니다

v0.247.0 으로 MCP 클라이언트가 Keycloak 로그인으로 들어오게 되자, 지금까지
API 키를 붙인 스크립트만 두드리던 `/mcp` 를 **공식 SDK 를 쓰는 클라이언트**가
부르게 됩니다. 그 클라이언트들은 응답을 스키마로 검증합니다. 그 눈으로 `/mcp`
를 다시 읽어 보니, 지금까지 아무도 걸리지 않았을 뿐인 어긋남이 여럿 있었습니다.

**목록이 통째로 거절되던 것.** `spreadsheet.workbook.list` 처럼 배열을 돌려주는
도구는 `structuredContent` 에 배열을 그대로 실었습니다. 명세는 이 자리를
**객체**로 정하고, TypeScript·Python SDK 는 배열이 오면 성공한 호출을 통째로
오류로 바꿉니다. 이제 목록은 `{"items": [...]}`, 스칼라는 `{"value": ...}` 로
감싸고, 모델이 읽는 `content[0].text` 에는 원래 JSON 이 그대로 있습니다.

**`ping` 과 알림.** 클라이언트가 주기적으로 보내는 `ping` 에 "지원하지 않는
메서드" 라고 답했고, `notifications/cancelled` 같은 알림에도 오류를 돌려
보냈습니다 — 알림에는 답하지 않는 것이 규칙입니다. `ping` 은 빈 결과로,
`notifications/*` 와 id 없는 요청은 202 로 답합니다.

**버전 협상.** `initialize` 는 클라이언트가 무엇을 말하든 `2025-06-18` 이라고만
했습니다. 이제 `2024-11-05`·`2025-03-26`·`2025-06-18` 중 클라이언트가 말한
것을 그대로 돌려주고, 모르는 버전이면 최신으로 답합니다. `MCP-Protocol-Version`
헤더에 모르는 버전이 오면 400 입니다.

**GET /mcp 가 HTML 이었던 것.** 스트림을 열어 보려는 클라이언트의 GET 은 SPA
폴백에 걸려 `index.html` 을 200 으로 받았습니다. 이제 GET 과 DELETE 는 405 와
`Allow: POST` 로 답합니다. 배치(배열) 요청과 해석할 수 없는 본문도 400 페이지
대신 JSON-RPC 오류(-32600, -32700)로 돌아갑니다. 없는 도구는 실행 실패가 아니라
-32602 프로토콜 오류입니다.

## 끊기지 않습니다

도구 하나가 패닉을 내면 연결이 끊어져 클라이언트는 이유 없이 재시도만 했습니다.
이제 -32603 으로 답하고 스택은 서버 로그 `mcp handler panicked` 에 남습니다.
결과를 JSON 으로 만들 수 없을 때(예: 수식이 낸 NaN) 200 헤더를 보낸 뒤 본문이
반쯤 끊기던 것도, 먼저 다 만들어 보고 안 되면 이유를 담은 도구 실패로 답합니다.
설정·API 키·로그 저장소가 붙어 있지 않은 서버에서 그 도구를 부르면 nil 참조
대신 "not configured" 라고 답합니다. API 키 만들기·수정 도구가 잘못된 인수를
조용히 빈 값으로 바꾸던 것도 오류로 돌려줍니다.

## 지키는 것 둘

- **`mcp.enabled`** 는 문서에는 있었지만 코드가 보지 않았습니다. 이제 끄면
  `/mcp` 가 503 으로 답합니다.
- 명세가 요구하는 **Origin 검사**를 합니다. 브라우저에서 오는 요청은 서버 자신의
  오리진과 개발 서버(`localhost:5173`)만 통과하고 다른 오리진은 403 입니다.
  Origin 헤더가 없는 일반 클라이언트는 아무 영향이 없습니다.

## 확인

- `internal/httpapi/mcp_protocol_test.go` — 버전 협상, `ping`·알림·id 없는
  요청 202, 해석 오류·배치·잘못된 버전·없는 도구·낯선 Origin 의 오류 코드,
  목록의 `items` 감싸기, 서비스 없는 도구의 거절, GET·DELETE 405, 직렬화
  불가 결과의 처리
- 기존 REST·MCP 계약 테스트는 목록 결과의 새 꼴에 맞춰 고쳤습니다

`gofmt`·`go vet`·`go build`·`go test ./...`(전체 통과), 통합 테스트,
`scripts/check-release-docs.sh`, `scripts/check-commit-identities.sh` 를
돌렸습니다.

## 올리실 때

마이그레이션과 새 설정은 없습니다. **목록 도구의 `structuredContent` 꼴이
바뀌었습니다** — 배열을 직접 읽던 스크립트가 있다면 `items` 아래를 읽거나
`content[0].text` 를 쓰도록 고쳐야 합니다. `mcp.enabled` 를 꺼 두었던 설치는
이제부터 실제로 `/mcp` 가 막히므로, 쓰고 있었다면 켜 두어야 합니다. v0.247.0
에서 올라오시는 분은 이미지만 바꿔 다시 띄우시면 됩니다.
