## 릴리즈 요약

v0.74.0은 **수식 안에 이름과 함수를 들여옵니다.** `LET` 으로 계산 단계에 이름을 붙이고, `LAMBDA` 로 수식 자체를 함수로 만들어 `MAP`·`REDUCE` 같은 함수에 넘길 수 있습니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## LET — 계산 단계에 이름 붙이기

```
=LET(매출, SUM(C2:C100), 건수, COUNT(C2:C100), IF(건수=0, 0, 매출/건수))
```

같은 계산을 세 번 쓰던 수식이 한 번으로 줄고, 읽는 사람은 계산 순서대로 따라갈 수 있습니다. **이름이 가리키는 계산은 한 번만 수행됩니다.**

이름은 앞에서 정한 이름을 쓸 수 있습니다. `A1` 처럼 셀 주소로 읽히는 이름은 거절합니다. 같은 수식이 어디에 놓이느냐에 따라 뜻이 달라지기 때문입니다.

**이름을 붙여도 의존성은 그대로입니다.** `LET(총합, SUM(A1:A3), 총합)` 은 A1:A3 세 셀에 의존하므로, 그 셀을 고치면 다시 계산됩니다. 이름 뒤로 의존성이 끊기면 화면이 조용히 낡습니다.

## LAMBDA — 수식으로 함수 만들기

`=LAMBDA(x, x*2)(21)` 처럼 만든 자리에서 바로 호출하거나, `LET` 으로 이름을 붙여 여러 번 씁니다.

```
=LET(부가세, LAMBDA(값, 값*0.1), SUM(MAP(B2:B10, 부가세)))
```

함께 들어온 함수는 여섯 개입니다. `MAP`(값마다 적용, 배열 여러 개를 나란히 받습니다), `BYROW`·`BYCOL`(행·열마다 적용), `REDUCE`(하나로 접기), `SCAN`(누적 중간 결과), `ISOMITTED`(인수 생략 확인).

`LAMBDA` 만 홀로 쓴 셀은 오류로 처리합니다. 함수는 셀이 담을 수 있는 값이 아니라, 화면에 표시할 수도 다시 계산에 쓸 수도 없기 때문입니다.

## 구현 메모

이름은 **파싱하는 동안** 알아야 합니다. 그렇지 않으면 `LET(x, 5, x*2)` 의 `x` 가 이름 범위로 조회되어 계산이 시작되기도 전에 실패합니다. 그래서 파서가 이름 스택을 들고 다니며, 안쪽 이름이 바깥 이름을 가립니다.

값은 셀 맵이 아니라 **바인딩 프레임**에 둡니다. 이름 세 개를 더하자고 10만 칸짜리 시트를 복사할 이유가 없기 때문입니다. 프레임은 평가가 끝나면 되돌려져서, 반복 평가가 이전 값을 보는 일이 없습니다.
