## 릴리즈 요약

v0.130.1은 **가져온 차트가 서로 겹쳐 하나만 보이던 것** 을 고칩니다.

## 다 되었는지 다시 짚어 보다

v0.130.0에서 차트 가져오기를 넣고, 정말 끝난 것인지 다시 짚어 보았습니다. 차트가 **둘인** 파일을 가져와 보니 이렇게 나왔습니다.

```
bar   "월별 매출"   x=24  y=24
line  "추세"        x=24  y=24
```

같은 자리입니다. 뒤엣것이 앞엣것을 완전히 가립니다.

## 겹치면 없는 것과 같다

사람 눈에는 **차트 하나만 들어온 것** 으로 보입니다. 나머지는 가져오지 못한 줄 알게 되는데, "차트 1개는 가져오지 않습니다" 같은 알림도 뜨지 않으니 물어볼 데가 없습니다. 파일 쪽이 잘못됐나 싶어 원본을 다시 열어 보게 됩니다.

가져온 차트를 아래로 늘어놓도록 고쳤습니다.

```
bar   "월별 매출"   x=24  y=368
line  "추세"        x=24  y=24
```

그림이 **원래 놓여 있던 자리** 는 그리기 관계를 따라가야 알 수 있습니다. 자리는 자료가 아니라 배치이므로 그대로 옮기지 않아도 되지만, 겹치지 않는 것은 지켜야 합니다.

## 검증 결과

- 자리가 겹치는지 보는 시험을 두었습니다. 고치기 전 코드에서 걸립니다.
- 종류를 알 수 없거나 범위가 없는 차트는 만들지 않는지도 함께 봅니다.
- Go 시험 전체와 웹 시험 376개가 통과합니다.
