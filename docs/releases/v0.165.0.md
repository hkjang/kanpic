## 릴리즈 요약

v0.165.0은 **반만 만들어 둔 것** 을 마저 합니다. 표에 색을 담아 두고 엑셀의 표 서식으로 내보내면서도, 정작 고를 자리가 없었고 화면에서도 쓰지 않았습니다.

## 색을 고릅니다

대화상자에서 **파랑 · 초록 · 주황 · 빨강** 가운데 고릅니다. 고른 색으로 테두리와 머리글, 이름표를 그립니다. 표가 여럿일 때 어디까지가 어느 표인지 한눈에 갈립니다.

## 화면과 파일이 같은 색이어야 합니다

다르면 어느 쪽이 맞는지 사람이 알 수 없습니다. 그래서 고를 수 있는 이름은 **내보내는 쪽이 아는 것만** 늘어놓습니다 — 모르는 이름을 보내면 기본값으로 나가 화면과 달라집니다.

## 검증 결과

- 브라우저에서 고른 색이 저장되는지 확인하고, 색이 다른 표 둘을 실제로 그려 눈으로 확인했습니다.
- 웹 시험 392개와 Go 시험 전체가 통과합니다.
