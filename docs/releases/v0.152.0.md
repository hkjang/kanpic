## 릴리즈 요약

v0.152.0은 **kanpic 안에서는 되는데 밖으로 나가면 깨지는 것** 두 가지를 고칩니다. 이름 있는 수식이 엑셀에서 `#NAME?` 이 되던 것과, 지켜보는 범위가 행을 끼워도 제자리에 남아 엉뚱한 칸의 알림을 보내던 것입니다.

## 이름 있는 수식이 엑셀에서도 동작합니다

v0.148.0에서 이름 있는 수식을 넣었지만, XLSX 로 내보내면 정의가 함께 나가지 않았습니다. `=마진율(A1,B1)` 이 든 파일을 엑셀에서 열면 `#NAME?` 이 떴습니다.

엑셀은 매개변수를 가진 이름을 `LAMBDA` 로 적습니다. 그 꼴로 내보냅니다.

```
마진율(매출, 원가) = (매출-원가)/매출
  -> _xlfn.LAMBDA(매출,원가,(매출-원가)/매출)
```

본문이 `IFS` 같은 최신 함수를 쓰면 그 이름도 파일 안의 꼴이어야 하므로 이미 있는 변환을 지납니다. 매개변수가 없으면 `LAMBDA` 로 감쌀 까닭이 없어 그 수식 그대로 나갑니다.

엑셀이 받아 주지 않는 이름 하나가 내보내기 전체를 막으면 안 되므로, 이름 범위와 같이 그것만 건너뜁니다.

## 지켜보는 범위가 행과 열을 따라 움직입니다

행이나 열이 끼워지고 지워질 때 범위를 담은 표는 모두 따라 움직입니다 — 조건부 서식, 데이터 확인, 보호 범위, 이름 범위, 필터 보기, 차트, 피벗, 댓글. **변경 알림만 빠져 있었습니다.**

`B5:B9` 를 지켜보는 중에 위에 한 행을 끼우면 규칙은 그대로 `B5:B9` 를 봤습니다. 사람은 자기가 정한 칸을 지켜본다고 믿는 채로 엉뚱한 칸의 알림을 받게 됩니다. **알림이 오지 않는 것보다 엉뚱한 알림이 오는 것이 더 나쁩니다.**

꺼 둔 규칙도 같이 옮깁니다. 다시 켰을 때 제 칸을 봐야 하므로, 옮길 때는 켜짐 여부로 거르지 않고 다 읽습니다.

지켜보던 칸이 통째로 지워지면 규칙도 사라집니다. 시트 전체를 보는 규칙으로 바꾸면 사람이 부탁한 적 없는 알림을 받게 됩니다. 범위를 비워 둔 규칙은 처음부터 시트 전체이므로 옮길 것이 없습니다.

## 검증 결과

- 내보내기: 매개변수가 있는 것, 없는 것, 본문이 최신 함수를 쓰는 것 셋을 확인합니다.
- 변경 알림: 메모리와 Postgres 양쪽에서 끼우기, 꺼 둔 규칙, 시트 전체, 지우기를 확인합니다.
- Go 시험 전체와 통합 시험 전체가 통과합니다.
