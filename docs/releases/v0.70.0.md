## 릴리즈 요약

v0.70.0은 **조건부 서식을 XLSX와 주고받도록** 합니다. 지난 릴리즈에서 남겨 둔 마지막 자리입니다. 이제 값·수식·서식·병합에 더해 시트 배치, 데이터 검증, 조건부 서식이 모두 파일을 통해 오갑니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 오가는 규칙

| kanpic | XLSX |
| :--- | :--- |
| 값 조건 (8개 비교, 포함·미포함) | 셀 값 / 텍스트 규칙 |
| 빈 값 · 빈 값 아님 | blanks / no blanks |
| 맞춤 수식 | 수식 규칙 |
| 중복 · 고유 값 | duplicate / unique |
| 2색 · 3색 범위 | 2색 · 3색 색조 |
| 데이터 막대 | 데이터 막대 |

셀 서식(배경·글자색·굵게 등)은 엑셀 스타일로 변환되어 함께 나가고, 읽어 올 때도 스타일에서 되돌립니다.

**대응이 없으면 옮기지 않습니다.** 아이콘 집합, 상위 N개, 날짜 구간처럼 kanpic에 대응이 없는 엑셀 규칙은 비슷한 것으로 바꾸지 않고 빼놓습니다. 엉뚱한 셀을 강조하는 시트는 아무것도 강조하지 않는 시트보다 나쁩니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`, PostgreSQL 통합 테스트를 통과했습니다. 새 테스트는 값 조건·색상 범위·데이터 막대·맞춤 수식 네 가지를 내보내 엑셀 쪽 규칙 종류와 비교식(`greater than`, `100`, `$A1>100`)을 확인하고, 다시 읽어 **저장된 시트의 규칙**까지 확인합니다.
- 실제 서버에서 내보낸 파일의 `sheet1.xml` 에 `<conditionalFormatting>` 두 블록이 있는 것을 확인하고, 그 파일을 되올려 값 조건(배경 `#FEE2E2`)과 색상 범위(`#dcfce7`→`#ef4444`)가 복원되는 것을 확인했습니다.
- React/Vitest 234개 테스트, TypeScript 타입 검사, Vite 프로덕션 빌드, Playwright E2E 130건을 통과했습니다.
