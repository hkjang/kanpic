## 릴리즈 요약

v0.170.0은 **에이전트가 표를 만들 수 있게** 합니다. 표를 넣어 놓고 정작 kanpic의 간판 기능에는 알리지 않았습니다.

## "이 범위를 표로 만들어 줘"

도구 목록에 차트·피벗·필터 보기는 있는데 표가 없었습니다. 오늘 만든 것이 AI 도우미에서는 보이지 않았던 셈입니다.

```
이 범위를 표로 만들어줘
A1:C20을 매출표라는 이름의 표로 바꿔줘
선택한 곳을 테이블로 변환해줘
```

표가 생기면 `=SUM(매출표[금액])` 처럼 열 이름으로 가리킬 수 있고, 행과 열이 움직여도 그 수식이 그대로 맞습니다.

## 도구 하나는 열한 자리를 지납니다

허용 목록, 프롬프트 안내, 계획 설명, 모드 문턱, 인자 검증, 승인 scope, 작업 기억, 이어 물을 것, 실행, 검증, 되돌리기. **하나만 빠져도 도구가 있어도 닿지 않습니다** — 이 세션에서 이미 다섯 도구가 그렇게 닿지 않고 있었습니다.

## "표" 는 가장 흔한 낱말입니다

넓게 잡으면 `표 서식을 입혀줘`(색 칠하기)가 표 도구로 새고, `피벗 테이블 만들어줘`도 새어 나갑니다. 범위를 표로 **바꾸는** 말만 봅니다 — 만들다·바꾸다·변환하다가 뒤에 와야 합니다.

## 계획 단계에서 미리 막습니다

한 칸짜리 범위, 머리글만 있고 자료가 없는 범위, 이름 없는 표를 계획을 세울 때 막습니다. 그럴듯한 계획을 사람이 승인한 뒤 저장에서 막히면, **무엇을 승인한 것인지 알 수 없어집니다.**

## 검증 결과

- 관문이 도구를 받아들이는지, 위험도가 낮은지, scope 를 요구하는지, 잘못된 범위·이름을 막는지 확인합니다.
- 표 요청이 에이전트로 가고 서식·피벗·정렬·필터를 가로채지 않는지 확인합니다.
- 이미 있던 "모든 도구가 제자리에 있는지" 시험이 예시 인수 누락을 잡아 줬습니다 — 어제 표에 만든 것과 같은 종류의 장치가 여기에도 있었습니다.
- Go 시험 전체와 통합 시험 전체가 통과합니다.
