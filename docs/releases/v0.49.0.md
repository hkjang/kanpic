## 릴리즈 요약

v0.49.0은 **데이터 연결 패널**을 더합니다. v0.48.0에서 들어온 IMPORTRANGE는 갱신이 "아무 셀이나 고치기"에 의존했고, 원본을 읽을 수 있는지 확인할 방법도 없었습니다. 가져온 데이터를 읽는 사람이 늘 묻는 두 가지 — 이 값이 최신인가, 아직 볼 수 있는가 — 에 답하는 화면을 붙였습니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 새로운 기능

- **데이터 › 데이터 연결…**: 이 워크북이 가져오는 모든 원본을 한 곳에 보여 줍니다. 원본 워크북 이름, 범위, 가져온 크기(행 × 열), 그 값을 쓰는 셀 주소가 함께 나옵니다.
- **끊어진 연결은 이유와 함께 붉게 표시됩니다.** 권한이 사라졌는지, 워크북이 지워졌는지, 범위 표기가 틀렸는지 구분됩니다. 패널의 판정은 계산이 쓰는 것과 같은 코드 경로라 셀에 보이는 값과 어긋날 수 없습니다.
- **새로 고침 버튼**은 워크북의 모든 수식을 다시 계산해 IMPORTRANGE가 원본을 다시 읽게 합니다. 워크북 버전이 올라가므로 함께 보고 있는 사람에게도 같은 값이 전달되고, 갱신 시각이 패널 아래에 남습니다.

REST `GET /api/v1/workbooks/{workbookId}/connections` 와 `POST /api/v1/workbooks/{workbookId}/connections:refresh` 로 같은 기능을 쓸 수 있습니다. 조회는 읽기 권한, 새로 고침은 쓰기 권한이 필요합니다.
