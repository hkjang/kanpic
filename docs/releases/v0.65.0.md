## 릴리즈 요약

v0.65.0은 **부분합 제거**를 더합니다. 직전 릴리즈에서 부분합을 넣을 수 있게 됐지만 되돌릴 방법이 없어, 한 번 넣으면 표가 그 상태로 굳었습니다.

마이그레이션은 없습니다. 서버 변경도 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 새로운 기능

**데이터 › 데이터 정리 › 부분합 제거…** 는 부분합이 넣은 행을 지우고 남은 행을 위로 당기며, 그때 만든 접기 그룹도 함께 풉니다. 지울 행은 미리보기로 먼저 보여 줍니다.

지울 행은 라벨이 아니라 **셀에 든 `SUBTOTAL` 수식**으로 찾습니다. `부산 합계` 를 `부산 소계` 로 고쳐 두었어도 정확히 찾아내고, 반대로 사람이 직접 쓴 `합계` 라는 글자를 소계 행으로 오인하지 않습니다.

## 함께 바뀐 것

전체 합계 행이 `=SUM(C2:C3,C5:C7)` 에서 `=SUBTOTAL(109,C2:C3,C5:C7)` 로 바뀌었습니다. 계산 결과는 같습니다(데이터 구간만 가리키므로 소계를 다시 더하지 않습니다). 부분합이 넣은 모든 행이 같은 표시를 갖게 되어, 제거 기능이 라벨에 기대지 않고 행을 찾을 수 있습니다.
