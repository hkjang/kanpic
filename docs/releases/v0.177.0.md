## 릴리즈 요약

v0.177.0은 v0.176.0이 빨갛게 만든 CI를 고칩니다. **시나리오를 더하면서 데이터 메뉴가 창을 넘었습니다.**

## 시험이 예언한 그대로였습니다

메뉴 높이를 지키는 시험이 이미 있었고, 그 주석은 이렇게 적혀 있었습니다.

> 항목을 하나 더할 때마다 조금씩 다가가다가 어느 날 넘어가고, 그때 무엇이 밀려났는지는 아무도 모른다.

제가 그 어느 날을 만들었습니다. 한도(1280×800 창에 들어가는 스무 줄)를 올리는 것은 **시험이 막으려던 것을 없애는 일** 이므로 하지 않았습니다.

## 가정 분석으로 묶습니다

목표값 찾기 · 데이터 표 · 시나리오는 셋 다 **가정을 바꿔 보는 일** 입니다. 엑셀도 가상 분석으로 묶습니다. 세 줄이 한 줄이 되어 한도 아래로 내려옵니다.

```
데이터 › 가정 분석 › 목표값 찾기…
                  › 데이터 표…
                  › 시나리오…
```

## 검증 결과

- 메뉴 높이 시험을 포함해 브라우저 시험 197개가 통과합니다. 남은 4개는 프레젠테이션 것으로, 외부 서비스가 이 환경에 없어서입니다 — CI에서는 통과합니다.
