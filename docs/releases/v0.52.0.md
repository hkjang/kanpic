## 릴리즈 요약

v0.52.0은 **시트 전체 보호**를 더합니다. 지금까지는 범위 단위 보호만 있었고, 실무에서 가장 필요한 형태 — 확정된 모델 전체를 잠그고 입력 칸만 열어 다른 팀에 넘기는 구성 — 은 범위를 하나씩 보호해서는 만들 수 없었습니다.

마이그레이션 `028_sheet_protection.sql`이 추가됩니다. `protected_ranges` 테이블에 `scope` 와 `exceptions` 열을 더합니다. 기존 보호 규칙은 그대로 `범위` 보호로 남습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 새로운 기능

- **보호 대상 선택**: 데이터 › 범위 보호 대화상자에서 `선택한 범위` 와 `시트 전체` 중 고릅니다.
- **편집 허용 범위(예외)**: 시트 전체를 고르면 `B3:B6, E1` 처럼 열어 둘 칸을 적을 수 있습니다. 그 칸만 편집되고 나머지는 잠깁니다. 비우면 시트 전체가 잠깁니다. 한 보호에 최대 20개입니다.
- 거부 메시지가 대상에 맞춰 바뀝니다. 시트 보호는 `이 시트는 보호되어 있습니다: <설명>` 로 알려 줍니다. 어떤 범위가 막았는지 되묻게 만들지 않기 위해서입니다.
- 행·열을 넣거나 지우면 **예외 범위도 함께 움직입니다.** 시트 보호 자체는 언제나 시트 전체를 덮으므로 구조가 바뀌어도 어긋나지 않습니다.
- 소유자와 보호를 만든 사람은 계속 자기 시트를 편집할 수 있습니다. 보호는 협업자로부터 모델을 지키는 장치이지 소유자를 잠그는 장치가 아닙니다.

REST와 MCP는 `scope:"sheet"` 와 `exceptions:["B3:B6"]` 를 받습니다.
