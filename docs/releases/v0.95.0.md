## 릴리즈 요약

v0.95.0은 **마우스 없이 쓸 때 걸리는 두 가지**를 고칩니다. 탭만으로 편집기를 돌아다녀 보다 찾았습니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 시트에 닿기까지 마흔 번

편집기를 열고 `Tab`을 누르면 상단 링크, 알림, 프로필, 메뉴 여덟 개, 공유 단추들, 도구 모음의 단추 서른 개를 차례로 지납니다. **시트에 닿기까지 마흔 번이 넘습니다.** 그 뒤 셀 하나를 고치고 다른 시트로 옮기려면 다시 처음부터입니다.

이제 `Tab`을 처음 누르면 **시트로 건너뛰기** 링크가 화면 왼쪽 위에 나타납니다. `Enter`를 누르면 곧바로 시트에 들어가고 방향키로 움직일 수 있습니다. 링크는 초점을 받았을 때만 보이므로 마우스로 쓰는 화면은 그대로입니다.

## 이름 없는 단추 둘

도구 모음의 **확대·축소** 단추에는 이름이 없었습니다. 아이콘만 있는 단추는 이름을 달아 주지 않으면 화면 낭독기에 그냥 "단추" 라고만 읽힙니다.

편집기와 대화상자의 조작 가능한 요소를 전부 훑어 이름 없는 것을 찾았고, 이 둘이 마지막이었습니다. 확대 배율 표시도 바뀔 때 읽히도록 했습니다.

## 확인만 하고 지나간 것

대화상자는 이미 제대로 동작했습니다. 열리면 초점이 안으로 들어가고, 여덟 번 탭해도 밖으로 새지 않으며, `Esc`로 닫으면 **열었던 단추로 초점이 돌아옵니다.** 돌려주지 않으면 키보드 사용자는 처음부터 다시 탭해야 하는데, 그렇지 않았습니다.

탭을 일흔 번 눌러 보는 동안 초점을 잃고 문서 바닥으로 떨어지는 자리도 없었습니다.

## 검증 결과

- 세 가지를 E2E로 남겼습니다. 첫 탭이 건너뛰기 링크에 닿고 `Enter` 뒤 방향키가 시트를 움직이는지, 도구 모음에 이름 없는 조작이 없는지, 대화상자가 초점을 붙들었다가 제자리로 돌려주는지 확인합니다.
- 고치기 전 번들에서 앞의 두 가지가 실패하는 것을 확인했습니다. 대화상자 시나리오는 원래 통과합니다.
- `go vet ./...`, `go test ./...`, React/Vitest 265개 테스트, TypeScript 타입 검사, Vite 프로덕션 빌드, Playwright E2E 151건을 통과했습니다.
