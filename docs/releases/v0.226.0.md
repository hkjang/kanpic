# v0.226.0

## 이미지 삽입

시트 위에 그림을 놓을 수 있습니다. 들어오는 길은 둘입니다.

- **삽입 → 이미지…** 로 파일을 고르기
- 화면을 캡처하고 격자에서 **Ctrl+V** — 클립보드에 그림이 있으면 글자가 아니라 그림이 들어갑니다

차트와 같은 층에 떠 있고, 머리띠를 끌면 옮기고 오른쪽 아래 모서리를 끌면 크기를
바꿉니다. 크기는 그림의 비율을 지킵니다 — 찌그러진 사진은 아무도 원하지 않습니다.
큰 사진은 너비 360px 에 맞춰 놓입니다. 4000px 사진이 격자를 다 덮고 들어오면 안
되기 때문입니다. 손으로 잡을 수 없을 만큼 작은 그림은 잡을 수 있는 크기로 키워
놓습니다 — 1×1 픽셀도 그림이지 거절할 실수가 아닙니다.

PNG·JPEG·GIF·WebP 를 받습니다.

## 이진 파일은 어디에 두는가

**Postgres 의 `bytea`** 입니다. 새 저장소 없이 백업과 함께 가고, 도커 이미지 하나로
돕니다. 오브젝트 스토리지가 필요해지는 크기까지 가려면 먼저 한도가 있어야 합니다.

| 한도 | 값 |
|---|---|
| 한 장 | `files.max_image_mb` (기본 5MB) |
| 워크북당 | 50장 |
| 화면 크기 | 16~4000px |

목록에는 바이트가 실리지 않습니다. 본체는 자기 주소 `/api/v1/images/{id}/content`
에서 옵니다.

## 그림이라서 지켜야 하는 것

- **종류는 파일 이름이 아니라 바이트에서 읽습니다.** `safe.png` 라는 이름의 SVG 는
  거절됩니다. 브라우저는 잘못 붙은 SVG 를 실행합니다.
- 본체는 올릴 때 읽은 종류 그대로, `X-Content-Type-Options: nosniff` 와
  `Content-Disposition: inline` 으로 나갑니다. 브라우저가 다시 추측하지 않고,
  내려받기 창이 뜨지 않고, 스크립트가 되지 않습니다.
- **워크북을 볼 수 없는 사람은 본체도 볼 수 없습니다.** 그림은 사진일 수 있습니다.
  이 앱의 인가 층은 자원 종류 표에 없는 것을 보호하지 못하므로, 그림을 그 표에
  올렸습니다 — 차트와 같은 권한 범위입니다.
- WebP 는 디코더 없이 RIFF 머리에서 크기만 읽습니다. 의존성을 더하지 않았습니다.

## 하지 않은 것

XLSX 로 내보내고 가져올 때 그림은 아직 따라가지 않습니다. 다음에 합니다.
