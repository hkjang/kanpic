## 릴리즈 요약

v0.30.0은 **방문자 추적**을 추가합니다. 관리자 콘솔에서 제공자를 고르고 식별자만 넣으면 모든 사용자 화면에 추적 자바스크립트가 삽입됩니다. kanpic이 보내는 엄격한 콘텐츠 보안 정책은 그대로 두고 **요청마다 새로 만드는 nonce**로 코드를 실행하므로, 정책을 느슨하게 만들지 않고 사내 분석 도구까지 붙일 수 있습니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 추적 코드 삽입

- 콘솔에 **방문자 추적** 화면이 생겼습니다. **Google Analytics 4**, **Google Tag Manager**, **Matomo(사내 설치)**, **직접 입력** 중에서 고릅니다.
- GA4와 GTM은 ID만 입력하면 로더와 초기화 코드를 자동으로 만듭니다. Matomo는 서버 주소와 사이트 ID만 넣으면 되고, 직접 입력은 사내 도구의 `<script>` 태그를 그대로 붙여 넣습니다(최대 8KB).
- 화면 아래 **미리보기**에 실제로 삽입될 코드가 그대로 나오고, **설정 확인**은 빠진 값이 있으면 어떤 키가 문제인지 알려 줍니다.
- 삽입 위치는 `head`가 기본이고 `body` 끝으로 바꿀 수 있습니다. 스위치를 끄면 코드도 허용 도메인도 응답에서 사라지므로, 제공자 설정을 지우지 않고 껐다 켤 수 있습니다.

## 보안 정책을 유지한 채 실행

- 페이지 응답마다 nonce를 새로 만들어 삽입한 `<script>`에 붙이고, 같은 nonce를 응답 헤더의 `script-src`에 넣습니다. `unsafe-inline` 없이 인라인 추적 코드가 실행됩니다.
- 붙여 넣은 코드에 이미 `nonce`가 있으면 손대지 않고, 없는 태그에만 붙입니다.
- 제공자에 따라 필요한 도메인이 정책에 자동으로 추가됩니다. GA4·GTM은 `googletagmanager.com`과 `google-analytics.com`, Matomo는 서버 주소에서 뽑아낸 원본입니다. 직접 입력한 코드가 접속하는 도메인은 **추가 허용 도메인**에 적습니다.
- 관리자 콘솔과 개인 설정 화면은 기본적으로 추적하지 않습니다. 콘솔 이용까지 집계하려면 **관리자 화면 포함**을 켭니다.

| 키 | 기본값 | 설명 |
| --- | --- | --- |
| `analytics.enabled` | `false` | 추적 코드 삽입 사용 |
| `analytics.provider` | `none` | `none`, `ga4`, `gtm`, `matomo`, `custom` |
| `analytics.measurement_id` | 빈 값 | GA4 측정 ID 또는 GTM 컨테이너 ID |
| `analytics.matomo_url` / `analytics.matomo_site_id` | 빈 값 | 자체 호스팅 Matomo 주소와 사이트 ID |
| `analytics.custom_snippet` | 빈 값 | 직접 입력하는 추적 코드 |
| `analytics.allowed_hosts` | 빈 값 | 직접 입력한 코드가 접속하는 도메인 |
| `analytics.include_admin` | `false` | 관리자·개인 설정 화면 포함 |
| `analytics.placement` | `head` | 삽입 위치 |

## 개선

- 콘솔의 설정 스위치가 서버 응답을 기다리지 않고 즉시 반영됩니다. 저장에 실패하면 이전 값으로 되돌리고 사유를 알려 줍니다. 방문자 추적과 알림 메일 화면에 함께 적용했습니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. 제공자별 생성 코드와 nonce 부착, 이미 nonce가 있는 코드의 중복 방지, 관리자 화면 제외, 제공자별 정책 도메인 도출, 설정 누락 검사를 확인합니다. HTTP 계층 테스트는 삽입된 코드의 nonce와 응답 헤더의 nonce가 일치하고 `unsafe-inline`이 없는지 검사합니다.
- React/Vitest 29개 테스트 파일, 133개 테스트를 통과했습니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 76건을 통과했습니다. 실제 브라우저에서 붙여 넣은 코드가 CSP 위반 없이 실행되는지, 콘솔 화면은 추적되지 않는지, 스위치를 끄면 응답에서 사라지는지 확인합니다.
