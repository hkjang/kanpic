## 릴리즈 요약

v0.23.1은 사용성을 막던 결함을 고칩니다. **한글 입력이 첫 글자부터 정상 조합**되고, **입력한 값이 사라지지 않으며**, 관리자 계정에서 **워크북 목록이 500 오류로 실패하던 문제**와 **프로필 메뉴에 관리자 콘솔이 보이지 않던 문제**를 해결했습니다.

필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나이며 새 마이그레이션은 없습니다.

## 관리자 계정의 워크북 목록 500 오류

- 관리자는 모든 워크북을 보므로 접근 권한 조건절을 건너뛰는데, 그 조건절만 사용하던 질의 매개변수는 그대로 전달되어 PostgreSQL이 `expected 0 arguments, got 3`으로 거절했습니다. `GET /api/v1/workbooks`와 `GET /api/v1/workbooks/trash`가 관리자에게만 500을 반환했고, 홈 화면이 비어 보였습니다.
- 조건절과 매개변수를 함께 구성하도록 고쳤습니다. 관리자·일반 사용자 모두, workspace 필터가 있든 없든 정상 동작합니다.
- 이 결함은 in-memory 저장소에는 존재하지 않아 기존 테스트가 잡지 못했습니다. `KANPIC_TEST_DSN`이 지정되면 실제 PostgreSQL로 실행되는 회귀 테스트를 추가했습니다.

## 한글 입력과 입력 손실

- 그리드는 이제 활성 셀 위치에 **입력 요소를 항상 유지**합니다. 예전에는 첫 키를 누른 뒤에야 입력창이 만들어져서, 입력기가 준비되기 전의 첫 글자가 영문 원본 키로 들어갔습니다. `안녕`을 입력하면 `dㅏ녕`이 되던 문제입니다.
- 조합 중 입력한 `Enter`는 조합만 확정하고 셀을 저장하지 않습니다.
- **입력을 마치고 `Tab`이나 `Enter`로 옮긴 셀에서 글자가 입력되지 않던 문제**를 고쳤습니다. 저장이 끝나기 전에 입력 요소가 사라져 초점이 사라졌던 것이 원인입니다. 이제 `Enter`와 `Tab`은 즉시 다음 셀로 이동하고 저장은 뒤에서 진행되므로, 빠르게 연속 입력해도 글자가 사라지지 않습니다.
- **입력 도중 다른 셀을 클릭하면 입력하던 값이 버려지던 문제**를 고쳤습니다. 이제 선택이 바뀌기 전에 저장합니다.
- 이름 상자나 빠른 이동으로 셀을 옮긴 뒤 키보드 초점이 사라져 입력이 되지 않던 문제도 고쳤습니다. 이동 후 초점은 그리드로 돌아옵니다.
- 셀을 편집하는 동안의 복사·잘라내기·붙여넣기는 셀 범위가 아니라 편집 중인 텍스트에 적용됩니다.

## 수식 입력창 편집

- 읽기 전용이던 `fx` 수식 입력창을 실제 편집기로 바꿨습니다. 클릭해서 값이나 수식을 고치고 `Enter`로 저장하면 아래 셀로 이동하며, `Esc`로 되돌립니다. 그리드 편집기와 같은 입력 내용을 공유합니다.

## 관리자 지정과 프로필 메뉴

- 콘솔에서 관리자 역할을 부여해도 프로필 메뉴에 **관리자 콘솔** 항목이 나타나지 않았습니다. 세션 응답의 관리자 판정이 IdP 토큰의 역할만 확인하고 kanpic 디렉터리 역할은 보지 않았기 때문입니다. 요청 권한 판정과 같은 기준을 사용하도록 맞췄습니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. `KANPIC_TEST_DSN`을 지정해 PostgreSQL 회귀 테스트 2건도 함께 실행했습니다.
- React/Vitest 27개 테스트 파일, 111개 테스트를 통과했습니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 62건을 통과했습니다. 실제 브라우저와 PostgreSQL에서 조합 입력으로 `안녕` 입력, `Tab`·`Enter` 이동 후 연속 입력, 편집 중 다른 셀 클릭 시 저장, 이름 상자 이동 후 입력과 단축키 동작, 수식 입력창 편집, 관리자 목록 조회와 프로필 메뉴의 관리자 콘솔을 확인했습니다.

## 업그레이드 참고

- 그리드에는 항상 숨겨진 입력 요소가 초점을 가집니다. 워크북 단축키는 셀을 편집 중일 때만 편집기가 우선하며, 그 외에는 이전과 동일하게 동작합니다.
