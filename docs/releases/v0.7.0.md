## 핵심 변경

- 시트별 행 높이와 열 너비를 희소 레이아웃으로 저장하고 Canvas 가상 축에 반영했습니다.
- 행·열 숨김/표시, 전체 표시 및 고정 행·열을 관리자 설정이 아닌 워크북 버전 상태로 관리합니다.
- 레이아웃 변경에 revision 낙관적 잠금, 멱등 키, 작업 로그 및 실시간 버전 알림을 적용했습니다.
- 행·열 삽입/삭제와 버전 복원 시 레이아웃 좌표도 함께 변환·복구합니다.
- REST `PATCH /api/v1/sheets/{sheetId}/layout:apply`와 MCP `spreadsheet.layout.apply`를 추가했습니다.

## 검증

- Go 단위 테스트와 PostgreSQL 통합 테스트 통과
- React/Vitest 38개 테스트와 프로덕션 빌드 통과
- Playwright 21개 브라우저 E2E 시나리오 통과
- 릴리즈 Docker 이미지 로드 후 `/api/v1/version`의 버전과 commit 일치 확인

## 업그레이드 참고

- 별도 데이터베이스 마이그레이션은 필요하지 않습니다. 레이아웃은 기존 `sheets.properties` JSONB에 하위 호환 방식으로 저장됩니다.
- 레이아웃이 없는 기존 시트는 기본 행 높이 27px, 열 너비 108px, 고정 없음으로 표시됩니다.
