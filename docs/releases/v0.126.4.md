## 릴리즈 요약

v0.126.4는 **CI가 `gofmt`를 확인하도록** 합니다. 이 세션에서 세 번 적어 두고 세 번 다 넘어간 자리입니다.

## 적어 두기만 하는 것도 안 하는 것이다

이번 세션의 릴리즈 노트에 "`gofmt`가 CI에서 확인되지 않아 파일 넷의 서식이 어긋나 있습니다"라고 세 번 적었습니다. 세 번 다 다음으로 미뤘습니다.

미뤄 두는 동안 실제로 방해가 됐습니다. 수식 엔진을 고칠 때마다 `gofmt -l`이 늘 이 네 파일을 함께 뱉었고, 그때마다 **내가 어긋뜨린 것인지 원래 그랬는지** 다시 확인해야 했습니다. 서식이 어긋난 파일은 다음에 누가 손댈 때 diff를 시끄럽게 만들어, 정작 무엇이 바뀌었는지 가립니다.

## 고친 것

```
internal/formula/functions_date.go
internal/workbook/model.go
internal/workbook/pivot.go
internal/workbook/template.go
```

바뀐 것은 모두 **구조체 필드 자리맞춤** 이라 셈은 그대로입니다.

CI에는 검사를 넣었습니다. 어긋난 파일이 있으면 이름과 함께 무엇이 다른지 보여주고 멈춥니다.

## 검증 결과

- 서식이 어긋난 코드를 일부러 넣어 검사가 잡아내는 것을 확인했습니다.
- `ci.yml`이 올바른 YAML인지 확인했습니다.
- Go 시험 전체가 통과합니다.
