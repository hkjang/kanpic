## 릴리즈 요약

v0.210.0은 부서를 거슬러 오르는 반복문에 **걸음 수** 를 둡니다. 주석이 코드보다 앞서 있었습니다.

## 적어 놓고 넣지 않았습니다

주석에는 이렇게 적혀 있었습니다.

```
// 고리가 생겨도 멈추도록 걸음 수를 제한한다.
```

제한은 없었습니다. 부모를 바꿀 때 자기 자손을 부모로 삼는 것은 이미 막고 있으므로 고리는 생기지 않아야 합니다. 그래도 걸음을 셉니다 — **그것 하나에 기대어 끝없이 도는 반복문** 을 두면 자료가 한 번 어긋났을 때 서버가 섭니다. 옆의 깊이·경로 계산도 같은 이유로 걸음을 세고 있었는데, 새로 쓴 것만 빠져 있었습니다.

고치다 `ok` 를 무조건 참으로 만들어 부모가 없는 경우에 빈 부서를 한 번 더 보게 만들었습니다. 반복문을 풀어 써서 조회 결과를 그대로 쓰게 했습니다.

## 검증 결과

- 세 겹 부서에서 위를 맡은 사람이 맨 아래 구성원을 보는지, 맡지 않은 사람에게는 아무것도 없는지 시험합니다.
- Go 시험 전체가 통과하고 `gofmt` 도 확인했으며, 브라우저 시험도 새 서버로 다시 돌렸습니다.
