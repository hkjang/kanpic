## 릴리즈 요약

v0.199.0은 지난 판 GROUPBY의 **묶음 차례** 를 고칩니다.

## 둘째 이름표가 아무렇게나 놓였습니다

차례를 **첫 이름표만** 보고 정했습니다. 이름표가 여러 칸이면 둘째 칸은 표에 적힌 차례대로 남습니다.

```
=GROUPBY(A1:B3, C1:C3, SUM)

관리  1분기
영업  2분기   ← 같은 부서 안에서 2분기가 1분기보다 앞
영업  1분기
```

부서로 묶고 분기로 다시 묶었으면 **분기도 차례가 있어야 합니다.** 앞 칸부터 차례로 견줍니다.

## 내림차순이 거울이 아니었습니다

`오름차순이 아니면 내림차순` 으로 흉내 내고 있었습니다. 그것은 오름차순을 뒤집은 것이 아니고, 견주기가 앞뒤가 맞지 않으면 정렬이 흔들릴 수 있습니다. 견줄 것을 서로 바꿔 **같은 규칙을 한 번만** 씁니다.

## 겉보기로는 멀쩡했습니다

이름표가 한 칸일 때는 첫 칸이 곧 전부이고, 묶음마다 이름표가 다르므로 흉내 낸 내림차순도 답이 맞았습니다. **이름표를 두 칸으로 묶어 보고서야** 드러났습니다.

## 검증 결과

- 오름차순이 두 칸을 다 보는지, 내림차순이 그것을 그대로 뒤집은 것인지, 숫자 이름표를 수로 세우는지 시험합니다.
- Go 시험 전체가 통과하고 `gofmt` 도 확인했습니다.
