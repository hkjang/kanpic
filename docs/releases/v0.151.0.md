## 릴리즈 요약

v0.151.0은 차트에 **값 표시와 세로축 범위** 를 더합니다. 구글 시트에 있는데 kanpic에 없던 둘입니다.

## 눈금을 짚어 읽지 않아도 됩니다

차트 설정에서 **막대와 점에 값 표시** 를 켜면 숫자가 그림에 적힙니다. 인쇄물이나 보고 자료에서 특히 그렇습니다.

소수는 **두 자리까지만** 적습니다. 자릿수가 길면 수고를 덜자는 것이 도리어 읽기 어려워집니다.

## 축 범위는 뜻을 가지고 정하는 것입니다

```
세로축 최소   40
세로축 최대   80
```

비워 두면 자료에 맞춥니다. 정하면 그대로 씁니다 — **0에서 시작하지 않으면 작은 차이가 크게 보이므로**, 그리는 쪽에서 자료에 맞춰 다시 정해 주면 사람이 정한 뜻이 사라집니다.

최대가 최소보다 작거나 같으면 눈금이 한 줄로 뭉개져 아무것도 읽을 수 없으므로 **저장할 때 막습니다.** 그래도 예전 자료가 뒤집혀 있을 수 있으므로, 그리는 쪽은 그릴 수 있는 범위를 내도록 했습니다.

두 설정 모두 **XLSX 로 내보낼 때 함께 나갑니다.** 화면에서 정한 것이 파일에서 사라지면 정한 뜻이 없습니다.

## 시험을 쓰며 만난 것

셀을 넣는 엔드포인트를 `POST` 로 적었습니다. `405` 가 조용히 무시되어 셀이 하나도 안 들어갔고, 화면에는 "표시할 숫자 데이터가 없습니다" 만 남아 **값 표시 기능이 안 되는 것처럼** 보였습니다. `PATCH` 로 고치니 바로 그려졌습니다.
