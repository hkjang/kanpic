## 릴리즈 요약

v0.191.0은 **붙여넣기와 데이터 정리가 같은 값을 같게** 읽도록 맞춥니다.

## 들어오는 길이 둘인데 규칙이 둘이었습니다

같은 글자가 칸에 들어오는 길은 둘입니다. 붙여넣기와, 이미 글자로 들어와 있는 것을 **데이터 정리** 로 고치는 것. 둘이 따로 적혀 있었고 서로 달랐습니다.

| 값 | 붙여넣기 | 데이터 정리 |
| --- | --- | --- |
| `(500)` | `-500` (서식 없음) | `(500)` |
| `₩5,000` | `"₩"#,##0` | `₩#,##0` |

**회계 표기의 괄호를 붙여넣기가 떼어 버렸습니다.** `(500)` 을 옮겼는데 `-500` 이 됩니다. 사람은 자기가 옮긴 표와 다른 것을 보게 됩니다. 데이터 정리는 괄호를 지키고 있었으므로, 같은 값이 **어느 길로 들어왔느냐** 에 따라 달라졌습니다.

서식 글자도 달랐습니다. 그리는 결과는 같지만 파일에 다른 글자가 남습니다. 기호를 따옴표로 묶는 쪽으로 모았습니다 — 엑셀 서식 말에서 따옴표 안은 언제나 그대로 적는 글자이므로 `$` 처럼 다른 뜻으로 읽힐 수 있는 기호도 안전합니다.

## 붙여넣기에는 자릿수 한도가 없었습니다

```
₩12345678901234567890  →  12345678901234567000
```

스무 자리는 계좌번호이지 금액이 아닙니다. 붙여넣은 사람이 보던 것과 **다른 값** 이 칸에 들어갑니다. 정리 쪽에는 v0.185.0에서 넣어 둔 한도를 여기에도 둡니다. 글자로 두면 적어도 그대로 남습니다.

## 검증 결과

- 두 길이 같은 값과 같은 서식을 내는지 시험으로 붙잡습니다. 고른 서식이 **실제로 그리는 글자** 가 원래 보이던 것과 같은지까지 봅니다.
- 웹 시험 449개와 Go 시험 전체, 브라우저 시험 34개가 통과합니다.
