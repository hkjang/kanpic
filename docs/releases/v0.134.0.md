## 릴리즈 요약

v0.134.0은 **AI 도우미가 조건부 서식을 만들 수 있게** 합니다. "매출 상위 10%에 색 칠해줘" 가 이제 됩니다.

## 색을 박아 넣는 것과 규칙을 만드는 것

에이전트가 쓸 수 있는 것은 **셀 쓰기·차트·보고서 시트** 뿐이었습니다. 그래서 조건을 말하는 요청도 셀마다 배경색을 박아 넣는 수밖에 없었습니다.

그렇게 칠하면 **자료가 바뀌어도 색은 어제 것으로 남습니다.** 숫자가 내려갔는데 아직 빨간 셀을 보고 사람이 판단하게 됩니다.

조건부 서식은 값에 따라 다시 칠합니다. 조건을 말하는 요청에는 이쪽이 맞습니다.

```
"매출 상위 10%에 색 칠해줘"
"음수는 빨갛게"
"목표 미달인 줄 표시해줘"
```

## 고른 범위 밖은 칠하지 않습니다

규칙이 칠하는 곳은 **사람이 고른 범위 안** 으로 묶었습니다. 고르지도 않은 곳이 물드는 것은 시킨 일이 아니고, 승인 화면에서도 눈에 잘 띄지 않습니다. 범위를 적지 않으면 고른 범위를 그대로 씁니다.

되돌리면 **규칙 자체가 지워집니다.** 규칙이 남아 있으면 셀은 제자리로 돌아왔는데 색만 남아, 되돌렸다는 말과 화면이 어긋납니다.

## 도구 하나를 붙인다는 것

여섯 군데를 손봐야 했습니다 — 모델에 알리기, 계획 검증, 실행, 검사, 되돌리기, 기억.

허용 목록이 **두 곳** 에 있었습니다. 한 곳만 고쳤더니 `unsupported workbook tool`로 막혔습니다. 실제 관문은 인수를 검증해 계획에 넣는 자리였습니다.

## 검증 결과

- 게이트웨이가 도구를 받아 인수를 그대로 싣는지 봅니다. 서식을 잃으면 규칙은 생기는데 색이 없습니다.
- 선택 밖 범위, 종류 없는 규칙, 범위 생략을 모두 확인합니다.
- 허용 목록에 없는 도구는 그대로 막힙니다.
- Go 시험 전체와 웹 시험 379개가 통과합니다.
