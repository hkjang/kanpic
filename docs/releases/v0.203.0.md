## 릴리즈 요약

v0.203.0은 **잠든 사용자와 워크북** 을 세어 보여 줍니다.

## 무엇이 잠들어 있는지 알 수 없었습니다

관리자 화면은 지금 있는 것을 잘 보여 주는데, **잠든 것** 은 알 수 없었습니다. 정리할지 남길지 정하려면 그것부터 보여야 합니다.

```
90일 넘게 들어오지 않은 계정
1년 이상 손대지 않은 워크북
```

## 한 번도 들어온 적 없는 계정도 셉니다

미리 등록해 두고 아무도 쓰지 않은 계정이 그대로 남는 일이 흔합니다. `마지막 접속이 없음` 을 빼고 세면 **그런 계정은 영영 목록에 나오지 않습니다.**

## 새 화면을 만들지 않았습니다

워크북은 거버넌스 화면의 거르개에 한 줄 더하고, 사용자는 목록에 켜고 끄는 것 하나를 두었습니다. 개요에서 수를 보고 목록으로 넘어가는 길은 이미 있던 것을 그대로 씁니다.

날 수는 서버와 화면 양쪽에 적혀 있습니다. 서로 다르면 개요에 적힌 수와 목록의 줄 수가 어긋나므로, 한쪽을 고치면 다른 쪽도 고쳐야 한다고 주석에 적어 두었습니다.

세는 기준 시각은 **한 번만** 읽습니다. 사용자와 워크북이 각자 시각을 읽으면 세는 도중에 날이 바뀔 때 수가 서로 어긋납니다.

## 검증 결과

- 한 번도 들어온 적 없는 계정을 세는지, 방금 만든 워크북이 잠든 것으로 나오지 않는지, 거르개 이름을 서버가 아는지 시험합니다.
- 브라우저에서 개요 → 목록으로 넘어가는 것과, 잠든 계정만 켜는 것까지 확인합니다.
- 웹 시험 457개와 Go 시험 전체가 통과하고 `gofmt` 도 확인했습니다.
