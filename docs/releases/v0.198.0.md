## 릴리즈 요약

v0.198.0은 **GROUPBY** 와 **PIVOTBY** 를 더합니다. 피벗 테이블을 만들지 않고 수식 하나로 집계합니다.

## 수식 하나로

```
=GROUPBY(A2:A100, B2:B100, SUM)            부서별 합계
=PIVOTBY(A2:A100, C2:C100, B2:B100, SUM)   부서 × 분기 합계
```

원본이 바뀌면 결과도 **따라 바뀝니다.** 피벗 테이블처럼 새로 고칠 것이 없습니다.

셋째(GROUPBY)와 넷째(PIVOTBY) 인수는 **함수 자체** 입니다. v0.197.0에서 이름만 적어도 넘길 수 있게 해 두었으므로 `SUM` 이라고만 적으면 됩니다.

## 없는 것과 0은 다릅니다

교차점에 자료가 없으면 **비워 둡니다.** `0` 을 적으면 "그만큼 팔았다" 는 뜻이 되어 없는 것과 구별되지 않습니다.

```
          1분기   2분기   총합계
영업1팀     125      50      175
영업2팀     200               200    ← 2분기에 자료가 없다
총합계      325      50      375
```

## 이어지는 선택 인수

`[머리글]` `[총계]` `[정렬]` 입니다. 머리글은 범위의 첫 줄이 이름 줄인지(기본 아니오), 총계는 `0` 이면 총합계 줄을 붙이지 않고(기본 붙임), 정렬은 `1` 오름차순·`-1` 내림차순·`0` 은 표에 적힌 차례 그대로입니다.

## 엑셀이 받는 것을 다 받지는 않습니다

`filter_array` 같은 자리는 없습니다. 받지 않는 자리에 값을 적으면 **조용히 다르게 셈하지 않고** 무엇까지 되는지 말합니다 — 엑셀에서 옮겨 온 수식이 말없이 다른 답을 내는 것이 가장 나쁩니다.

## 검증 결과

- 이름표별 집계, 총계·정렬 선택지, 이름과 `LAMBDA` 가 같은 답을 내는지, 자료 없는 교차점이 비어 있는지, 받지 않는 인수에 말을 하는지 시험합니다.
- 브라우저에서 칸에 실제로 펼쳐지는지와, 원본을 고치면 따라 바뀌는지까지 확인합니다.
- 웹 시험 457개와 Go 시험 전체가 통과하고 `gofmt` 도 확인했습니다.
