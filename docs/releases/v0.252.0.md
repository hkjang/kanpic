# v0.252.0

## Keycloak 에 로그인돼 있으면 로그인 화면 없이 들어갑니다

사내 앱을 여럿 오가는 사람은 Keycloak 에 이미 로그인돼 있는데도 kanpic 을 열 때마다
로그인 화면에서 단추를 한 번 더 눌러야 했습니다. kanpic 에는 사일런트 SSO 가
없었습니다. 이제 관리자가 `auth.oidc.auto_login` 을 켜면, 로그인하지 않은 브라우저가
화면을 열 때 SPA 가 `/auth/login?prompt=none` 으로 **최상위 이동**해 Keycloak 에
조용히 묻습니다. 세션이 있으면 인가 코드가 곧바로 돌아와 처음 열었던 경로로
들어가고, 없으면 Keycloak 이 화면을 그리지 않고 `login_required` 로 답하므로
콜백이 `/login?sso=none` 으로 보내 "회사 계정 세션이 없어 자동으로 로그인하지
않았습니다" 안내와 함께 로그인 화면을 보여 줍니다. 숨은 iframe 을 쓰지 않아
서드파티 쿠키가 막힌 브라우저에서도 되고, Keycloak 이 프레임을 허용하는지 신경
쓰지 않아도 됩니다.

되풀이를 막는 장치가 세 겹입니다 — 탭 세션당 한 번만 시도, 스스로 로그아웃한
뒤에는 시도하지 않음(다시 로그인하면 풀림), 거절당한 주소의 `sso=none` 표시.
브라우저 저장소를 읽지 못하는 사생활 보호 모드에서는 시도하지 않습니다.
`prompt=none` 은 브라우저가 청하지만 **관리자 설정만이 허락**합니다. 꺼져 있으면
주소에 붙어 와도 평범한 로그인으로 바꾸므로, 리다이렉트가 생기는 자리는 설정에만
묶입니다. 기본값은 꺼짐이라 켜기 전까지는 아무것도 달라지지 않습니다.

## 로그인 화면은 회사 계정이 문입니다

OIDC 를 켠 설치의 로그인 화면은 bootstrap 관리자 아이디·비밀번호 폼이 먼저 보이고
"조직 계정으로 로그인" 은 그 아래 보조 단추였습니다. 모두가 회사 계정으로 들어와야
하는 곳에서 관리자 폼이 앞에 있으면 사람들이 거기에 회사 비밀번호를 넣습니다.
appstore 의 로그인 창과 같은 배치로 바꿨습니다 — **회사 계정으로 SSO 로그인**이
첫 단추이고, bootstrap 관리자는 그 아래 **관리자 계정으로 로그인**을 눌러야 펼쳐지며
"SSO 를 사용할 수 없을 때를 위한 복구용 관리자 계정입니다" 라고 적혀 있습니다.
OIDC 가 없는 설치는 전과 같이 관리자 폼이 바로 보입니다.

  평범한 로그인, 거절 뒤 돌아갈 주소는 같은 오리진 경로만
- `internal/integration/postgres_test.go` — 조용한 시도의 거절 콜백이 트랜잭션을
  한 번만 소비하고 조용했음을 알림(마이그레이션 044)
- `web/src/lib/silent-sso.test.ts` — 설정이 켜졌을 때만, 탭당 한 번, 로그아웃 뒤
  중지, `sso=none` 존중, 로그인 화면·`/api`·`/auth`·`/mcp` 제외, 저장소 불가
  시 시도하지 않음, 같은 오리진 경로만 돌아감
- 실제 서버를 띄워 로그인 화면·관리자 폼 펼치기·`sso=none` 안내를 눈으로 확인하고,
  로그인하지 않은 채 워크북을 열면 `/auth/login?prompt=none&return_to=…` 로 한 번만
  나가는 것을 확인했습니다

`gofmt`·`go vet`·`go build`·`go test ./...`, 통합 테스트, `npm run lint`·`npm test`·
`npm run build`, `scripts/check-release-docs.sh` 를 돌렸습니다.
