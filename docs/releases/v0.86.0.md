## 릴리즈 요약

v0.86.0은 지난 릴리즈에서 행 한도를 20만으로 올리며 드러난 **행 머리글 잘림**을 고칩니다. 큰 파일 가져오기는 함께 점검했고 문제가 없었습니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 가져오기는 괜찮았습니다

15만 행 × 3열짜리 CSV(3.5MB)를 만들어 올려 봤습니다.

| 항목 | 값 |
| --- | --- |
| 가져오기 시간 | 2.5초 |
| 들어온 셀 | 450,003개 |
| 마지막 행 | 150,001 (머리글 + 15만 행) |
| 워크북 열기 | 2.7초 |
| 15만 행으로 이동 | 0.9초 |

잘린 곳도, 빠진 행도 없었습니다. 가져오기 한도는 100만 셀·업로드 20MB로 넉넉합니다.

## 잘려 나가던 행 번호

다만 15만 행 시트를 내려가 보니 행 머리글의 **번호 앞자리가 잘려 있었습니다.** `149981` 이 `49981` 처럼 보입니다. 머리글 폭 46px는 다섯 자리까지만 담습니다. 지난 릴리즈 전에는 행이 만 개뿐이라 드러나지 않던 문제입니다.

이제 머리글은 **그 자리에 보이는 가장 큰 행 번호의 자릿수** 에 맞춰 넓어집니다. 네 자리까지는 예전 폭 그대로라 작은 시트에서 자리를 낭비하지 않고, 확대하면 넓어지는 폭도 함께 커집니다.

폭을 시트 전체의 행 수가 아니라 **보이는 범위** 로 정한 이유는, 20만 행짜리 시트라도 위쪽에서 일할 때는 좁은 머리글이 맞기 때문입니다.

## 검증 결과

- 15만 행 시트의 맨 아래와 맨 위를 각각 찍어 확인했습니다. 아래에서는 여섯 자리가 온전히 보이고, 위로 돌아오면 머리글이 다시 좁아집니다.
- 폭 계산을 순수 함수로 떼어 내 단위 테스트를 붙였습니다. 네 자리까지 기본 폭, 자릿수마다 한 칸씩, 확대에 비례.
- `go vet ./...`, `go test ./...`, `go test -tags integration ./internal/...`, React/Vitest 259개 테스트, TypeScript 타입 검사, Vite 프로덕션 빌드, Playwright E2E 144건을 통과했습니다.
