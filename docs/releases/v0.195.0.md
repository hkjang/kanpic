## 릴리즈 요약

v0.195.0은 **표 검사** 를 더합니다. 만들어 둔 정리 도구를 사람이 찾지 않아도 되게 합니다.

## 도구는 여섯 개인데 아무도 열어 보지 않습니다

중복, 공백, 글자로 담긴 숫자, 병합 해제, 부분합 제거, 열 분할. 그런데 사람이 **데이터 정리** 를 열어 볼 생각을 해야 알 수 있습니다.

**무엇이 잘못됐는지 모르는 채로 열어 보는 사람은 없습니다.** 합계가 이상한데 이유를 모르는 사람은 수식을 들여다보지 도구 목록을 뒤지지 않습니다. 표를 보고 먼저 말해 주는 쪽이 맞습니다.

## 데이터 › 데이터 정리 › 표 검사…

```
△ 글자로 담긴 숫자   12칸    =SUM 이 이 칸들을 빼고 셈합니다
△ 병합된 칸           3곳    정렬도 피벗도 되지 않습니다
△ 중복된 행           2행    세어 보기 전에는 합계가 맞는지 알 수 없습니다
  앞뒤·가운데 공백    7칸    눈에 보이지 않지만 견주기에서는 다른 값입니다
```

**셈이 달라지는 것을 앞에 놓습니다.** 합계가 틀리는 것과 눈에만 거슬리는 것은 급한 정도가 다르므로 `△` 로 갈라 적습니다.

각 줄에서 **바로 그 갈래의 미리보기로** 넘어갑니다. 검사에서 고치기까지 한 걸음이 아니면 검사한 보람이 없습니다.

## 검사는 아무것도 바꾸지 않습니다

세기만 합니다. 중복 행을 지우는 일 같은 것은 되돌리기 어려우므로, 무엇을 고칠지는 사람이 미리보기를 보고 정합니다.

## 검증 결과

- 깨끗한 표에는 아무 말도 하지 않는지, 세는 수가 맞는지, 셈이 달라지는 것이 앞에 오는지, **훑은 뒤 시트가 그대로인지** 따로 시험합니다.
- 브라우저에서 검사 → 고치기 → 값이 실제로 바뀌는 데까지 확인합니다.
- 웹 시험 457개와 Go 시험 전체가 통과합니다.
