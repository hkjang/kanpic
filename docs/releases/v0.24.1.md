## 릴리즈 요약

v0.24.1은 메뉴 조작과 서식을 다듬습니다. `>` 하위 메뉴가 **부모 메뉴 안에서 스크롤되지 않고 옆으로 펼쳐지며**, 도구 모음에 **테이블 서식** 과 **테두리** 아이콘이 생겼습니다. 드래그로 차트를 옮길 때 발생하던 **400 오류**도 고쳤습니다.

필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나이며 새 마이그레이션은 없습니다.

## 하위 메뉴가 옆으로 펼쳐집니다

- 하위 메뉴는 스크롤되는 부모 목록 안에 그려져 잘리고, 항목을 고르려면 부모 메뉴를 스크롤해야 했습니다. 이제 하위 메뉴는 별도 레이어에 그려져 **부모 메뉴 오른쪽에 펼쳐지고**, 오른쪽에 공간이 없으면 왼쪽으로, 아래로 넘칠 때는 위로 올려 배치합니다.
- 마우스를 올리면 바로 열립니다. 클릭해서 닫히지 않으며 다른 항목으로 옮기면 닫힙니다.
- 키보드로 `→`를 누르면 하위 메뉴로 들어가 방향키로 고를 수 있고 `←`로 부모 메뉴로 돌아옵니다.
- 메뉴 막대에서 메뉴를 열면 키보드 초점이 **메뉴 목록** 으로 옮겨집니다. 이전에는 초점이 메뉴 버튼에 남아 방향키가 항목 대신 옆 메뉴로 이동했습니다. 하위 메뉴가 닫힌 상태의 `←`·`→`는 이전처럼 옆 메뉴로 이동합니다.

## 테이블 서식

- 도구 모음의 셀 병합 아이콘 오른쪽에 **테이블 서식** 아이콘을 추가했습니다. 청록·파랑·회색·주황·테두리만 다섯 가지 중 하나를 고르면 머리글 행, 줄무늬 행, 바깥쪽 굵은 테두리와 안쪽 연한 선이 한 번의 작업으로 적용됩니다.
- 셀 하나만 선택하면 주변 데이터 블록 전체가 대상이고, 적용될 범위를 메뉴 상단에 표시합니다.
- **옵션** 하위 메뉴에서 머리글 행, 줄무늬 행, 테두리, 합계 행 강조를 켜고 끕니다.
- 값·수식·표시 형식은 그대로 유지되고, **테이블 서식 지우기** 는 색과 테두리만 제거합니다.
- 서식 메뉴에도 같은 항목이 있습니다.

## 테두리 그리기

- **테두리** 아이콘에서 모든 테두리, 바깥쪽, 안쪽, 위·아래·왼쪽·오른쪽, 안쪽 가로·세로를 바로 그립니다. **선 색** 하위 메뉴로 색을 고르고 **테두리 지우기** 로 지웁니다. 선 종류까지 지정하려면 **테두리 설정…** 을 사용합니다.
- 테두리만 바꿀 때는 셀 스타일 패치를 함께 보내지 않으므로, 기존 서식이 그대로 유지됩니다.

## 차트 이동 400 오류 수정

- 차트를 드래그하면 `PATCH /api/v1/charts/{id}` 가 `invalid_json` 400을 반환하고 차트가 원래 자리로 돌아갔습니다. 브라우저는 확대·축소나 고밀도 디스플레이에서 포인터 좌표를 소수로 보고하는데, 차트 위치는 정수만 받았기 때문입니다.
- 서버가 소수 좌표를 반올림해 받아들이고, 편집기도 좌표를 정수로 보냅니다. 다른 클라이언트나 에이전트가 소수를 보내도 동작합니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. 소수 좌표를 반올림하고 좌표가 아닌 값은 계속 거절하는지 확인합니다.
- React/Vitest 29개 테스트 파일, 128개 테스트를 통과했습니다. 하위 메뉴 배치 계산과 테이블 서식 셀 생성에 대한 단위 테스트를 추가했습니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 66건을 통과했습니다. 실제 브라우저와 PostgreSQL에서 하위 메뉴가 부모 밖에 스크롤 없이 열리는지, 키보드로 들어가고 나오는지, 테이블 서식과 테두리가 값을 유지하며 적용되는지, 소수 좌표로 차트를 드래그해도 위치가 저장되는지 확인했습니다.
