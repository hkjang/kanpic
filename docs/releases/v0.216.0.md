# v0.216.0

## 서버에 아직 닿지 않은 편집이 몇 건인지 보여 준다

저장 배지는 두 가지만 알았습니다. `저장 중…` 과 `오프라인 · 로컬 저장`.

세 건이 밀렸는지 삼백 건이 밀렸는지는 어디에도 없었습니다. 지하철에서 삼십 분
편집하고 올라온 사람은, 배지가 언제 `모든 변경사항 저장됨` 으로 바뀔지만 보며
기다릴 뿐 얼마나 남았는지 알 수 없었습니다.

이제 이 워크북에서 아직 서버에 닿지 않은 편집 수를 함께 냅니다.

> `오프라인 · 로컬 저장 · 12건 대기`

다 나가면 숫자는 사라집니다.

## 밀린 편집을 두고 창을 닫으려 하면 묻는다

브라우저 안의 저장 큐는 창을 닫아도 남습니다. 잃지는 않습니다. 다만 **그 워크북을
다시 열기 전까지는** 서버로 나가지 못합니다. 다시 열지 않으면 그대로 남습니다.

그래서 닫기 전에 한 번 묻습니다. 다만 곧 나갈 저장까지 붙잡으면 매번 성가시기만
하므로, **연결이 끊겼거나 이미 멈춘 것이 있을 때만** 묻습니다.
