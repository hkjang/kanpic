## 릴리즈 요약

v0.154.0은 동적 배열 함수에서 **비어 있던 세 자리** 를 채웁니다. `WRAPROWS`, `WRAPCOLS`, `EXPAND` 입니다.

## 한 줄을 접어 표로 만듭니다

`TOCOL`, `TOROW`, `VSTACK`, `HSTACK`, `TAKE`, `DROP`, `CHOOSEROWS`, `CHOOSECOLS` 는 이미 있었습니다. 펼치고, 이어 붙이고, 골라내는 것은 되는데 **접는 것만** 없었습니다.

```
=WRAPROWS(A1:A12,4)   12개를 4개씩 세 행으로
=WRAPCOLS(A1:A12,4)   같은 것을 열 쪽으로
=EXPAND(A1:B2,3,3,0)  배열을 넓히고 빈 자리를 0으로
```

접을 것이 **이미 두 줄 이상이면 막습니다.** 무엇을 어떤 차례로 읽었는지 사람이 알 수 없기 때문입니다. 한 줄 길이가 1보다 작으면 `#NUM!` 입니다.

`EXPAND` 는 넓히는 함수이므로 지금보다 작게 적으면 `#VALUE!` 입니다. 조용히 잘라 내면 사라진 자료를 아무도 알아채지 못합니다. 줄이는 것은 `TAKE` 가 합니다.

## 빈 자리를 무엇으로 채우는가

채울 값을 적지 않으면 **빈 칸** 입니다. 구글 시트와 엑셀은 `#N/A` 를 채웁니다. kanpic 에서 오류는 **칸 하나가 통째로 가지는 것** 이라 배열 안에 담을 자리가 없습니다.

`#N/A` 처럼 보이는 글자를 넣을 수도 있었습니다. 화면으로는 같아 보이지만 `=ISNA` 가 거짓이 되고 `=IFNA` 가 걸러 주지 않습니다. **보기에 맞추자고 뜻을 틀리게 하지는 않습니다.** 채울 값을 적으면 그것으로 채웁니다.

## 파일로 나가고 들어옵니다

셋 다 엑셀에서도 같은 이름입니다. 내보낼 때 `_xlfn` 이 붙고 가져올 때 벗겨집니다.

## 검증 결과

- 접기: 남는 자리가 있는 경우, 딱 맞는 경우, 행 쪽과 열 쪽을 모두 확인합니다.
- 막는 경우: 두 줄을 접을 때, 한 줄 길이가 0일 때, `EXPAND` 가 작아질 때.
- 채우지 않은 자리가 `=ISBLANK` 로 참인지 확인합니다.
- 이름이 `_xlfn` 을 달고 나갔다 그대로 돌아오는지 확인합니다.
- Go 시험 전체가 통과합니다.
