## 릴리즈 요약

v0.208.0은 관리자 계정을 **부서 관리자 목록에서도** 뺍니다. v0.207.0에서 절반만 막았습니다.

## 막았다고 적어 놓고 절반만 막았습니다

```
GET /admin/users/{관리자}   403
GET /admin/users            목록에 그 관리자가 역할까지 함께 보임
```

한 사람을 열어 보는 것은 막았고 **목록은 그대로 두었습니다.** 열어 보면 막히는데 목록에는 보이면, 관리자 명단을 훑는 것은 그대로 되는 셈입니다.

## 같은 규칙을 나눠 씁니다

목록을 거를 때와 한 사람을 볼 때가 **같은 규칙** 을 쓰게 했습니다. 두 곳에 따로 적어 두면 이번처럼 한쪽만 고치고 다 고쳤다고 여깁니다.

## 검증 결과

- 구성원이 관리자로 올라간 뒤 목록에서 사라지는지 시험합니다.
- Go 시험 전체가 통과하고 `gofmt` 도 확인했으며, 브라우저 시험도 새 서버로 다시 돌렸습니다.
