## 릴리즈 요약

v0.71.0은 **차트를 XLSX로 내보냅니다.** 지금까지 내보낸 워크북에는 차트가 없었습니다. 보고서를 파일로 넘기면 표만 남고 그림은 사라졌습니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 나가는 차트

막대, 누적 막대, 선, 영역, 누적 영역, 원형, 분산이 각각 대응하는 엑셀 차트로 나갑니다. **혼합 차트**는 엑셀에서도 막대와 선을 겹친 하나의 차트가 됩니다.

차트는 **원본 셀 범위를 가리킵니다.** 그림을 찍어 붙이는 것이 아니라 `'Sheet1'!$B$2:$B$4` 같은 참조로 나가므로, 받은 사람이 엑셀에서 값을 고치면 차트도 따라 바뀝니다. 제목, 축 제목, 범례 위치도 함께 갑니다.

히스토그램은 빠집니다. kanpic이 구간을 직접 계산해 그리는 차트라 엑셀에 대응이 없고, 다른 차트로 바꾸면 다른 그림이 됩니다.

차트 위치는 셀 기준으로 근사합니다. 엑셀에는 픽셀 위치라는 것이 없어 저장된 좌표를 기본 행 높이·열 너비로 나눠 가장 가까운 셀에 붙입니다.

## 아직 안 되는 것

**엑셀 차트를 읽어 오는 방향은 아직입니다.** 사용 중인 XLSX 라이브러리에 차트를 쓰는 기능은 있고 읽는 기능은 없어, 가져오기는 별도 작업이 필요합니다. 지금은 내보내기만 된다는 점을 분명히 적어 둡니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. 새 테스트는 내보낸 파일의 압축을 풀어 `xl/charts/chart1.xml` 이 존재하는지, 막대 차트인지, 계열이 `$B$2:$B$3`, 항목이 `$A$2:$A$3` 을 가리키는지, 제목이 들어 있는지 확인합니다. 라이브러리가 차트를 읽지 못하므로 파일 자체를 봅니다.
- 실제 서버에서 막대 차트와 혼합 차트를 만들어 내보냈습니다. `chart1.xml` 은 `barChart` 와 제목 `분기 매출`, `chart2.xml` 은 `barChart` 와 `lineChart` 를 함께 담고 매출(`$B$2:$B$4`)과 이익률(`$D$2:$D$4`)을 각각 가리킵니다.
- React/Vitest 234개 테스트, TypeScript 타입 검사, Vite 프로덕션 빌드, Playwright E2E 130건을 통과했습니다.
