## 릴리즈 요약

v0.204.0은 **사용자 일괄 등록(CSV)** 을 더합니다. 팀 하나를 들이려고 스무 번 누르는 일을 없앱니다.

## 머리글 줄을 요구합니다

자리로 읽으면 열 차례가 다른 파일을 말없이 엉뚱하게 읽어, **이름 칸에 이메일이 들어간 사용자가 스무 명** 생깁니다.

`user_id`(필수) · `display_name` · `email` · `note` 를 읽고, `사용자 ID` · `이름` · `이메일` · `메모` 로 적어도 됩니다 — 한글로 적어 오는 것이 보통입니다.

## 먼저 미리 보여 줍니다

```
새로 만듦 1 · 갱신 1 · 건너뜀 1
```

새로 만들 사람, **이미 있어 정보만 갱신될 사람**, 건너뛸 줄을 줄마다 알려 줍니다. 사람을 여럿 만드는 일은 되돌리기 번거롭고, 이미 있는 사람의 이름을 덮어쓰는 것은 더 그렇습니다. "새로 만듭니다" 라고 해 놓고 기존 사용자를 덮어쓰면 사람은 무슨 일이 났는지 모릅니다.

미리보기와 실제 등록이 **같은 코드로** 읽습니다. 따로 읽으면 미리보기에서 본 것과 실제로 만들어지는 것이 달라집니다 — 사람은 미리보기를 믿고 누릅니다.

## 조용히 덮어쓰지 않습니다

- **같은 파일 안에 같은 아이디가 두 번** 나오면 뒤엣것으로 덮어쓰지 않고 몇 번째 줄과 겹치는지 짚어 줍니다. 어느 줄이 맞는지는 사람이 정해야 합니다.
- 한 줄이 잘못돼도 나머지를 버리지 않고, 무엇이 들어갔고 무엇이 안 들어갔는지 줄마다 돌려줍니다.

역할과 부서는 등록한 뒤 사용자별로 지정합니다.

## 검증 결과

- 머리글이 없거나 빈 파일을 물리치는지, 한글 머리글을 읽는지, 겹친 줄을 짚는지, **미리보기가 아무것도 만들지 않는지** 시험합니다.
- 브라우저에서 미리보기 수와, 등록 뒤 실제로 만들어지고 갱신되는지까지 확인합니다.
- 웹 시험 457개와 Go 시험 전체가 통과하고 `gofmt` 도 확인했습니다.
