## 릴리즈 요약

v0.24.0은 **템플릿 30종**을 추가합니다. 빠른 시작의 템플릿 카드는 그동안 제목만 붙은 빈 워크북을 만들었지만, 이제는 표 머리글과 예시 데이터, 계산되는 수식, 통화·백분율 서식, 열 너비, 머리글 고정까지 갖춘 워크북이 바로 열립니다. 긴 텍스트가 셀 안에서 찌그러지던 렌더링 문제도 함께 고쳤습니다.

필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나이며 새 마이그레이션은 없습니다.

## 템플릿 갤러리

- 홈 화면 **빠른 시작** 에 추천 템플릿 3종이 실제 내용과 함께 표시되고, **템플릿 갤러리** 에서 30종 전체를 분류와 검색으로 고를 수 있습니다.
- 카드에는 템플릿이 시작하는 열 목록이 함께 보이므로 열어 보지 않고도 고를 수 있습니다.
- 갤러리는 다른 대화상자와 같은 규칙을 따릅니다. `Esc`로 닫고, 포커스가 창 안에서 순환하며, 닫으면 열었던 버튼으로 포커스가 돌아갑니다.

| --- | --- |
| 재무·회계 | 월간 손익계산서, 현금흐름 관리, 예산 대비 실적, 거래명세서, 견적서, 경비 정산서 |
| 영업·마케팅 | 영업 파이프라인, 고객 관리 대장, 마케팅 캠페인 성과, 월간 매출 분석, KPI 대시보드 |
| 프로젝트 | 프로젝트 현황, 프로젝트 일정표, 업무 요청 관리, 회의록, 리스크 관리 대장 |
| 인사 | 근태 관리, 급여 대장, 채용 진행 현황, 사원 명부, 교육 이수 관리 |

| 개인·기타 | 가계부, 주간 플래너, 학습 계획표, 행사 준비 체크리스트 |

## 템플릿에 들어 있는 것

- **계산되는 수식**: 재고 관리는 `기초+입고-출고`로 현재고를 구하고 재주문점 이하이면 상태에 재주문을 표시합니다. 거래명세서는 수량과 단가에서 공급가액·부가세·합계를, 영업 파이프라인은 예상 금액과 확률로 가중 금액을, 리스크 관리 대장은 가능성×영향도로 위험도와 등급을 계산합니다.
- **집계 요약**: 표 아래에 합계 행과 함께 승인 금액, 재주문 품목 수, 합격률, 평균 달성률 같은 요약이 `SUMIF`·`COUNTIF`·`INDEX`/`MATCH`로 계산됩니다.
- **서식과 레이아웃**: 통화(`₩#,##0`), 백분율, 날짜 표시 형식과 머리글 배경색, 열 너비, 머리글 행 고정이 적용된 상태로 열립니다.
- 템플릿은 kanpic 수식 엔진이 실제로 지원하는 함수만 사용합니다. 새 워크북이 `#NAME?`을 띄우는 일이 없도록 30종 전부를 대상으로 검사하는 테스트를 두었습니다.

## 긴 텍스트 렌더링 수정

- 셀보다 긴 텍스트가 셀 너비에 맞춰 글자가 눌려 찌그러지던 문제를 고쳤습니다. 이제 오른쪽(오른쪽 정렬은 왼쪽, 가운데 정렬은 양쪽)의 **빈 셀로 흘러넘치고 내용이 있는 셀에서 잘립니다.** 일반적인 스프레드시트와 같은 동작입니다.

## REST API와 MCP

```http
GET  /api/v1/templates
POST /api/v1/workbooks   {"template_id":"inventory"}
```

- `GET /api/v1/templates`는 로그인한 사용자면 호출할 수 있고 id, 이름, 분류, 설명, 시작 열, 시트 이름을 반환합니다.
- `POST /api/v1/workbooks`에 `template_id`를 넣으면 제목을 생략해도 템플릿 이름으로 만들어집니다.
- 에이전트용으로 `spreadsheet.template.list` 도구를 추가하고 `spreadsheet.workbook.create`에 `template_id` 인자를 더했습니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. 템플릿 30종을 모두 적용해 수식이 오류 코드 없이 계산되는지, 지원하지 않는 함수를 쓰지 않는지, 거래명세서 합계가 손으로 계산한 39,490,000과 일치하는지 확인합니다.
- React/Vitest 28개 테스트 파일, 117개 테스트를 통과했습니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 63건을 통과했습니다. 실제 브라우저와 PostgreSQL에서 갤러리 목록·분류·검색, 템플릿으로 워크북 생성, 열린 워크북의 계산된 합계와 통화 서식, 머리글 고정을 확인했습니다.
