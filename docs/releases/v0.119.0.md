## 릴리즈 요약

v0.119.0은 **목표값 찾기** 를 넣습니다. 스프레드시트는 대개 앞으로 계산하려고 만들지만, 정작 묻고 싶은 것은 거꾸로인 경우가 많습니다 — 상환액을 정해 놓고 이자율을 되묻는 식입니다.

마이그레이션은 없습니다.

## 거꾸로 묻기

**데이터 › 목표값 찾기…** 에 세 가지를 적습니다: 원하는 값이 되어야 할 **수식 셀**, 그 **찾는 값**, 대신 움직일 **바꿀 셀**.

| | |
| :--- | :--- |
| 수식 셀 | `B4` (`=PMT(B2/12,B3,-B1)`) |
| 찾는 값 | `900000` |
| 바꿀 셀 | `B2` (연이자율) |

1억을 120개월에 걸쳐 갚을 때 월 상환액이 900,000이 되려면 연이자율은 **1.547%** 여야 합니다. 다섯 번 계산해 찾습니다.

수식 사슬을 따라갑니다. 바꿀 셀을 직접 참조하지 않고 중간 계산을 여러 번 거쳐도 되고, 다른 시트를 참조하는 수식도 함께 계산합니다 — 워크북 전체를 읽는 이유가 그것입니다. 요청한 시트만 읽으면 다른 시트의 값이 빈 칸으로 계산되어 **틀린 답을 자신 있게** 내놓게 됩니다.

## 답이 없으면 없다고 말한다

되짚어 찾는 것은 대수가 아니라 수치 탐색입니다. 값을 바꿔 가며 최대 100번 다시 계산해 목표에 다가갑니다. 그러니 실패할 수 있습니다.

실패했을 때 마지막으로 시도한 숫자를 답인 척 내미는 것이 가장 나쁜 답입니다. 그래서 이렇게 나눕니다.

| 상황 | 답 |
| :--- | :--- |
| 제곱을 음수로 만들라는 물음 | 목표에 이르지 못했습니다 (가장 가까운 값과 함께) |
| 값이 더 이상 움직이지 않음 | 그렇다고 말하고 멈춤 |
| 100번을 넘김 | 몇 번 계산했는지와 함께 말함 |
| 바꿀 셀에 수식이 있음 | **거절.** 값을 넣는 순간 그 수식이 사라집니다 |
| 수식 셀이 바꿀 셀의 영향을 받지 않음 | **거절.** 계산해 보기 전에 알 수 있습니다 |
| 수식 셀이 숫자가 아님 | **거절** |

마지막 두 가지는 백 번 돌려 보고 포기하는 것이 아니라, 물어보는 순간 답할 수 있는 것들입니다.

## 찾기와 넣기는 다른 일이다

**찾기** 는 아무것도 쓰지 않습니다. 답과 지금 값이 나란히 보이고, 얼마나 움직이는지 본 다음에 **값 넣기** 를 누릅니다. 넣는 것은 보통의 셀 편집이라 실행 취소도 됩니다.

권한도 그렇게 나뉩니다. 찾기는 읽기 권한이면 되고 — 워크북을 바꾸지 않으므로 — 넣기는 편집 권한을 씁니다.

## 데이터 메뉴가 화면을 넘겼다

항목을 하나 더하면서 **데이터** 메뉴가 1280×800 화면에서 4픽셀 넘쳤습니다. 넘치면 아래쪽 항목이 스크롤 뒤로 숨습니다. 항목을 더할 때마다 조금씩 다가가다가 어느 날 넘어가고, 그때 무엇이 밀려났는지는 아무도 모릅니다.

프레젠테이션 두 항목을 하위 메뉴로 묶어 한 줄로 줄였고(539px, 딱 맞음), **넘치면 걸리는 시험** 을 넣었습니다.

## 알려진 한계

- 답이 여럿인 수식(예: 제곱근이 둘)에서는 시작점에 가까운 쪽 하나만 찾습니다. 엑셀도 같습니다.
- 아직 MCP 도구로는 열지 않았습니다.
- 한 번에 5만 셀까지 읽습니다. 100번 다시 계산하므로 그보다 큰 워크북은 대화 상자에서 기다릴 일이 아닙니다.

## 검증 결과

- 실제 대출 모형(`PMT`)에서 이자율을 되찾고, 손으로 계산한 값과 맞는지 확인했습니다.
- 수식이 사슬로 이어진 경우와 비선형(`x³ = 1000` → 10)도 풉니다.
- 답이 없는 물음, 움직이지 않는 대상, 수식이 든 바꿀 셀, 같은 셀을 두 번, 숫자가 아닌 결과를 각각 시험합니다.
- 브라우저 E2E로 찾기가 **아무것도 쓰지 않는지** 확인한 뒤 값 넣기로 실제 셀이 바뀌는지 봅니다. 실패한 경우에는 **값 넣기 단추가 아예 없는지** 도 봅니다.
- 데이터 메뉴가 화면을 넘기지 않는지 브라우저에서 재어 봅니다.
- `go vet ./...`, `go test ./...`, PostgreSQL 통합 테스트, React/Vitest, TypeScript 타입 검사, Vite 프로덕션 빌드, Playwright E2E를 통과했습니다.
