## 릴리즈 요약

v0.211.0은 **관리자 콘솔에서 한 일** 을 기록으로 남깁니다.

## 나눠 주고 보지 못했습니다

계정 정지, 역할 부여, 소유권 이전은 사람에게 영향을 줍니다. 그런데 누가 언제 했는지가 **어디에도 남지 않았습니다.**

부서 관리자에게 권한을 나눠 준 뒤로는 더 그렇습니다. **나눠 주고 무엇을 했는지 볼 수 없으면 위임이 아니라 방치입니다.** 위임(v0.205.0)을 만들면서 그 짝을 빠뜨렸습니다.

## 무엇이 남는가

```
admin.action user.status
{"actor":"lead.kim","target":"team.park","status":"suspended","scope":"department"}
```

- `actor` — **누가** 했는지
- `scope` — **전역 관리자였는지 위임받은 부서 관리자였는지**. 감사에서 먼저 묻는 것이 "이 사람이 그럴 권한이 있었는가" 입니다.

남는 것: 계정 등록·정지·수정, 역할 부여·회수, 세션 종료, 사용자 일괄 등록, 워크북 소유권 이전(하나씩·일괄), 부서 관리자 지정·해제.

## 새 저장소를 만들지 않았습니다

서버 로그가 이미 PostgreSQL에 쌓이고, 기간으로 거를 수 있고, CSV로 나갑니다 — 감사에서 달라고 하는 것이 그것입니다. 메시지를 `admin.action` 으로 시작하게 맞춰 **이미 있는 검색·기간·내보내기가 그대로 듣습니다.**

로그 화면에 **관리자 행위만** 을 켜고 끄는 것을 두었습니다. 검색어를 외워 적게 하면 아무도 쓰지 않습니다.

## 검증 결과

- 등록·정지·역할 부여가 남는지, 누가 무엇에 했는지가 들어 있는지, 위임받은 사람이 한 일이 그렇게 표시되는지 시험합니다.
- 브라우저에서 **남기고 → 화면에서 찾고 → CSV로 내보내는 것** 까지 한 줄로 확인합니다.
- 웹 시험 457개와 Go 시험 전체가 통과하고 `gofmt` 도 확인했습니다.
