## 릴리즈 요약

v0.128.0은 **피벗 테이블이 구글 시트가 내주는 집계를 모두 내도록** 합니다. 같은 자리에서 `count`가 개수를 부풀리던 버그도 고쳤습니다.

## 손으로 셀 수 있는 자료로 확인했다

수식 엔진을 오래 들여다봤으니 이번에는 피벗을 보았습니다. 서울 10·20·3, 부산 5·7·1처럼 **손으로 셀 수 있는 자료** 를 넣고 결과를 맞춰 보았습니다.

숫자는 맞았습니다. 대신 **낼 수 있는 집계가 다섯 가지뿐** 이었습니다.

## 여덟 가지를 더했습니다

| | |
| --- | --- |
| 있던 것 | `sum` `average` `count` `min` `max` |
| 더한 것 | `counta` `countunique` `median` `product` `stdev` `stdevp` `var` `varp` |

`countunique`와 `median`은 표를 들여다볼 때 늘 쓰는 것들입니다. **"거래처가 몇 곳인가"** 와 **"가운데 값은 얼마인가"** 는 합계만큼 자주 묻습니다.

이름 끝의 `p`는 가진 자료가 **모집단 전체** 라는 뜻입니다. 표본이면 붙이지 않으며, 값이 둘은 있어야 셈할 수 있습니다.

## count 가 개수를 부풀리고 있었다

엑셀과 시트에서 `count`는 **숫자만** 셉니다. 비어 있지 않은 것을 모두 세는 것은 `counta`입니다. 피벗의 `count`는 후자처럼 세고 있었습니다.

```
수량 열에 10, "미정", 20 이 있을 때
  고치기 전   count = 3
  지금        count = 2,  counta = 3
```

수량 열에 `미정` 같은 글자가 섞여 있으면 개수가 부풀었고, **부풀었다는 사실은 원본을 직접 세어 보기 전에는 알 수 없었습니다.** 합계는 맞는데 개수만 틀리므로 평균을 손으로 검산해도 드러나지 않습니다.

`count`를 숫자만 세도록 고치고, 예전 셈법은 제 이름인 `counta`로 옮겼습니다. 예전 숫자가 필요하면 `counta`를 고르면 됩니다.

## 검증 결과

- 파이썬 `statistics`로 따로 셈한 값과 **열세 가지 모두** 맞춰 보았습니다.
- 고치기 전 코드에서 열 가지가 걸립니다.
- 없는 집계 이름은 그대로 거절합니다.
- 중앙값과 표준편차는 값을 다 봐야 셈할 수 있어 묶음마다 모아 둡니다. 원본은 이미 100,000셀로 묶여 있으므로 끝없이 자라지 않습니다.
- Go 시험 전체와 웹 시험 376개가 통과합니다.
