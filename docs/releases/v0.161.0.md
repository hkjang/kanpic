## 릴리즈 요약

v0.161.0은 표 이름을 **찾을 수 있게** 합니다.

## 만들어 두고 이름을 모르면 없는 것과 같습니다

```
=SUM(매        →  매출표[열 이름] 을 권합니다
이름 상자에 매출표  →  그 표로 갑니다
빠른 이동(Ctrl+K)  →  이름 범위 옆에 표가 나옵니다
```

이름 있는 수식을 자동완성에 넣은 것과 같은 까닭입니다. 이름 범위는 되는데 표는 안 되면, 사람은 왜 되고 안 되는지 알 수 없습니다.

열 이름은 머리글에서 오므로 자동완성은 알 수 없습니다. **대괄호까지만 권하고 그 안은 사람이 적습니다** — 아는 척하는 것보다 낫습니다.

## 검증 결과

- 브라우저에서 이름 상자에 표 이름을 적어 그 표로 가는지 확인합니다.
- 웹 시험 392개와 Go 시험 전체가 통과합니다.
