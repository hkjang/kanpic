## 릴리즈 요약

v0.58.0은 값을 입력받는 자리에서 **브라우저 기본 입력창(`window.prompt`)을 없앱니다.** 지난 릴리즈에서 링크 대화상자를 만들다 실제로 물린 문제이기도 합니다. 기본 입력창은 이름표를 붙일 수도, 값을 검사할 수도 없고, 일부 환경에서는 아예 뜨지 않습니다. 이름을 바꿨는데 아무 일도 일어나지 않는 것이 가장 나쁜 결과입니다.

마이그레이션은 없습니다. 서버 변경도 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 바뀐 곳

공용 입력 대화상자를 만들고 값을 실제로 수집하는 네 곳을 옮겼습니다.

- **워크북 이름 변경** (파일 메뉴)
- **시트 이름 변경** (모든 시트 관리)
- **소유권 이전** (관리자 콘솔 · 워크북 거버넌스)
- **사용자 메모** (관리자 콘솔 · 사용자 및 역할)

새 대화상자는 입력칸에 이름표가 붙어 화면 낭독기에서 읽히고, 빈 이름처럼 받을 수 없는 값은 그 자리에서 이유를 보여 주며, `Enter` 로 바로 확인됩니다. 소유권 이전에는 "이전 소유자는 편집 권한도 잃습니다" 같은 결과 설명을 함께 띄웁니다.

클립보드 복사가 실패했을 때 주소를 보여 주는 자리에는 기본 입력창이 그대로 남습니다. 값을 받는 것이 아니라 이미 만든 문자열을 보여 주는 마지막 수단이라 대화상자로 바꿀 이유가 없습니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다.
- React/Vitest 40개 테스트 파일, 219개 테스트를 통과했습니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 120건을 통과했습니다. 새 테스트는 빈 이름을 넣었을 때 대화상자가 이유를 표시하는지, 워크북과 시트 이름이 실제로 바뀌는지 확인합니다. 기본 입력창을 기다리던 기존 테스트도 새 대화상자에 맞게 고쳤습니다.
