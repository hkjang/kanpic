## 릴리즈 요약

v0.212.0은 관리자가 **새어 나간 API 키 하나만** 끊을 수 있게 합니다.

## 계정을 통째로 정지하는 수밖에 없었습니다

관리자는 전체 키를 **보기만** 했습니다. 키 하나가 새어 나가면 그 사람 계정을 정지하는 것이 유일한 수단이었고, 그러면 **키와 상관없는 그 사람의 일까지 멈춥니다.**

저장소는 이미 관리자 회수를 받고 있었습니다 — `Revoke` 가 admin 여부를 인수로 받아 소유자 조건을 뺍니다. **문만 없었습니다.**

## 어느 쪽을 쓰는가

계정을 정지하면 그 사람의 API 키도 함께 막힙니다(키 요청도 같은 정지 검사를 지납니다). 그러니

- **사람이 떠날 때** → 계정 정지로 충분합니다.
- **사람은 남고 키만 문제일 때** → 그 키만 폐기합니다.

폐기는 되돌릴 수 없고, 그 키를 쓰던 연동은 즉시 끊깁니다. 폐기한 일은 **관리자 행위 기록**(v0.211.0)에 남습니다 — 남의 키를 끊는 것은 사람에게 영향을 주는 일입니다.

## 검증 결과

- 브라우저에서 키를 만들고, 관리자 화면에서 폐기하고, **그 사람 계정은 그대로 활성인지** 와 기록에 남는지까지 확인합니다.
- 웹 시험 457개와 Go 시험 전체가 통과하고 `gofmt` 도 확인했습니다.
