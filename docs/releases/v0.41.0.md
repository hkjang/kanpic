## 릴리즈 요약

v0.41.0은 **셀 안에서 줄 바꾸기**를 추가합니다. 편집 중 `Alt + Enter` 를 누르면 같은 셀 안에서 줄이 바뀝니다. 주소나 조건처럼 여러 줄로 적어야 읽히는 내용에 쓰는 기능입니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 셀 안에서 줄 바꾸기

- 셀 편집 중 **`Alt + Enter`** 로 줄을 바꿉니다. `Enter` 는 지금까지처럼 입력을 끝내고 아래 셀로 넘어갑니다.
- 줄 바꿈이 있는 셀은 **자동으로 줄바꿈 표시** 됩니다. 서식에서 줄바꿈을 켜지 않아도 두 줄이 보이며, 행 높이가 모자라면 행 머리글 경계를 두 번 클릭해 맞춥니다.
- **수식 입력창에서도 `Alt + Enter`** 로 줄을 바꿀 수 있고, 여러 줄 셀을 수식 입력창에서 고쳐도 줄 바꿈이 사라지지 않습니다. 예전에는 입력창이 한 줄짜리라 줄 바꿈이 조용히 지워질 수 있었습니다.

## 한글 입력 확인

셀 편집기를 여러 줄을 담을 수 있는 형태로 바꾸면서, 예전에 고쳤던 한글 입력 문제가 되살아나지 않는지 다시 확인했습니다.

- 조합 중에 누르는 `Enter` 는 글자를 확정할 뿐 줄을 바꾸지 않습니다.
- 그리드에서 바로 한글을 치기 시작해도 첫 자모가 사라지지 않고, 확정 후 저장된 값에 빈 줄이 섞이지 않습니다.
- 기존 한글 입력 회귀 테스트와 새 조합 시나리오 테스트를 모두 실행합니다.
