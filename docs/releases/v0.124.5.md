## 릴리즈 요약

v0.124.5는 격자와 `TEXT`를 **840가지 서식에서 모두 맞대어 보고** 어긋난 곳을 고칩니다. 167군데가 달랐고, 틀린 쪽은 한쪽이 아니었습니다.

## 열여덟 가지로는 모자랐다

지난 판에서 "격자는 맞고 서버가 틀렸다"고 적었습니다. 열여덟 가지 서식을 보고 한 말이었습니다.

이번에는 값 24개와 서식 35가지를 곱해 **840가지** 를 만들어 양쪽에 모두 넣어 보았습니다. 167군데가 어긋났고, 그 중 상당수는 **격자 쪽** 이 틀린 것이었습니다.

## 서버가 틀린 것

| 무엇 | 어떻게 |
| --- | --- |
| `General`, `@` | "값을 손대지 말라"는 뜻인데 숫자 서식으로 읽었습니다. `=TEXT(0.5,"General")`이 `1`이었습니다 (32군데) |
| 하루 안의 시각 | 곱해서 자르니 16시간 11분 59.999초가 되어 `16:11`로 보였습니다. `16:12`여야 합니다 |
| `0.00E+00` | 아예 알아보지 못하고 `0.500000`처럼 적었습니다 |

## 격자가 틀린 것

| 무엇 | 어떻게 |
| --- | --- |
| 음수 날짜 | `-1`을 `1899-12-30`으로 그렸습니다. 표 프로그램에 1900년보다 앞선 날은 없습니다 (22군데) |
| `0.00E+00` | 지수 자리를 채우지 않아 `5.00E-1`이었습니다. 엑셀은 `5.00E-01`입니다 |
| 백분율 | `1.005`를 이진 실수로 100 곱해 `100%`로 내려앉았습니다. 십진수 자리에서 점을 옮기면 `101%`입니다 |
| `-0` | `-0.256`을 정수 자리로 반올림해 `-0`을 그렸습니다 |

## 시험이 틀린 답을 지키고 있었다

기존 시험 하나가 `0.00E+00` 서식에 `1.23E+3`을 기대하고 있었습니다. 서식의 `E+00`은 **지수를 두 자리로 적으라**는 뜻이므로 `1.23E+03`이 맞습니다. 시험이 버그를 고정하고 있던 셈입니다.

## 다시 갈리지 않도록

`testdata/cell-formats.json`에 840가지를 적어 두고 **양쪽 시험이 함께 읽게** 했습니다. 한쪽만 고치면 양쪽 다 걸립니다. 일부러 한 줄을 바꿔 두 시험이 모두 잡아내는 것을 확인했습니다.

## 검증 결과

- 840가지 모두 글자 하나까지 같습니다.
- 지수 서식이 엑셀과 같아졌습니다 — `0` → `0.00E+00`, `0.5` → `5.00E-01`, `0.000123` → `1.23E-04`.
- Go 시험 전체, 웹 시험 375개, e2e가 통과합니다.
