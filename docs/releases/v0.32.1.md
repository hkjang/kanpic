## 릴리즈 요약

v0.32.1은 홈, 편집기, Workbook Agent와 관리자 콘솔 전반에서 지나치게 작던 글자를 읽기 쉬운 크기로 조정한 가독성 개선 릴리즈입니다. 보조 정보까지 7–10px로 축소되던 기존 스타일을 네 단계의 공통 타이포그래피 체계로 통일하고, 실제 화면에 표시되는 텍스트는 최소 11px을 유지합니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나이며, 기존 `BOOTSTRAP_ADMIN_ID`·`BOOTSTRAP_ADMIN_PASSWORD` 및 Keycloak Confidential Client의 `client_secret` 설정 방식도 그대로 유지됩니다.

## 읽기 쉬운 공통 타이포그래피

- 보조 메타 정보 11px, 라벨 12px, 본문 13px, 주요 UI 14px의 공통 토큰을 도입했습니다.
- 홈의 워크북 카드와 템플릿, 편집기의 메뉴·툴바·상태 표시·시트 탭, Workbook Agent의 문맥·계획·Diff·도구 호출, 관리자 콘솔의 내비게이션·지표·설정 표를 같은 기준으로 조정했습니다.
- 자동화, 차트, 피벗, 댓글, 공유, 검색, 시트 관리, 충돌 및 버전 이력 패널과 대화상자에도 동일한 최소 크기를 적용했습니다.
- 고정 높이와 고밀도 레이아웃은 유지해 더 큰 글자가 버튼, 카드나 표에서 잘리거나 겹치지 않도록 확인했습니다.

## 회귀 방지

- 홈, 편집기와 관리자 콘솔에서 실제로 보이는 텍스트의 계산된 글자 크기를 브라우저에서 검사합니다.
- 표시 텍스트가 11px 미만으로 내려가면 E2E 테스트가 실패하도록 가독성 기준을 자동화했습니다.

## 검증 결과

- React/Vitest 30개 테스트 파일, 140개 테스트를 통과했습니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 83건을 통과했습니다. 기존 82개 전체 사용자 흐름과 신규 가독성 회귀 검사를 포함합니다.
- 1440×900 브라우저에서 홈, 활성 Workbook Agent 편집기와 관리자 개요 화면을 직접 확인해 텍스트 잘림과 겹침이 없음을 확인했습니다.
