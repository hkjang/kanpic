## 핵심 변경

- 원본 값·수식·기본 서식을 변경하지 않는 서버 권위 조건부 서식을 추가했습니다.
- 값 비교, 텍스트 포함·미포함, 빈 값·비어 있지 않은 값, 중복·고유 값 규칙을 지원합니다.
- 숫자 분포를 2색 또는 중간색을 포함한 3색으로 보간하는 색상 범위를 지원합니다.
- 같은 규칙 범위의 최솟값과 최댓값을 기준으로 셀 안에 비율을 표시하는 데이터 막대를 지원합니다.
- 규칙 우선순위와 `조건이 참이면 중지` 정책으로 겹친 규칙의 적용 순서를 명시적으로 제어합니다.
- 조건부 서식 스타일은 기존 셀 스타일 위에 속성 단위로 합성되며, 매칭된 규칙 ID와 데이터 막대 비율을 평가 결과에 포함합니다.

## 데이터 내구성과 버전 관리

- 조건부 서식 정의를 PostgreSQL `conditional_formats` 테이블에 저장하고 이름, 범위, 유형, 조건, 스타일, 색상, 우선순위, revision, 작업자와 시각을 기록합니다.
- 생성 요청에는 idempotency key가 필수이며 같은 시트와 키의 재전송은 중복 규칙을 만들지 않습니다.
- 수정과 삭제는 `expected_revision`을 검사하고 모든 변경은 워크북 서버 버전을 증가시켜 공동 편집자에게 전파합니다.
- PostgreSQL 평가는 반복 가능 읽기 트랜잭션에서 규칙과 셀 블록을 함께 읽어 한 응답 안에 서로 다른 워크북 시점이 섞이지 않도록 했습니다.
- 워크북 버전 스냅샷과 복원에 조건부 서식 정의를 포함하며 복원 직전 자동 백업 정책을 그대로 사용합니다.
- 행·열 삽입 또는 삭제 시 조건부 서식 A1 범위를 함께 이동하고, 대상 범위 전체가 삭제되면 해당 규칙도 원자적으로 제거합니다.
- 시트 복제와 워크북 복제 시 새 ID와 독립 revision을 가진 규칙을 복사하므로 원본 변경이 복제본에 영향을 주지 않습니다.
- PostgreSQL을 최종 상태로 사용하며 Redis, 메시지 브로커 또는 외부 인터넷을 런타임 필수 구성으로 추가하지 않았습니다.

## 편집기와 Canvas 렌더링

- 툴바에 **조건부 서식** 진입 버튼과 현재 시트의 규칙 개수를 반영하는 활성 상태를 추가했습니다.
- 규칙 관리 화면에서 이름, A1 범위, 유형, 연산자, 기준값, 배경·글자색, 굵게·기울임, 색상 범위, 막대 색상, 우선순위와 중지 정책을 생성·수정·삭제할 수 있습니다.
- 2색·3색 그라데이션, 셀 스타일과 데이터 막대의 즉시 미리보기를 제공합니다.
- Canvas는 현재 화면과 고정 행·열에 필요한 타일만 서버에 평가 요청하고, 응답한 가상 스타일을 셀 기본 스타일 위에 그립니다.
- 빈 셀 규칙도 실제 셀 행을 생성하지 않은 채 화면에 표시하며 데이터 막대는 값 텍스트를 가리지 않는 반투명 레이어로 렌더링합니다.
- 셀 값 변경, 공동 편집 버전, 구조 변경, 버전 복원과 규칙 revision 변경 시 보이는 범위만 다시 평가합니다.

## REST API 및 MCP

- REST: `GET|POST /api/v1/sheets/{sheetId}/conditional-formats`
- REST: `GET /api/v1/sheets/{sheetId}/conditional-formats:evaluate?range=A1:B10`
- REST: `GET|PATCH|DELETE /api/v1/conditional-formats/{conditionalFormatId}`
- MCP 조회: `spreadsheet.conditional_format.list|get|evaluate`
- MCP 변경: `spreadsheet.conditional_format.create|update|delete`
- 조회·평가는 `format.read`, 생성·수정·삭제는 `format.write` scope를 검사하며 API 키로 MCP를 호출할 때는 `mcp.use`도 필요합니다.
- REST와 MCP는 같은 저장소, 입력 검증, idempotency, revision, 평가 및 공동 편집 버전 전파 계약을 사용합니다.

## 제한과 안전장치

- 시트당 규칙은 최대 100개, 규칙 원본 범위는 최대 100,000셀, 단일 평가 요청은 최대 10,000셀로 제한합니다.
- 우선순위는 1부터 1,000까지이며 낮은 숫자를 먼저 적용합니다.
- 스타일 입력은 기존 공통 셀 스타일 검증을 통과해야 하며 색상은 `#RRGGBB` 형식만 허용합니다.
- `between`과 `not_between`은 순서가 올바른 숫자 기준 두 개를 요구하고 숫자가 아닌 셀에는 매칭하지 않습니다.
- 색상 범위와 데이터 막대는 숫자 셀만 계산하며 동일한 값만 있는 범위는 안정적으로 100% 비율을 사용합니다.

- 실제 PostgreSQL 5432 통합 테스트 전체를 통과했습니다.

## 업그레이드 참고

- 서버 시작 시 `010_conditional_formats.sql`이 자동 적용되어 조건부 서식 정의와 우선순위 조회 인덱스를 생성합니다.
- 필수 런타임 환경 변수는 기존과 동일하게 `POSTGRES_DSN` 하나이며 PostgreSQL 기본 포트 5432를 사용할 수 있습니다.
- 기존 API 키로 조건부 서식 REST 또는 MCP 도구를 사용하려면 개인화 화면에서 `format.read` 또는 `format.write` scope를 추가하거나 키를 회전해야 합니다.
- 조건부 서식은 워크북 스냅샷 schema version 8부터 저장됩니다. 이전 스냅샷은 기존 데이터와 기능을 그대로 복원하고 조건부 서식 목록만 빈 상태로 유지합니다.
- 오프라인 번들은 `kanpic-v0.12.0.tar.gz`와 SHA-256 파일로 제공되며 Docker에 로드한 뒤 기존 PostgreSQL 5432 인스턴스에 연결하면 됩니다.
