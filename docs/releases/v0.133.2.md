## 릴리즈 요약

v0.133.2는 **제가 v0.133.0에서 낸 회귀** 를 고칩니다. 지표 넉 장을 얻는 대신 마무리 슬라이드 한 장이 사라져 있었습니다.

## 얻은 것과 잃은 것

v0.133.0에서 잴 것이 여럿일 때 지표 칸을 열마다 합계에 내주려고, **최저를 아예 셈하지 않게** 했습니다. 그런데 마무리 슬라이드(주요 시사점)가 그 최저를 재료로 씁니다.

```
측정값 하나   표지 · 지표 · 추이 · 상세 · 주요 시사점
측정값 셋     표지 · 지표 · 추이 · 상세            ← 한 장이 사라졌다
```

품질을 올리려던 쪽에서 덱이 **오히려 얇아졌습니다.** 알림도 없고 오류도 아니어서, 덱을 나란히 놓고 장수를 세어 보기 전에는 드러나지 않습니다.

## 무엇을 뒤섞었나

**칸이 모자란 것** 과 **그런 통찰이 없는 것** 은 다른 이야기입니다. 앞 판에서 저는 이 둘을 하나로 처리했습니다.

최저는 늘 셈해 두고, 좁은 칸을 누구에게 내줄지는 지표 슬라이드가 정하도록 나눴습니다.

```
지표    최고 매출 · 합계 매출 · 합계 비용 · 합계 이익   (넓이 그대로)
마무리  3분기의 매출 개선 방안 검토                     (돌아왔다)
```

## 검증 결과

- 고치기 전 코드에서 최저 통찰이 사라져 걸립니다.
- 잴 것이 하나일 때 최저가 지표에 그대로 보이는지도 함께 봅니다.
- 실제 서버에서 두 가지 표의 슬라이드 구성을 모두 확인했습니다.
- Go 시험 전체와 웹 시험 379개가 통과합니다.
