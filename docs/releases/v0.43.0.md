## 릴리즈 요약

v0.43.0은 **서식 복사(붓)** 를 추가합니다. 원본 셀을 고르고 툴바의 붓을 누른 뒤 대상 범위를 클릭하면 서식만 옮겨 갑니다. 어느 스프레드시트에서든 가장 자주 눌리는 도구 중 하나인데 kanpic에는 없었습니다.

마이그레이션은 없습니다. 서버 변경도 없으며, 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 서식 복사

- 원본 셀 선택 → 툴바 **붓 아이콘** → 대상 셀이나 범위 클릭. 범위는 드래그로도 지정할 수 있습니다.
- 대상은 원본과 **똑같은 모양** 이 됩니다. 원본에 없는 서식은 지워지므로 결과가 두 서식의 혼합이 되지 않습니다.
- **값·수식·병합 상태는 건드리지 않습니다.** 서식만 바뀝니다.
- 붓을 **두 번 클릭** 하면 계속 사용 상태가 되어 여러 곳에 연달아 입힐 수 있고, `Esc` 나 붓을 다시 누르면 해제됩니다. 붓을 든 동안에는 마우스 커서가 바뀝니다.

- `go vet ./...`와 `go test ./...`를 통과했습니다.
- React/Vitest 38개 테스트 파일, 203개 테스트를 통과했습니다. 원본이 지정한 서식은 옮기고 지정하지 않은 서식은 지우는 규칙, 병합 정보를 절대 옮기지 않는 규칙을 단위 테스트로 확인합니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 101건을 통과했습니다. 실제 브라우저에서 서식이 옮겨 가고 값은 그대로인지, 한 번 쓰면 붓이 내려지는지, 두 번 클릭하면 연달아 쓰이고 `Esc` 로 멈추는지 확인했습니다.
