## 릴리즈 요약

v0.130.2는 **제가 낸 회귀를 고칩니다.** 인쇄 관련 e2e 일곱 개가 CI에서 한꺼번에 실패했습니다.

## 무엇이 걸렸나

v0.129.0에서 파일 메뉴에 인쇄 영역 항목 둘을 더했습니다. 시험은 인쇄 항목을 이렇게 골랐습니다.

```
getByRole('menuitem',{name:/인쇄/})
```

부분 일치라서 예전에는 `인쇄` 하나만 걸렸는데, 이제 셋이 걸립니다.

```
인쇄
인쇄 영역으로 설정
인쇄 영역 해제
```

여럿이 걸리면 무엇을 눌러야 할지 알 수 없어 시험이 멈춥니다.

## 왜 놓쳤나

**메뉴를 건드려 놓고 메뉴를 지나는 e2e를 돌리지 않았습니다.** 그때 돌린 것은 제가 보고 있던 두 개뿐이었습니다. 화면의 어느 한 곳을 바꾸면 그 곳을 지나는 시험을 모두 돌려야 합니다.

## 첫 고침은 틀렸다

처음에는 `exact:true`로 고쳤는데 이번에는 **아무것도 걸리지 않아** 시간만 흘렀습니다. 인쇄 항목에는 단축키가 함께 그려져 접근 이름이 `인쇄 Ctrl+P`이기 때문입니다.

화면에 실제로 그려진 이름을 먼저 확인했어야 했습니다. 짐작으로 고치니 실패하는 모양만 바뀌었습니다.

영역 항목만 빼고 고르도록 했습니다.

```
{name:/^인쇄(?!\s*영역)/}
```

## 검증 결과

- 다섯 파일 일곱 자리를 고쳤습니다.
- e2e를 **통째로** 돌렸습니다. 189개가 모두 통과합니다.
