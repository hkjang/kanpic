## 릴리즈 요약

v0.31.1은 **직접 입력한 추적 코드가 보안 정책에 막히던 문제**를 서비스 차원에서 없앱니다. 붙여 넣은 코드에 적힌 주소는 자동으로 허용되고, 코드 안에서 조립하는 주소처럼 미리 알 수 없는 경우에는 브라우저가 보내온 차단 보고를 콘솔에 보여 주고 한 번의 클릭으로 허용합니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 코드에 적힌 주소는 자동 허용

- 붙여 넣은 추적 코드에서 `http(s)` 주소를 찾아 **스크립트 로드·수집 요청·이미지 전송**에 모두 허용합니다. 스크립트를 내려받는 주소와 수집 엔드포인트가 같은 호스트인 일반적인 구성은 이제 아무 설정 없이 동작합니다.
- 미리보기 아래에 코드에서 찾아낸 도메인이 표시되므로, 어떤 주소가 열렸는지 확인한 뒤 저장할 수 있습니다.
- 상대 경로나 주소가 아닌 문자열은 무시하고, 같은 출처는 한 번만 허용합니다.

## 차단된 요청 보고와 한 번의 클릭으로 허용

- 추적이 켜져 있는 동안에는 정책에 `report-uri`가 함께 나가 브라우저가 막은 요청을 서버로 알려 줍니다.
- 콘솔의 **차단된 요청** 카드에 막힌 주소·지시문·횟수·마지막 시각이 표시되고, **이 도메인 허용**을 누르면 `analytics.allowed_hosts`에 추가되어 즉시 열립니다. 이미 허용된 주소는 **허용됨**으로 표시됩니다.
- 보고는 메모리에 최근 100개 출처만 같은 주소끼리 묶어 보관합니다. 데이터베이스에 남기지 않으므로 재시작하면 비워지고, 브라우저 확장 프로그램처럼 허용할 수 없는 항목은 기록하지 않습니다.

```http
GET    /api/v1/admin/analytics/violations
DELETE /api/v1/admin/analytics/violations
POST   /api/v1/admin/analytics/violations:allow   {"origin":"https://collector.corp.example"}
POST   /api/v1/analytics/csp-report                (브라우저가 보내는 경로, 인증 없음)
```

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. 코드에서 주소를 뽑아내는 규칙, 같은 출처의 중복 제거, 보고 기록의 개수 제한과 이미 허용된 주소 표시, 허용 목록에 추가하는 규칙을 확인합니다.
- React/Vitest 30개 테스트 파일, 142개 테스트를 통과했습니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 81건을 통과했습니다. 실제 브라우저에서 수집 엔드포인트로 보내는 요청이 CSP 위반 없이 나가는지, 코드에서 찾을 수 없는 주소가 차단 목록에 올라오고 콘솔에서 허용한 뒤 정상 동작하는지 확인했습니다.
