## 표에서 조건에 맞는 줄만 골라 셈합니다

`D` 로 시작하는 열두 함수가 하나도 없었습니다. 업무용 표에서 아직 자주 보이는 꼴이고, 가져온 파일에 들어 있으면 그대로 `#NAME?` 이었습니다.

```
=DSUM(A1:C5, "매출", E1:E2)
```

표와 조건표 모두 **첫 줄이 머리글** 입니다. 셈할 열은 머리글 이름으로도 몇 번째 열인지로도 가리킵니다. 조건표의 **한 줄 안에 있는 조건은 모두** 맞아야 하고(그리고), **줄이 여럿이면 그중 하나만** 맞으면 됩니다(또는).

조건을 읽는 규칙은 `COUNTIF` 가 쓰는 것을 **그대로** 씁니다. 두 곳에 나누어 적으면 `">=50"` 이나 `"영*"` 을 한쪽만 알아듣게 됩니다.

`DSUM`, `DAVERAGE`, `DCOUNT`, `DCOUNTA`, `DMAX`, `DMIN`, `DPRODUCT`, `DSTDEV`, `DSTDEVP`, `DVAR`, `DVARP`, `DGET` 입니다.

**답을 낼 수 없는 자리는 그렇다고 말합니다.** `DGET` 은 맞는 줄이 없으면 `#VALUE!`, 여럿이면 `#NUM!` 입니다. 조용히 0을 내면 사람은 맞는 줄이 없다는 것과 합이 0이라는 것을 구별할 수 없습니다.

## 진법과 비트

공학 함수 스물여섯 개 중에도 하나도 없었습니다. 진법 바꾸기 열둘, 비트 셈 다섯, 견주기 넷을 채웠습니다.

엑셀은 진법 값을 **10자리 2의 보수** 로 다룹니다. 맨 앞자리가 켜져 있으면 음수입니다.

```
=BIN2DEC(1111111111)  ->  -1     (1023이 아닙니다)
=DEC2HEX(-54)         ->  FFFFFFFFCA
=OCT2DEC(7777777533)  ->  -165
```

이것을 놓치면 음수가 큰 양수로 **조용히** 바뀝니다. 자릿수를 넘거나 모자라면 잘라 내지 않고 `#NUM!` 을 냅니다. 비트 함수는 음수와 소수를 받지 않고 48비트까지 셉니다.

복소수(`COMPLEX`, `IM*`)와 `CONVERT` 는 아직 없습니다. 단위표와 복소수 표현이 따로 필요해서 이번에 넣지 않았습니다.
