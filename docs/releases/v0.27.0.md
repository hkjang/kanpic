## 릴리즈 요약

v0.27.0은 관리자 콘솔에 **AI 호출 이력** 화면을 추가합니다. 지금까지 AI 사용 기록은 데이터베이스에만 쌓이고 사용자 본인만 자기 이력을 볼 수 있었습니다. 이제 관리자가 조직 전체의 요청을 조회·검색하고, CSV로 내보내고, 보존 기간을 정해 자동으로 정리할 수 있습니다.

필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나이며 새 마이그레이션은 없습니다.

## AI 호출 이력 화면

- 콘솔 왼쪽 메뉴에 **AI 호출 이력** 이 생겼습니다. 조직 전체의 요청을 최신순으로 보여 주고 사용자, 워크북, 작업 유형, 상태, 기간, 요청 문장으로 걸러 볼 수 있습니다.
- 상단 카드에 **전체 요청 수**, **적용·실패 건수**, **입력과 응답 토큰 합계**를 표시하고, 아래에 현재 필터 기준 **사용량 상위 사용자**를 요청 수와 토큰으로 정렬해 보여 줍니다.
- 행을 누르면 요청 문장, 요약, 설명, 제안된 변경 셀, 이벤트 타임라인, 오류 메시지를 담은 상세 창이 열리고 해당 워크북으로 바로 이동할 수 있습니다.
- 토큰 사용량은 v0.26.0에서 기록하기 시작한 계획 이벤트에서 읽어 옵니다.

## 내보내기와 보존

- **CSV 내보내기**는 화면의 필터를 그대로 적용해 시각·사용자·워크북·유형·범위·상태·모델·요청·변경 셀·토큰 열을 내보냅니다. Excel에서 한글이 깨지지 않도록 BOM을 포함합니다.
- 새 설정 **`ai.history_retention_days`**(기본 `0` = 계속 보관)를 지정하면 서버가 매시간 그보다 오래된 **완료·실패** 이력을 삭제합니다. 승인 대기 중인 요청은 지우지 않습니다.
- **지정 시점 이전 삭제** 버튼으로 특정 날짜 이전 이력을 즉시 정리할 수 있고, 삭제 건수는 `audit_logs`에 `ai.history.purge`로 남습니다.

## REST API

```http
GET    /api/v1/admin/ai/actions?status=&mode=&actor=&q=&since=&until=&limit=&offset=
GET    /api/v1/admin/ai/actions?format=csv
GET    /api/v1/admin/ai/actions/{actionId}
DELETE /api/v1/admin/ai/actions?before=YYYY-MM-DD
```

관리자만 호출할 수 있습니다. 목록 응답은 항목과 함께 상태별·유형별 집계, 토큰 합계, 상위 사용자, 가장 오래된 기록 시각, 현재 보존 기간을 반환합니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. 실제 PostgreSQL에서 목록·필터·페이징·집계·상위 사용자·보존 삭제를 검증하고, 승인 대기 요청이 삭제되지 않는지 확인합니다. 관리자 경로는 필터 적용, CSV 형식, 잘못된 삭제 기준 거부를 확인합니다.
- React/Vitest 29개 테스트 파일, 133개 테스트를 통과했습니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 70건을 통과했습니다. 실제 브라우저와 PostgreSQL에서 계획을 만든 뒤 콘솔 목록에 나타나는지, 상세 창에 요청과 이벤트가 보이는지, 상태 필터로 목록이 비는지, CSV에 사용자가 포함되는지, 삭제 후 목록에서 사라지는지 확인했습니다.

## 수정된 문제

- 보존 기간 입력이 존재하지 않는 단일 설정 경로를 호출해 저장된 값 대신 항상 `0`을 보여 주던 문제를 고쳤습니다. 이제 설정 목록에서 현재 값을 읽습니다.
