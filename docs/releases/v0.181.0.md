## 릴리즈 요약

v0.181.0은 **병합 해제하고 채우기** 를 더합니다. 지난 판에서 막아 둔 일을 사람이 손으로 하지 않아도 되게 합니다.

## 막아 놓고 끝내면 일이 사람에게 넘어갑니다

v0.180.0에서 데이터 정리가 병합된 칸을 만나면 `병합을 해제한 뒤 다시 시도하세요` 하고 멈추게 했습니다. 그러면 해제하는 일은 사람 몫이 됩니다. **병합이 서른 개면 서른 번입니다.**

## 읽기 좋은 표가 쓸 수 없는 표입니다

다른 곳에서 받은 보고서는 병합투성이입니다.

```
부서      금액
영업1팀   100     ← A2:A4 가 한 칸으로 묶여 있다
          200
          300
```

사람 눈에는 읽기 좋습니다. 그런데 이 표는 **정렬도 피벗도 되지 않습니다.** 둘째와 셋째 행에는 부서가 적혀 있지 않기 때문입니다.

**데이터 › 데이터 정리 › 병합 해제하고 채우기…** 가 풀고 채웁니다.

```
영업1팀   100
영업1팀   200
영업1팀   300
```

## 없애는 일은 하지 않습니다

가려져 있던 칸에 **이미 값이 있으면 그 값을 남깁니다.** kanpic의 병합은 값을 지우지 않고 가리기만 하므로, 덮어 채우면 사람이 보지 못하던 값을 없애는 일이 됩니다. 채우는 일을 부탁받았지 없애는 일을 부탁받은 것이 아닙니다. 몇 칸을 채우고 몇 칸을 그대로 두는지 미리 적어 보여 줍니다.

**병합이 고른 자리 밖까지 뻗어 있으면 밖까지 함께 풉니다.** 절반만 풀면 어느 곳에도 적히지 않는 반쪽짜리 병합이 남습니다 — 지난 판에서 열로 나누기가 그렇게 하던 것입니다.

**수식이 든 칸을 그대로 베끼지 않습니다.** 채우려는 것은 눈에 보이던 값이므로 계산된 값을 넣습니다. 같은 수식이 여러 자리에 앉는 것은 채우기가 아닙니다.

- 브라우저에서 풀고 채운 뒤, **병합 때문에 멈추던 중복 항목 삭제가 열리는 데까지** 확인합니다.
