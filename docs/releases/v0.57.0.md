## 릴리즈 요약

v0.57.0은 **이 워크북 안의 범위로 가는 링크**를 만듭니다. 목차에서 요약으로 뛰는 링크는 스프레드시트에서 가장 흔한 링크인데, 주소를 손으로 만들 수 있는 사람은 없었습니다.

마이그레이션은 없습니다. 서버 변경도 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 새로운 기능

- **삽입 › 링크…** 가 두 탭을 가진 대화상자가 되었습니다. `window.prompt` 두 번 대신 **웹 주소** 와 **이 워크북의 범위** 중에서 고릅니다.
- 범위 탭에서는 시트를 고르고 범위를 적습니다. `C20` 처럼 한 칸도 됩니다. 표시할 텍스트를 비우면 `시트!범위` 가 그대로 들어갑니다.
- 내부 범위 링크의 칩은 URL 대신 **`이 워크북 · C20`** 으로 보입니다. URL은 사람이 보고 판단할 것이 없습니다.
- 누르면 **페이지를 새로 읽지 않고** 그 자리로 이동합니다. 두 칸 옆으로 가려고 편집 중이던 상태를 잃는 일이 없습니다.
- 링크는 **누르는 즉시 셀에 들어갑니다.** 이전에는 대화상자가 수식을 편집기에 넣어 두고 Enter를 기다렸습니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다.
- React/Vitest 40개 테스트 파일, 219개 테스트를 통과했습니다. 내부 링크 주소 해석과 칩 표시 방식을 다루는 테스트가 추가되었습니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 119건을 통과했습니다. 새 테스트는 대화상자로 범위 링크를 만들고, 셀에 바로 들어가는지, 칩 문구, 클릭 후 선택 이동과 **주소창이 그대로인지**(새로 읽지 않았다는 증거)를 확인합니다.

브라우저로 확인하다 실제 버그를 하나 잡았습니다. 범위 검사기가 `B2:C10` 형태만 통과시켜 `C20` 같은 한 칸 주소를 거부했고, 경고창이 조용히 흐름을 막고 있었습니다. 한 칸도 범위로 받아들이도록 고쳤습니다.
