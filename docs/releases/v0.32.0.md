## 릴리즈 요약

v0.32.0은 기존 AI 도우미를 **Workbook Agent**로 확장합니다. Agent는 현재 선택 범위와 워크북 구조를 읽어 여러 단계 작업을 계획하고, 셀 Diff·도구 인자·위험도를 보여 준 뒤 사용자가 승인한 경우에만 실행합니다. 적용 결과는 검증하고 하나의 ChangeSet으로 남기므로 대화에서 “지난번 작업 취소”라고 요청하거나 **Undo**를 눌러 전체 작업을 되돌릴 수 있습니다.

이번 버전은 `022_workbook_agent.sql`, `023_workbook_agent_rollback_guard.sql` 마이그레이션을 추가합니다. 서버 시작 시 자동 적용되며 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 문맥을 이해하는 Workbook Agent

- 활성 시트와 선택 범위는 헤더, 값, 수식, 데이터 유형, 빈 값과 숫자 통계까지 의미 문맥으로 구성합니다. 선택하지 않은 시트는 이름·크기·사용 범위 같은 메타데이터만 전달해 불필요한 데이터 노출을 줄였습니다.
- 수식 생성·채우기·오류 수정, 중복·공백 정리, 서식, 분석, 차트 생성과 신규 보고서 시트+수식+차트 복합 작업을 지원합니다.
- 셀 우클릭 메뉴의 **Workbook Agent** 하위 명령으로 선택 범위 분석, 수식 생성, 오류 수정, 데이터 정리, 서식과 차트를 바로 요청할 수 있습니다.
- 대화, 추천 질문, 최근 Run, 계획 단계, 도구 호출, Diff와 검증 결과를 편집기 오른쪽 패널에서 함께 확인합니다.

## 승인, 검증, Undo와 감사

- 계획은 허용된 도구와 선택 범위, 셀 수, 워크북 버전을 서버에서 다시 검사합니다. 워크북 데이터는 프롬프트 명령이 아닌 신뢰하지 않는 데이터로 분리합니다.
- 변경 전에는 미리보기만 만들고 명시적 승인 후 실행합니다. 셀 변경과 차트, 새 보고서 시트를 하나의 ChangeSet으로 기록하며 작업별 위험도와 도구 인자를 표시합니다.
- 실행 후 수식 오류와 기대 조건을 검증해 Run에 남깁니다. 적용 후 워크북이 다시 바뀌었다면 오래된 ChangeSet의 위험한 롤백을 거부합니다.
- 메시지 전송과 실행 취소는 멱등하게 처리하며 대화·Run·Plan·Step·Tool Call·ChangeSet·검증·감사 로그를 PostgreSQL에 보존합니다.

```http
POST /api/v1/workbooks/{workbookId}/agent/messages
GET  /api/v1/agent/runs/{runId}
GET  /api/v1/agent/runs/{runId}/plan
POST /api/v1/agent/runs/{runId}/approve
POST /api/v1/agent/runs/{runId}/cancel
POST /api/v1/changesets/{changeSetId}/rollback
```

## 운영 인증

- Docker 실행 시 `BOOTSTRAP_ADMIN_ID`와 `BOOTSTRAP_ADMIN_PASSWORD`를 함께 지정하면 초기 관리자 로그인을 환경 변수로 보호합니다. 하나만 지정하면 안전하게 기동을 거부하며, 둘 다 생략하면 기존 초기 설정 모드로 동작합니다.
- Keycloak Public Client는 secret 없이, Confidential Client는 관리자 콘솔의 비밀 설정 `auth.oidc.client_secret`을 통해 연결할 수 있습니다. 두 방식 모두 Authorization Code Flow와 PKCE를 사용합니다.

## 업그레이드 참고

- 기존 데이터는 변경하지 않지만 Agent 실행 이력을 위한 PostgreSQL 테이블과 롤백 버전 보호 컬럼이 추가됩니다. 운영 DB는 일반적인 배포 절차에 따라 백업한 뒤 새 이미지를 시작하십시오.
- AI 기능은 기본 비활성화 상태를 유지합니다. 관리자가 사내 OpenAI 호환 Gateway와 모델을 설정하고 `ai.enabled`를 켠 경우에만 외부 모델을 호출합니다.
- Agent가 읽고 쓸 수 있는 범위는 기존 워크북 ACL과 `ai.use`, `range.read`, 작업별 write scope를 그대로 따릅니다.
