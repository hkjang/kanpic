## 릴리즈 요약

v0.147.0은 **복소수 함수 16개** 를 더합니다. 구글 시트가 아는 함수 400개 중 kanpic이 아는 것이 **391개에서 397개** 로 늘었습니다.

## 글자로 주고받습니다

엑셀은 복소수를 `"3+4i"` 같은 **글자** 로 다룹니다. 셈할 때마다 읽고 다시 적으므로, 읽는 쪽과 적는 쪽이 서로를 되돌려야 합니다.

```
=COMPLEX(3,4)              ->  3+4i
=IMPRODUCT("3+4i","1-2i")  ->  11-2i
=IMSQRT("3+4i")            ->  2+i
```

## 적는 규칙이 까다롭습니다

허수부가 `1`이나 `-1`이면 숫자를 적지 않고, 한쪽이 `0`이면 그쪽을 적지 않습니다.

```
=COMPLEX(0,1)   ->  i
=COMPLEX(0,-1)  ->  -i
=COMPLEX(1,0)   ->  1
=COMPLEX(0,0)   ->  0
```

읽을 때는 **지수 표기의 부호를 실수부와 허수부가 갈리는 자리로 보면 안 됩니다.** `"2.5e3-4i"` 에서 `e` 뒤의 부호는 자리가 아닙니다.

허수 단위는 `i` 와 `j` 를 모두 쓰고 **적어 준 쪽으로 답합니다** — 사람이 고른 표기를 바꾸지 않습니다. 다만 한 식 안에서 섞으면 어느 쪽으로 적을지 정할 수 없어 `#VALUE!` 입니다.
