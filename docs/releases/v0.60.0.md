## 릴리즈 요약

v0.60.0은 **텍스트를 열로 분할**에 미리보기를 붙이고, 따옴표로 감싼 값을 제대로 다룹니다. 지금까지는 메뉴에서 구분 기호를 고르면 곧바로 실행됐습니다. 무엇이 어떻게 나뉘는지도, 오른쪽에서 무엇이 사라지는지도 모른 채 누르는 버튼이었습니다.

마이그레이션은 없습니다. 서버 변경도 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 새로운 기능

- **미리보기 대화상자**: 앞의 몇 행이 실제로 어떻게 나뉘는지 표로 보여 주고, 몇 개 열이 되는지와 **오른쪽 몇 개 열의 기존 값을 덮어쓰는지** 를 함께 알려 줍니다.
- **맞춤 구분 기호**: 쉼표·세미콜론·탭·공백 외에 `::` 처럼 두 글자 이상도 직접 적을 수 있습니다.
- **자동 감지 결과를 밝힙니다.** `자동 감지: 쉼표 · 3개 열로 나뉩니다` 처럼 무엇으로 판단했는지 보여 줍니다.
- 고른 구분 기호로 나눌 수 없으면 **분할** 버튼이 비활성화되고 이유가 표시됩니다.

## 고친 문제

- **따옴표 안의 구분 기호로 나누던 문제.** `"서울, 강남구",100,완료` 는 세 칸인데 네 칸으로 쪼개졌습니다. 분할하는 텍스트는 대개 붙여 넣은 CSV라 실제로 자주 만나는 경우입니다. 큰따옴표 안의 `""` 는 따옴표 한 개로 읽습니다.
- **덮어쓰기 경고가 좁은 선택에서 뜨지 않던 문제.** 경고를 선택 범위 안의 셀만 보고 판단했는데, 분할이 덮어쓰는 열은 정의상 선택 **바깥**입니다. A열만 선택하면 B열에 값이 있어도 "덮어쓸 것 없음"으로 보였습니다. 이제 오른쪽 열까지 읽어 판단합니다. v0.44.x에서 고친 "화면에 있는 것만 보고 계산하기"와 같은 종류의 실수였습니다.
