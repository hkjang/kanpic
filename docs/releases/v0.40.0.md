## 릴리즈 요약

v0.40.0은 **열 통계**를 추가합니다. 수식을 쓰기 전에 데이터를 훑어보는 자리로, 선택한 열이 얼마나 채워져 있는지·어떤 값이 반복되는지·숫자가 어디에 몰려 있는지를 한 화면에 보여 줍니다.

마이그레이션은 없습니다. 서버 변경도 없으며, 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 열 통계

- **데이터 › 열 통계** 또는 열 머리글 오른쪽 클릭의 **이 열 통계 보기** 로 엽니다. 다른 셀을 고르면 그 열로 즉시 바뀝니다.
- 값 있음·빈 셀·고유값·숫자 개수를 먼저 보여 주고, 숫자가 있으면 합계·평균·중앙값·표준편차·최소·최대와 **분포 막대** 를 함께 그립니다.
- 아래에는 **자주 나오는 값** 이 많은 순으로 최대 8개까지 나옵니다. 오타나 표기가 갈린 값을 찾을 때 씁니다.
- 첫 행이 숫자 열 위의 글자면 머리글로 보고 집계에서 빼며, 그 사실을 화면에 적어 둡니다.
- 화면에 보이는 부분이 아니라 **그 열 전체(최대 2만 행)** 를 서버에서 읽어 계산하므로, 스크롤하지 않은 아래쪽 값도 포함됩니다. 쉼표가 섞인 숫자 텍스트도 숫자로 셉니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다.
- React/Vitest 36개 테스트 파일, 191개 테스트를 통과했습니다. 채움·고유값 집계, 숫자 요약과 표준편차, 값이 하나뿐이거나 아예 없는 열, 머리글 판단을 단위 테스트로 확인합니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 94건을 통과했습니다. 실제 브라우저에서 숫자 열의 합계와 평균이 맞는지, 머리글을 빼는지, 텍스트 열에서는 반복 값이 나오고 숫자 요약이 사라지는지 확인했습니다.
