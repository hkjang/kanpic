## 릴리즈 요약

v0.44.2는 **정렬을 비롯한 데이터 명령이 화면에 보이는 행만 대상으로 삼던 문제**를 고칩니다. 300행짜리 표에서 셀 하나를 고르고 정렬하면 대상이 `A1:A22` 로 잡혔고, 그마저도 실행되지 않았습니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 수정된 문제

- **데이터 명령의 대상 범위가 화면에 불러온 행까지였습니다.** 그리드는 보이는 행만 불러오는데 정렬·중복 삭제·공백 제거·텍스트 분할·테이블 서식이 그 메모리 내용으로 대상 블록을 정하고 있었습니다. 300행 표를 정렬하면 위쪽 21행만 뒤섞여 **표가 서로 어긋나는** 결과가 될 수 있었습니다. 이제 시트의 사용 범위를 서버에서 읽어 대상을 정하고, 그 명령이 쓰는 셀 값도 같은 읽기에서 가져옵니다.
- **데이터 메뉴의 "선택 열 기준 정렬"이 아무 일도 하지 않았습니다.** 정렬 대상 범위를 고른 직후 아직 반영되지 않은 예전 선택(셀 하나)을 서버로 보내 "정렬 범위에는 데이터 행이 두 개 이상 있어야 합니다" 로 거부됐습니다. 이제 정렬은 넘겨받은 범위를 그대로 사용합니다.

두 문제 모두 v0.44.1에서 고친 것과 같은 계열(화면에 없는 데이터를 조용히 빠뜨림)이며, 300행 표를 정렬해 전체가 정렬되는지 확인하는 회귀 테스트를 추가했습니다.
