## 릴리즈 요약

v0.68.0은 **XLSX 가져오기가 시트 배치를 읽도록** 합니다. 직전 릴리즈에서 내보내기가 배치를 담게 됐지만 가져오기는 여전히 값만 읽었습니다. kanpic에서 내보낸 파일을 다시 올리면 숨김·너비·틀 고정·그룹이 전부 사라졌습니다. 자기 파일 형식을 한 바퀴 도는 것만으로 배치를 잃는 상태였습니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 새로운 기능

XLSX를 올리면 다음이 함께 들어옵니다.

- 숨긴 행·열 (연속 구간으로 묶어서)
- 행 높이·열 너비 (엑셀 단위를 픽셀로 환산, 기본값과 다른 것만)
- 틀 고정
- 아웃라인 그룹 (엑셀은 행마다 수준을 적고 kanpic은 구간을 적으므로, 같은 수준이 이어지는 구간을 하나의 그룹으로 묶습니다)

파일이 말하는 배치도 **요청과 똑같이 검사합니다.** 범위를 벗어난 크기나 좌표는 무시됩니다. 파일이라고 해서 더 믿을 이유가 없습니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. 새 테스트는 내보낸 파일을 다시 파싱해 숨김 구간·틀 고정·열 너비가 돌아오는지 확인하고, **파싱 결과에서 그치지 않고** 저장된 시트의 배치까지 확인합니다.
- 가져오기에서 배치 읽기를 빼 보았고 테스트가 `Layout:(*workbook.SheetLayout)(nil)` 로 실패했습니다.
- 실제 서버에서 워크북을 내보내 그 파일을 `POST /api/v1/imports` 로 다시 올렸습니다. 새 워크북의 시트 배치에 `hidden_rows: [{start:2,end:2}]` 와 틀 고정 1행 1열이 그대로 들어 있습니다.
- PostgreSQL 통합 테스트, React/Vitest 234개 테스트, TypeScript 타입 검사, Vite 프로덕션 빌드, Playwright E2E 130건을 통과했습니다.
