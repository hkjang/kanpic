## 릴리즈 요약

v0.175.0은 데이터 표가 **감당 못 할 일을 미리 막습니다.** 어제 넣은 것을 훑다가 비용을 재 보고 나왔습니다.

## 재 보고 알았습니다

표 한 칸마다 워크북을 통째로 다시 셈합니다. 그러니 얼마나 걸릴지는 **워크북 칸 수와 표 칸 수의 곱** 으로 정해지는데, 둘을 따로 묶어 두면 그 곱이 얼마가 될지는 아무도 보지 않습니다.

```
수식 2,000칸 워크북 × 400칸 표  →  2.9초
읽기 상한 50,000칸까지 가면      →  70초쯤
서버의 쓰기 제한                 →  130초
```

끊기지는 않지만 너무 가깝습니다. 끊기면 사람은 무엇이 잘못됐는지 알 길이 없습니다.

이제 **곱을 셈하기 전에 봅니다.** 30초 어름에서 막고, 가정을 줄이거나 더 작은 시트에서 해 보라고 말해 줍니다.

## 검증 결과

- 작은 표는 그대로 셈하고, 칸 수를 넘기면 사람 말로 알려 주는지 확인합니다.
- Go 시험 전체와 통합 시험 전체가 통과합니다.
