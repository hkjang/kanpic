## 릴리즈 요약

v0.184.0은 **두 목록 비교(대사)** 를 더합니다.

## 지금까지는 눈으로 셌습니다

은행에서 받은 내역과 장부를 맞춰 보는 일을 대사라고 합니다. 지금까지는 `VLOOKUP` 을 두 번 쓰고 `#N/A` 를 눈으로 세는 수밖에 없었습니다.

**데이터 › 두 목록 비교…** 가 키 열을 정해 두 범위를 견줍니다.

```
양쪽에 2 · 왼쪽에만 1 · 오른쪽에만 1
```

## 글자 금액과 숫자 금액을 맞춥니다

```
은행 내역        장부
"1,000"    ↔    1000     맞음
"2,000"    ↔    2000     맞음
"3,000"          —       왼쪽에만
   —            4000     오른쪽에만
```

한쪽이 글자이고 다른 쪽이 숫자인 것은 **거의 항상** 그렇습니다. 글자 그대로 견주면 하나도 맞지 않고, 그런 대사표는 아무 말도 해 주지 않습니다. 숫자로 읽히는 것을 숫자로 보는 규칙은 다른 곳에서 쓰던 것을 그대로 씁니다.

앞뒤 빈칸을 버리고 영문 대소문자를 가리지 않습니다. 옮겨 적힌 이름은 그 정도로 흔들리고, 그 흔들림까지 "없는 항목" 으로 세면 쓸모가 없어집니다.

## 조용히 빼지 않습니다

- **같은 키가 한쪽에서 거듭 나오면** 따로 알립니다. 대사에서 같은 번호가 두 번 나오는 것은 잡음이 아니라 발견입니다.
- **키 칸이 비어 견주지 못한 행** 도 셉니다. 조용히 빼면 "다 맞았다" 는 대사표가 나오고 수는 맞지 않습니다.

## 시트 두 개를 견줍니다

비교할 범위는 `장부!A1:C100` 처럼 적습니다. 대사는 대개 시트 두 개를 견주는 일이므로 한 시트 안으로 묶으면 정작 하고 싶은 일을 못 합니다. 시트 이름에도 느낌표가 들어갈 수 있으므로 **마지막** 느낌표에서 자릅니다.

결과는 **새 시트에만** 적습니다. 원래 자료는 건드리지 않습니다.
