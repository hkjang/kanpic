## 릴리즈 요약

v0.29.0은 **알림 메일**을 추가합니다. 관리자 콘솔에서 사내 SMTP를 연결하면 워크북 공유, 댓글, 멘션, 액세스 요청이 발생할 때 관련된 사람에게 메일이 나갑니다. 사내 릴레이를 염두에 두고 **인증 없이 서버 주소만으로도 동작**하며, 발송 결과는 모두 콘솔에 남습니다.

새 마이그레이션 `021_mail.sql`이 포함됩니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## SMTP 연결

- 콘솔에 **알림 메일** 화면이 생겼습니다. SMTP 서버·포트·보내는 주소·kanpic 주소를 넣고 이벤트별 스위치를 켜면 끝입니다.
- **사용자 이름을 비우면 인증 없이 발송합니다.** 사내 릴레이가 포트 25에서 인증 없이 받는 일반적인 구성을 그대로 지원합니다.
- 보안 모드 `auto`(기본)는 서버가 STARTTLS를 광고할 때만 사용하고, 광고하지 않으면 평문으로 진행합니다. 포트를 465로 지정하면 별도 설정 없이 TLS로 접속하고, 사설 인증서는 검증 생략 옵션으로 처리합니다. 인증이 필요한 릴레이에는 서버가 지원하는 PLAIN·LOGIN·CRAM-MD5 중에서 고릅니다.
- 보내는 주소를 비우면 `kanpic@SMTP호스트`를 사용하고, EHLO 인사에는 보내는 주소의 도메인을 씁니다.
- **연결 확인** 은 인사까지만 하고 메일을 보내지 않습니다. **테스트 메일 보내기** 는 실제로 한 통 보내고 결과를 그대로 보여 줍니다.

## 이벤트 알림

| 이벤트 | 받는 사람 |
| --- | --- |
| 워크북 공유 | 공유받은 사용자 |
| 댓글·답글 | 워크북 소유자, 사용자 공유 대상, 스레드 참여자 |
| 멘션 | `@`로 언급된 사람 |
| 액세스 요청 | 소유자와 공유 대상 |
| 요청 처리 결과 | 요청자 |

- 본인이 한 행동에 대한 메일은 보내지 않고, 멘션된 사람은 스레드 알림 대신 멘션 메일만 받습니다.
- 메일에는 계정 ID가 아니라 디렉터리의 **표시 이름**과 워크북 링크가 들어갑니다. 링크는 `mail.base_url`로 만들고, 값이 없으면 링크 없이 본문만 보냅니다.
- 이벤트별로 끄고 켤 수 있습니다.

## 발송 이력

- 모든 시도가 `mail_deliveries`에 남고 콘솔의 **발송 이력** 표에서 시각·이벤트·수신자·제목·상태·오류를 확인합니다. 상태로 걸러 볼 수 있습니다.
- 발송은 요청 처리와 분리된 백그라운드에서 이뤄지므로 SMTP가 느려도 화면이 기다리지 않습니다. 실패하면 2초 뒤 한 번 더 시도합니다.
- 수신자 주소는 사용자 디렉터리에서 찾고, 이메일이 없는 계정은 조용히 건너뜁니다.

## REST API

```http
GET  /api/v1/admin/mail/deliveries?status=sent|failed|queued&limit=100
POST /api/v1/admin/mail:test   {"recipient":"admin@corp.example"}
```

관리자만 호출할 수 있습니다. 시스템 설정의 **연결 테스트** 결과에도 `사내 SMTP` 항목이 추가됩니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. 실제 SMTP 대화를 받는 인프로세스 릴레이로 인증 없는 발송, 인증이 설정된 발송, 인증을 지원하지 않는 서버에 대한 안내, 발송 없는 연결 확인, 거절 응답 처리, 제목 인코딩과 본문의 마침표 이스케이프를 확인합니다.
- React/Vitest 29개 테스트 파일, 133개 테스트를 통과했습니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 73건을 통과했습니다. 실제 SMTP 서버를 띄워 콘솔의 연결 확인과 테스트 메일, 공유·댓글·멘션 메일이 각각 올바른 사람에게만 가는지, 표시 이름과 링크가 들어가는지, 이벤트를 끄면 그 메일만 멈추는지 확인했습니다.
