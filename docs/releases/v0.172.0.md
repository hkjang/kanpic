## 릴리즈 요약

v0.172.0은 **금액을 한글로** 적습니다. 품의서와 세금계산서에 필수인데 엑셀에서는 매크로를 짜야 하는 자리입니다.

```
=HANGULNUM(3200000)   →  삼백이십만
=HANGULWON(3200000)   →  일금 삼백이십만원정
```

## 문서에 적는 꼴을 따릅니다

십·백·천 앞의 `일` 은 뺍니다 — `15` 는 `십오` 지 `일십오` 가 아닙니다. 만·억·조 앞에서는 남깁니다 — `10000` 은 `만` 이 아니라 `일만` 입니다.

```
15          십오
1,004       천사
10,000      일만
100,000,001 일억일
1,234,567,890  십이억삼천사백오십육만칠천팔백구십
```

## 틀린 금액이 조용히 나가지 않게 합니다

**원 단위 아래는 오류입니다.** 조용히 버리면 적힌 금액과 셈한 금액이 달라집니다. 반올림은 사람이 뜻을 가지고 하게 둡니다.

**9,007,199,254,740,992 를 넘으면 오류입니다.** 표 프로그램의 숫자는 배정도 실수라 그 너머를 정확히 담지 못합니다. 담지 못한 값을 한글로 적으면 세금계산서에 **틀린 금액이 조용히** 들어갑니다. 못 적는다고 말하는 편이 낫습니다.

음수는 `마이너스` 를 앞에 붙입니다. 환불이 섞인 열에서 오류를 내면 열 전체가 멈추기 때문입니다.

## 검산

규칙을 **파이썬으로 먼저 세우고** Go 를 거기에 맞춰 짰습니다. 그 뒤 **22,033개 값** 을 두 구현으로 대 봤고 한 글자도 다르지 않았습니다. 금액이 틀리는 자리라 제 코드를 제 코드로 확인할 수 없습니다.

## 검증 결과

- 십·백·천의 `일` 생략, 만·억·조의 `일` 유지, 가운데 묶음이 비는 경우, 음수, 소수, 담을 수 있는 가장 큰 값과 그 너머.
- Go 시험 전체가 통과합니다.
