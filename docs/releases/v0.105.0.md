## 릴리즈 요약

v0.105.0은 **채우기 손잡이가 `1월` 을 이어 쓰지 못하던 것**을 고칩니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 1월을 끌면 1월만 나왔다

채우기 손잡이는 숫자(`1, 2` → 3, 4), 날짜(하루씩), 뒤에 숫자가 붙은 이름(`항목 1` → `항목 2`)까지는 이어 썼습니다. 그런데 `1월` 을 끌면 1월만 계속 복사되었습니다. `월요일`, `1분기`, `Jan`, `Mon` 도 마찬가지입니다.

이제 이어집니다 — 한국어 요일(`월`·`월요일`), 월(`1월`~`12월`), 분기(`1분기`~`4분기`), 영문 요일과 월(`Mon`·`Monday`·`Jan`·`January`).

## 12월 다음은 13월이 아니다

숫자 규칙만으로는 이 부분을 표현할 수 없습니다. `1월` 은 "숫자 1에 월이 붙은 것" 으로도 읽히지만, 그렇게 세면 12월 다음이 13월이 됩니다. 되돌아오는 자리를 아는 것은 목록뿐이라 이름 목록으로 두었고, 목록 규칙이 숫자 규칙보다 먼저입니다.

씨앗을 여럿 고르면 간격을 지킵니다. `월`, `수` 는 금·일·화로, `1월`, `4월` 은 7월·10월로 이어집니다. 영문은 쓴 모양을 따라 `mon` 은 `tue`, `MON` 은 `TUE` 입니다.

## 숫자가 앞에 오는 이름

`3반`, `1차 검토`, `08호` 처럼 숫자가 앞에 오면 그대로 복사되었습니다. 뒤에 오는 경우는 이미 되던 일입니다. 이제 앞에 와도 세어 나가고, `08호` 처럼 자릿수를 맞춰 쓴 값은 자릿수를 지킵니다. 되돌아올 자리가 없는 규칙이므로 계속 늘어납니다.

## 이어 쓰지 않는 것

목록에 없는 값(`제품A`)은 그대로 복사합니다. 서로 다른 목록을 섞은 씨앗(`월요일`, `Jan`), 간격이 일정하지 않은 씨앗(`월`, `수`, `목`), 제자리걸음(`월`, `월`)도 무엇을 이어야 할지 알 수 없으므로 복사합니다.

## 검증 결과

- 단위 테스트 8가지로 이어 쓰기와 되돌아옴, 간격 유지, 대소문자, 그리고 이어 쓰지 **않아야** 하는 여섯 가지 경우를 확인합니다.
- 브라우저 E2E로 실제 격자에서 손잡이를 끌어 `11월` 이 12월·1월·2월로 이어지는지 봅니다. 고치기 전 번들에서 실패하는 것을 확인했습니다.
- `go vet ./...`, `go test ./...`, PostgreSQL 통합 테스트, React/Vitest, TypeScript 타입 검사, Vite 프로덕션 빌드, Playwright E2E를 통과했습니다.
