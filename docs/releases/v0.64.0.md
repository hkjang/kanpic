## 릴리즈 요약

v0.64.0은 **부분합**을 더합니다. 한 열을 기준으로 표를 묶어 그룹마다 소계 행을 넣고, 그 그룹의 데이터 행을 접을 수 있게 묶어 줍니다. 지역별 매출표에서 지역마다 합계 줄을 만드는, 보고서를 만들 때 손으로 하던 일입니다.

마이그레이션은 없습니다. 서버 변경도 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 새로운 기능

**데이터 › 부분합…** 에서 그룹 기준 열, 집계 함수(합계·평균·개수·최대·최소), 집계할 열을 고르면 그룹 수와 추가될 행 수를 먼저 보여 주고, 실행하면 각 그룹 아래에 `<그룹> 합계` 행이 들어가고 데이터 행이 접히는 그룹으로 묶입니다.

- 그룹 기준 열이 정렬되어 있지 않으면 같은 값이 여러 그룹으로 나뉜다고 알려 줍니다.
- 표 아래에 다른 내용이 있으면 몇 행을 밀어내는지 미리 알려 줍니다.
- 대상 표는 서버가 알고 있는 시트 내용에서 찾습니다. 화면에 불러온 행만 묶는 일이 없습니다.

## 만들면서 잡은 문제 두 가지

브라우저에서 직접 돌려 보고 두 가지를 고쳤습니다.

**1. 전체 합계가 소계를 다시 더했습니다.** `=SUBTOTAL(109, …)` 의 `1xx` 코드는 원래 중첩된 소계를 무시하지만, 이 엔진은 셀의 값만 받고 그 값이 어떤 수식에서 나왔는지 모릅니다. 그래서 970(=485+485)이 나왔습니다. 전체 합계는 이제 소계를 건너뛰고 데이터 구간만 직접 가리킵니다(`=SUM(C2:C3,C5:C7)` → 485). 평균·최대처럼 단순 합산으로 대신할 수 없는 집계에서도 정확합니다.

**2. 소계 행에 이전 값이 남았습니다.** 소계 행이 끼어드는 자리에는 원래 다른 행이 있었고, 집계하지 않는 열은 그 값을 그대로 물려받아 `부산 합계 · 연필 · 175` 처럼 보였습니다. 소계 행의 모든 칸을 쓰도록 고쳤습니다.
