## 릴리즈 요약

v0.123.0은 빠른 채우기가 **자릿수를 맞출 줄** 알게 합니다. `7` 을 `007` 로 채워 두면 나머지도 세 자리로 맞춥니다.

## 사번과 상품코드는 늘 자릿수를 맞춘다

v0.122.0에 한계로 적어 둔 것입니다. 자릿수 맞추기를 모르니 `7` → `007` 을 **앞에 "00" 을 붙인 것** 으로 읽었고, 그러면 `12` 가 `0012` 가 됩니다.

이제 채워 맞추는 규칙을 먼저 봅니다. 두 규칙이 같은 본보기를 설명할 때 **채워 맞추는 쪽이 다음 줄에서도 맞을 확률이 훨씬 높기** 때문입니다.

| 본보기 | 읽는 방식 | `12` 는 |
| :--- | :--- | :--- |
| `7` → `007`, `12` → `012` | 세 자리로 채움 | `012` |
| `7` → `007`, `12` → `0012` | 앞에 `00` 을 붙임 | `0012` |

둘 다 사람이 보여 준 대로입니다. 어느 쪽인지는 **두 번째 본보기가** 말해 줍니다.

## 채움 글자는 자리를 메우는 글자여야 한다

만들다 잡은 것입니다. "앞에 붙은 같은 글자는 채움" 으로만 보면 `홍`+`길동` → `홍길동` 에서 **성이 채움 글자** 가 되고, 다음 줄의 김철수가 **홍철수** 가 됩니다.

채움 글자는 `0` 과 띄어쓰기만 인정하고, `0` 일 때는 원본이 숫자로만 되어 있을 것을 함께 봅니다.

## 검증 결과

- `7` → `007`, `12` → `012` 로 채우고 `5` → `005`, `123` → `123`(이미 세 자리) 이 되는지 봅니다.
- 같은 본보기를 앞자리 붙이기로 읽어야 하는 경우와 가르는지 봅니다.
- 성을 채움 글자로 읽지 않는지, 어느 쪽으로도 설명되지 않으면 채우지 않는지 봅니다.
- 브라우저에서 `Ctrl+E` 로 열어 실제로 채워지는지 봅니다.
