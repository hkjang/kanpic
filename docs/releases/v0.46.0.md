## 릴리즈 요약

v0.46.0은 **행과 열을 끌어서 옮기는 기능**을 더합니다. 지금까지 열 순서를 바꾸려면 잘라내기 → 열 삽입 → 붙여넣기 → 빈 열 삭제를 거쳐야 했고, 그 과정에서 수식이 깨지기 쉬웠습니다. 이제 이미 선택된 머리글을 다시 잡아 끌면 되고, 그 행·열을 가리키던 수식은 새 위치를 가리키도록 다시 쓰입니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 새로운 기능

- **머리글 드래그 이동**: 행 또는 열 머리글을 클릭해 선택한 뒤 다시 잡아 끌면 이동합니다. 끄는 동안 놓일 자리에 굵은 안내선이 표시되고, 커서는 잡는 손 모양으로 바뀝니다. 선택 범위 밖의 머리글을 누르면 지금까지처럼 선택이 시작되므로 두 동작이 서로 방해하지 않습니다.
- **머리글 메뉴의 한 칸 이동**: 오른쪽 클릭 메뉴에 **왼쪽으로 이동**/**오른쪽으로 이동**(행은 위/아래)이 추가되어 드래그 없이도 순서를 바꿀 수 있습니다.
- **수식 참조 재작성**: 이동은 삽입·삭제와 같은 구조 변경 경로를 지나므로 수식, 병합 범위, 조건부 서식, 데이터 검증, 필터 뷰, 보호 범위, 차트·피벗 원본, 이름 범위, 댓글 위치, 열 너비·행 높이, 숨김과 그룹이 모두 함께 움직이고 변경 직전 복구 버전(`열 이동 전 자동 백업`)이 생성됩니다.
- 이동은 아무것도 지우지 않으므로 `#REF!`를 만들지 않습니다. 범위 한가운데를 옮겨 범위가 갈라지는 경우에는 원래 담고 있던 셀을 모두 포함하도록 범위를 넓힙니다. 합계에서 셀이 조용히 빠지는 쪽이 더 위험하기 때문입니다.

REST `PATCH /api/v1/sheets/{sheetId}/structure:apply` 와 `spreadsheet.structure.apply` MCP 도구는 `action:"move"` 와 `destination`(이동 전 좌표 기준으로 밴드가 끼어들 위치)을 받습니다.
