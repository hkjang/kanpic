## 릴리즈 요약

v0.23.0은 **메뉴**를 완성합니다. 지금까지 그리드에만 있던 컨텍스트 메뉴를 **시트 탭·차트·홈 화면 워크북 카드**까지 넓혀 모두 같은 부품으로 통일했고, Google Sheets와 비교해 비어 있던 메뉴 기능을 채웠습니다. **인쇄**, **특수 붙여넣기**, **눈금선과 전체 화면**, **글꼴·색·회전 서식**, **데이터 정리와 텍스트를 열로 분할**, **함수 목록**이 새로 들어왔고, 수식 엔진에 **함수 31개**를 추가했습니다.

필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나이며 새 마이그레이션은 없습니다.

## 컨텍스트 메뉴 확장

- **시트 탭**은 활성 탭이 아니어도 마우스 오른쪽 클릭으로 메뉴가 열립니다. 이름 변경, 복제, 다른 워크북으로 복사, 좌우 이동, 탭 색상, 숨기기, 삭제, 모든 시트 관리를 제공하고 메뉴를 열면 해당 시트로 이동합니다.
- **시트 탭의 빈 영역**에서는 새 시트, 모든 시트 관리, 숨긴 시트 목록을 바로 사용할 수 있습니다. 숨긴 시트 이름을 선택하면 즉시 다시 표시합니다.
- **차트**에서 차트 설정, 원본 데이터 범위로 이동, SVG·PNG 내보내기, 차트 삭제를 실행합니다. 차트 삭제는 그동안 설정 창을 거쳐야만 가능했습니다.
- **홈 화면 워크북 카드**는 열기, 새 탭에서 열기, 공유, 즐겨찾기, 이름 변경, 복제, 링크 복사, 휴지통으로 이동을 제공합니다. 목록의 빈 영역에서는 새 워크북, 파일 가져오기, 휴지통 보기를 제공합니다.
- 시트 탭과 워크북 카드의 자체 메뉴 마크업을 그리드와 같은 공용 컴포넌트로 교체했습니다. 이제 모든 메뉴가 방향키 이동, `→` 하위 메뉴 열기, `Enter` 실행, `Esc` 닫기, 화면 밖으로 나가지 않는 위치 보정을 동일하게 지원하고, 메뉴에 접근성 이름이 붙습니다.

## 메뉴 막대에 추가된 기능

- **파일**: 새 워크북, 사본 만들기, 워크북 이름 변경, 인쇄, 휴지통으로 이동
- **수정**: 특수 붙여넣기 — 값만, 서식만, 행과 열 바꿔 붙여넣기
- **보기**: 눈금선 표시, 전체 화면(`F11`)
- **삽입**: 함수(SUM·AVERAGE·COUNT·COUNTA·MAX·MIN·MEDIAN·PRODUCT와 전체 목록), 링크, 드롭다운
- **서식**: 글꼴, 글꼴 크기, 텍스트 색, 채우기 색, 텍스트 회전
- **데이터**: 선택 열 기준 A→Z·Z→A 정렬, 데이터 정리(중복 항목 삭제·공백 제거), 텍스트를 열로 분할
- **도움말**: 함수 목록

새 명령은 `Ctrl/⌘ + K` 빠른 이동에서도 검색해 실행할 수 있습니다.

## 인쇄

`Ctrl/⌘ + P` 또는 파일 › 인쇄는 현재 시트에서 값이 있는 범위를 표로 만들어 브라우저 인쇄 화면을 엽니다. 캔버스 그리드는 그대로 인쇄할 수 없으므로 셀의 굵게·기울임·색·정렬·글꼴 크기를 반영한 인쇄용 문서를 만들어 사용합니다. 행과 열 머리글이 함께 인쇄되고, 눈금선은 보기 메뉴 설정을 따르며, 셀 내용은 이스케이프되어 마크업으로 해석되지 않습니다.

## 데이터 정리와 텍스트를 열로 분할

셀 하나만 선택하면 주변 데이터 블록 전체가, 범위를 선택하면 그 범위가 대상입니다.

- **중복 항목 삭제**: 같은 내용의 행을 첫 번째만 남기고 아래 행을 위로 당깁니다. 첫 행이 머리글로 보이면 유지합니다.
- **공백 제거**: 앞뒤 공백과 중간의 연속 공백을 정리하고 수식 셀은 건너뜁니다.
- **텍스트를 열로 분할**: 쉼표·세미콜론·탭·공백 또는 자동 감지한 구분자로 나눠 오른쪽 열에 채웁니다. 숫자는 숫자로 저장하고, 오른쪽 열에 데이터가 있으면 덮어쓰기 전에 확인을 받습니다.

세 작업 모두 실행 전에 대상 건수를 확인받고 하나의 원자적 변경으로 저장되므로 실행 취소와 버전 이력에 그대로 남습니다.

## 수식 함수 31개 추가와 함수 목록

- 추가된 함수: `COUNTA`, `COUNTBLANK`, `MEDIAN`, `PRODUCT`, `ROUNDUP`, `ROUNDDOWN`, `ABS`, `INT`, `SQRT`, `MOD`, `POWER`, `NOT`, `IFERROR`, `LEN`, `TRIM`, `UPPER`, `LOWER`, `PROPER`, `SUBSTITUTE`, `FIND`, `SEARCH`, `REPT`, `TEXTJOIN`, `VALUE`, `HYPERLINK`, `TODAY`, `NOW`, `YEAR`, `MONTH`, `DAY`, `WEEKDAY`
- `IFERROR`는 인수를 평가하기 전에 오류를 가로채므로 `=IFERROR(1/0,"안전")`처럼 사용할 수 있습니다.
- 도움말 › 함수 목록은 새 endpoint `GET /api/v1/formula/functions`의 카탈로그를 그대로 보여 줍니다. 목록과 실제 계산 가능한 함수가 어긋나지 않도록 서버가 단일 출처입니다.

## 수정된 문제

- 시트 탭 메뉴가 활성 탭의 ⋯ 버튼에서만 열려 다른 시트를 조작하려면 먼저 탭을 눌러야 했습니다.
- 차트를 삭제하려면 설정 창을 열어야 했고, 차트에서 원본 데이터로 이동할 방법이 없었습니다.
- 시트 탭과 워크북 카드 메뉴는 키보드로 조작할 수 없고 `Esc`로 닫히지 않았습니다.
- 컨텍스트 메뉴의 접근성 이름이 메뉴 역할을 가진 요소가 아니라 바깥 상자에 붙어 있었습니다.
- 사용자 안내서가 `ABS`·`TRIM`·`LEN`·`UPPER`·`LOWER`를 지원 함수로 설명했지만 실제로는 `#NAME?`을 반환했습니다. 이번 릴리즈에서 실제로 동작합니다.
- 선택 범위를 지정한 뒤 함수를 삽입하면 활성 셀이 이동하면서 입력하던 수식이 지워질 수 있었습니다.

## REST API

```http
GET /api/v1/formula/functions
```

로그인한 사용자면 호출할 수 있고 함수 이름, 분류, 구문, 설명만 반환합니다.
