# v0.225.0

## 외부 호출 함수 — 기본은 꺼짐

수식 함수 둘이 생겼습니다.

```
=WEBSERVICE("https://api.example.com/rate")        본문을 글자로
=IMPORTDATA("https://data.example.com/sales.csv")  CSV 를 표로 (spill)
```

둘 다 **관리자가 켜기 전에는 아무 데도 부르지 않습니다.** 켜도 **허용 호스트
목록에 적은 곳만** 부릅니다. 목록이 비어 있으면 켜져 있어도 아무 데도 못 갑니다.

| 설정 | 기본 | 뜻 |
|---|---|---|
| `external.enabled` | 꺼짐 | 외부 호출 사용 |
| `external.allowed_hosts` | 비어 있음 | `api.example.com` 또는 `*.example.com` |
| `external.timeout_seconds` | 10 | 한 건의 제한 시간 |
| `external.max_kb` | 1024 | 응답 최대 크기 |
| `external.cache_seconds` | 300 | 같은 주소를 다시 부르지 않는 시간 |

## 밖으로 나가는 스프레드시트가 지켜야 하는 것

셀 하나가 밖을 부를 수 있으면, 그 셀은 이 서버 옆의 데이터베이스나 클라우드의
메타데이터 주소도 부를 수 있습니다. 함수를 모든 사용자에게 주려면 정책이
함수보다 먼저 있어야 합니다.

- **https 만.** `http://` 는 거절합니다.
- **허용 목록.** `*.example.com` 은 그 아래 호스트만이고 `example.com` 자신은 아닙니다. `evil-example.com` 도 아닙니다.
- **사설·루프백·링크로컬 차단.** DNS 를 먼저 풀어 나온 주소가 `10.`, `192.168.`, `127.`, `169.254.169.254`, `100.64.` 이면 허용 목록에 있어도 거절합니다.
- **DNS 리바인딩 방지.** 검사한 그 IP 로만 접속합니다. 검사와 접속 사이에 이름이 바뀌어도 사설 주소로 새지 않습니다.
- **리다이렉트 거절.** 허용된 주소가 다른 곳으로 넘기면 따라가지 않습니다.
- **크기와 시간 상한.** 넘으면 잘라 쓰지 않고 거절합니다.
- **주소에 든 자격 증명 거절.** `https://user:pw@…` 는 받지 않습니다.
- 한 번의 재계산에 외부 호출은 20개까지입니다.

## 수식 엔진은 연결을 열지 않는다

`IMPORTRANGE` 와 같은 얼개입니다. 저장소가 수식에서 주소를 미리 훑어 정책 아래
가져오고, 엔진은 넘겨받은 것만 읽습니다. 평가는 동기적이고, 정책은 한 곳에
있습니다. 주소를 다른 칸에서 만들어 넘기는 `=WEBSERVICE(B4)` 는 평가 전에 알 수
없으므로 큰따옴표 안에 직접 적으라고 답합니다.

거절은 언제나 이유를 말합니다. 빈 값은 "자료 없음" 으로 읽히는데, 진실은
"허용되지 않음" 이기 때문입니다.
