## 릴리즈 요약

v0.54.0은 수동 갱신 피벗에 **원본 변경 알림**을 더합니다. 수동 모드 피벗은 만들어진 시점의 숫자를 계속 보여 주는데, 그 숫자가 아직 유효한지 알 방법이 없었습니다. 오래된 합계를 최신으로 착각하기 딱 좋은 상태였습니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 새로운 기능

- 피벗 결과 창에 **원본이 바뀌었습니다 · 지금 갱신하면 반영됩니다** 알림이 붙습니다. 마지막 갱신 이후 원본 범위의 셀이 수정되었다는 뜻입니다.
- **숫자는 바꾸지 않습니다.** 알림이 떠도 화면에는 갱신 당시의 값이 그대로 남습니다. 보고 있는 숫자가 언제 것인지 분명한 편이, 소리 없이 값이 바뀌는 것보다 낫습니다.
- 판정은 워크북 버전이 아니라 **원본 범위 셀의 최종 수정 시각**으로 합니다. 워크북 버전은 시트 어디를 고쳐도 올라가므로 그것으로 판정하면 관계없는 편집에도 알림이 뜹니다.
- `GET /api/v1/pivots/{pivotId}/data` 응답에 `stale` 과 `source_changed_at` 이 추가됩니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. 새 단위 테스트는 생성 직후 최신 상태, 원본 변경 후 알림과 캐시 유지, 갱신 후 알림 해제를 확인합니다.
- PostgreSQL 통합 테스트 전체를 통과했습니다.
- React/Vitest 39개 테스트 파일, 209개 테스트를 통과했습니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 116건을 통과했습니다. 새 테스트는 원본을 고친 뒤 캐시된 합계(230)가 유지된 채 알림이 뜨고, 갱신하면 알림이 사라지며 합계가 1030으로 바뀌는지 확인합니다.
- 실제 브라우저에서 시트가 900을 가리키는 동안 피벗이 갱신 전 180/50/230을 알림과 함께 보여 주는 것을 눈으로 확인했습니다.
