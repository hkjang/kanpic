## 전부 "며칠인가" 에 달려 있습니다

`DISC`, `INTRATE`, `RECEIVED`, `PRICEDISC`, `YIELDDISC`, `PRICEMAT`, `YIELDMAT`, `TBILLPRICE`, `TBILLYIELD`, `TBILLEQ` — 이름은 달라도 하는 일은 같습니다. 결제일과 만기일 사이가 **한 해의 몇 분의 몇** 인지를 세고, 거기에 이율을 곱하거나 나눕니다.

그 셈은 `=YEARFRAC` 이 이미 하고 있으므로 그대로 씁니다. 옮겨 적으면 기준(basis)을 한쪽만 늘리게 됩니다. 기준은 `0`~`4` 로 `=YEARFRAC` 과 같은 규칙입니다.

결제일이 만기일보다 뒤면 `#NUM!` 입니다. 단기 국채는 만기가 결제일에서 **한 해를 넘을 수 없습니다.**

## 분수로 적은 가격

```
=DOLLARDE(1.02, 16)  ->  1.125    "1과 16분의 2"
=DOLLARFR(1.125, 16) ->  1.02
```

분모의 자리 수만큼 밀어 읽습니다. 16도 32도 두 자리입니다.

## 같은 값이 나오면 오히려 틀린 것입니다

기댓값은 파이썬으로 따로 계산해 맞췄습니다. 그런데 왕복 시험 두 개의 값을 **계산하지 않고 지어내** 적었다가 걸렸습니다.

할인율로 매긴 가격에서 수익률을 되물으면 할인율과 **다른** 값이 나옵니다. 두 셈이 나누는 밑이 다르기 때문입니다 — 할인율은 상환액으로, 수익률은 가격으로 나눕니다. 같은 값이 나왔다면 오히려 한쪽이 틀린 것입니다. 계산해 보고 그 값을 적었습니다.
