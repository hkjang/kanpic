## 릴리즈 요약

v0.173.0은 **목표값 찾기가 표를 쓰는 워크북에서 아예 동작하지 않던 것** 을 고칩니다. 데이터 표를 만들려고 목표값 찾기를 들여다보다 나왔습니다.

## 격자에서는 되는데 목표값 찾기에서는 안 됐습니다

```
A6 = SUM(매출표[금액])*A5     격자에서는 600
목표값 찾기 → "찾을 셀이 바꿀 셀의 영향을 받지 않습니다"
```

워크북을 통째로 읽어 다시 셈하는 자리인데 **표와 이름 있는 수식을 엔진에 넘기지 않았습니다.** 그러면 그 수식이 풀리지 않고, **풀리지 않는 수식은 의존성 그래프에 오르지 못합니다** — 무엇에 기대는지 알아내려면 먼저 풀려야 하기 때문입니다.

표 머리글을 고쳤을 때 옛 값이 남던 것(v0.156.0)과 **같은 뿌리** 입니다. 같은 성질이 다른 자리에서 다시 나왔습니다.

수식 설명도 같은 자리를 지납니다. 표를 모르면 격자에서는 멀쩡히 셈되는 칸을 풀 수 없는 수식이라고 답했습니다.

## 언제부터였나

표는 **v0.156.0** 부터, 이름 있는 수식은 **v0.148.0** 부터 이랬습니다.

## 읽어 오는 자리를 하나로 묶었습니다

두 곳에 나누어 적으면 한쪽만 늘어납니다 — 이번 결함이 바로 그 모양입니다.

## 검증 결과

- 표를 쓰는 수식에서 목표값 찾기가 `4` 를 찾아내는지, 수식 설명이 기대는 칸을 찾아내는지 HTTP 계층에서 확인합니다.
- Go 시험 전체와 통합 시험 전체가 통과합니다.
