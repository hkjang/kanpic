## 릴리즈 요약

v0.157.0은 표를 **살아 있는 것** 으로 만듭니다. 바로 아래 줄에 값을 넣으면 표가 그 줄을 삼킵니다.

## 자료를 한 줄 더 붙이는 일

표를 만든 뒤 자료를 한 줄 더 붙이는 것은 가장 흔한 일입니다. 그때마다 사람이 범위를 손으로 늘려야 한다면, `=SUM(매출표[금액])` 은 **새로 넣은 줄을 빼고** 셈합니다. 답이 나오기는 하는데 틀린 답입니다.

```
매출표 A1:B3        대구 300 을 4행에 넣으면
  -> A1:B4          합계가 그 저장에서 곧바로 600
```

**다시 셈하기 전에 늘립니다.** 나중에 늘리면 한 박자 늦은 답이 한 번 저장됩니다.

## 삼키지 않는 것들

- **한 줄 건너뛴 자리.** 표 아래 따로 적은 메모까지 표가 되면 열 이름이 제멋대로 늘어납니다.
- **빈 칸.** 지우는 것은 늘리는 까닭이 되지 않습니다.
- **남의 표를 밟는 자리.** 걸친 표는 한쪽에서 행을 지우면 다른 쪽이 조용히 어그러집니다.

**옆으로도 늘리지 않습니다.** 열을 하나 더 쓰는 것은 표의 생김새를 바꾸는 일이라 사람이 뜻을 가지고 하는 편이 낫습니다.

## 검증 결과

- 메모리와 Postgres 양쪽에서 한 줄 넣기, 여러 줄, 건너뛴 자리, 빈 칸, 남의 표를 밟는 자리를 확인합니다.
- 합계가 늘어난 그 저장에서 곧바로 맞는지 확인합니다.
- Go 시험 전체와 통합 시험 전체가 통과합니다.
