## 릴리즈 요약

v0.213.0은 **공개된 링크를 한 번에** 닫습니다.

## 마흔일곱 번 누르는 사람은 없습니다

하나씩 닫는 단추는 전부터 있었습니다. 그런데 `링크 공개 47개` 를 보고 마흔일곱 번 누르는 사람은 없습니다. 몇 개는 남고, **남은 것은 아무도 세지 않습니다.**

**워크북 거버넌스** 에서 `링크 공개` 나 `조직 전체` 를 고르면 목록 위에 **이 목록 전체 공개 해제** 가 나옵니다.

## 고른 거르개만 닫습니다

`링크 공개` 를 눌렀다고 `조직 전체` 가 함께 닫히지 않습니다 — 사람이 보고 있던 목록과 실제로 바뀐 것이 달라지면 안 됩니다. 닫을 수 있는 거르개가 아니면 **물리칩니다.** 무엇을 닫는지 모르는 채로 자료가 바뀌어서는 안 됩니다.

## 한 번에 다 닫지 않습니다

500개까지 닫고 **남은 수를 다시 세어** 돌려줍니다.

```
2개를 제한했습니다. 아직 31개 남았습니다. 다시 눌러 주세요.
```

조직이 크면 요청 하나가 몇 분씩 걸리는 편보다, 몇 번 나눠 누르되 몇 개가 남았는지 아는 편이 낫습니다. 목록이 잘린 것을 조용히 넘기면 "다 닫았다" 는 말과 남아 있는 워크북이 어긋납니다.

못 닫은 것이 있으면 그 수도 함께 적고, 일괄 해제한 일은 **관리자 행위 기록** 에 남습니다.

## 검증 결과

- 고른 거르개만 닫는지, 남은 수를 세는지, 닫을 수 없는 거르개를 물리치는지, 관리자만 부를 수 있는지 시험합니다.
- 브라우저에서 **링크 공개는 닫히고 조직 공개는 그대로인지** 와 기록에 남는지까지 확인합니다.
- 웹 시험 457개와 Go 시험 전체가 통과하고 `gofmt` 도 확인했습니다.
