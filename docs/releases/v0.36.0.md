## 릴리즈 요약

v0.36.0은 스프레드시트에서 가장 아쉬웠던 두 가지를 채웁니다. **QUERY** 는 필터·정렬·피벗을 수식 한 줄로 대신하고, **SPARKLINE** 은 셀 안에 미니 차트를 그립니다. 두 기능을 함께 보여 주는 **QUERY 데이터 조회** 템플릿도 추가했습니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## QUERY

```
=QUERY(A1:D100,"select A, sum(C), count(A) where B = '온라인' and C > 1000000 group by A order by sum(C) desc limit 5")
```

- 열은 **범위 안 순서대로** `A`, `B`, `C`… 로 부릅니다. 시트의 열 문자와는 무관하므로 범위를 옮겨도 질의는 그대로입니다.
- `select`(`sum`·`count`·`avg`·`min`·`max`, `select *`), `where`, `group by`, `order by`, `limit`, `offset`, `label` 을 지원합니다.
- 조건에는 `= != <> < <= > >=` 와 `contains`, `starts with`, `ends with`, `matches`, `like`, `is null`, `is not null` 을 쓰고 `and`·`or`·`not` 과 괄호로 묶습니다.
- 결과는 머리글을 포함한 표로 펼쳐집니다. 세 번째 인수로 머리글 행 수를 지정할 수 있고, 생략하면 첫 행이 모두 글자인지 보고 판단합니다. 조건에 맞는 행이 없으면 머리글만 남습니다.
- 집계하지 않은 열을 묶지 않고 고르거나, 범위 밖의 열을 부르거나, 질의 문법이 틀리면 무엇이 문제인지 알려 줍니다.

## SPARKLINE

```
=SPARKLINE(B2:G2)
=SPARKLINE(B2:G2,{"charttype","column";"color","#5268a6";"negcolor","#c2413b"})
```

- `line`(기본)·`column`·`bar`·`winloss` 네 가지를 셀 크기에 맞춰 그립니다. 표 오른쪽에 추세 열을 하나 두는 용도입니다.
- `color`·`negcolor`·`highcolor` 로 색을, `max`·`min` 으로 눈금 범위를, `axis` 로 0 기준선을, `linewidth` 로 선 굵기를 정합니다. 옵션은 이름과 값을 짝지은 배열이라 `{"이름","값";"이름","값"}` 형태로 씁니다.
- 차트 셀에는 글자가 표시되지 않고, 셀을 선택하면 수식 입력창에서 원래 수식을 볼 수 있습니다. **화면 낭독기에는 차트 모양을 말로 설명합니다** — 예를 들어 "선형 미니 차트, 값 6개, 90부터 210까지, 상승".

## QUERY 데이터 조회 템플릿

판매 시트에는 제품별 6개월 판매와 추세 스파크라인이, 주문 시트에는 원본 데이터가, 조회 시트에는 지역별 매출을 뽑는 QUERY 한 줄과 함께 쓸 수 있는 질의 예시가 들어 있습니다. 템플릿은 72종이 되었습니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. QUERY의 절별 동작·텍스트 연산자·머리글 판단·오류 보고와 SPARKLINE의 옵션 해석을 검사하고, 템플릿 72종의 모든 수식이 오류 없이 계산되는지 확인합니다.
- React/Vitest 34개 테스트 파일, 170개 테스트를 통과했습니다. 차트 값 인식과 캔버스 그리기를 단위 테스트로 검사합니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 88건을 통과했습니다. 실제 브라우저에서 QUERY 결과가 머리글과 함께 펼쳐지는지, 스파크라인 셀이 글자 없이 그려지고 낭독기 설명이 붙는지 확인했습니다.
