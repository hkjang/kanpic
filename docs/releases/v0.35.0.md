## 릴리즈 요약

v0.35.0은 **매일 쓰는 감각**을 채웁니다. 여러 셀을 선택하면 합계·평균·개수가 바로 보이고, 같은 열에 이미 쓴 값을 다시 입력할 때는 목록에서 골라 채우며, 수식 안에 `{1,2;3,4}` 형태의 표를 직접 쓸 수 있습니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 선택 범위 요약

- 두 셀 이상을 선택하면 시트 탭 줄 오른쪽에 **합계·평균·개수** 가 나타납니다. 수식을 쓰지 않고 숫자를 확인하는 자리입니다.
- 요약을 클릭하면 합계·평균·숫자 개수·개수·최소·최대 중에서 표시할 항목을 고를 수 있고, 선택은 브라우저에 기억됩니다.
- 숫자가 아닌 셀은 개수에만 반영되고 합계·평균에는 들어가지 않습니다. 텍스트로 저장된 숫자는 숫자로 셉니다. 한 셀만 선택했거나 값이 없으면 표시하지 않습니다.

## 열 값 자동완성

- 빈 셀에 글자를 입력하면 **같은 열에 이미 쓰인 값** 이 제안됩니다. 부서명이나 분류처럼 반복해 넣는 열에서 오타 없이 채울 수 있습니다.
- `Tab` 으로 채우고 `↑`·`↓` 로 고르며 `Esc` 로 닫습니다. **`Enter` 는 언제나 입력한 그대로 확정** 하므로, 기존 값의 앞부분과 같은 새 값을 넣을 때 마음대로 바뀌지 않습니다.
- 자주 쓰인 값이 먼저 나오고 수식이 든 셀과 숫자는 제안하지 않습니다. `=` 로 시작하면 함수 자동완성으로 바뀝니다.

## 배열 리터럴

- `={1,2;3,4}` 처럼 중괄호로 표를 수식 안에 직접 씁니다. 쉼표가 열을, 세미콜론이 행을 나눕니다.
- 기준표를 셀에 두지 않고 `=XLOOKUP(점수,{0;60;80},{"미흡";"보통";"우수"},"미흡",-1)` 처럼 쓸 수 있고, `SUM`·`SUMPRODUCT`·`INDEX` 같은 함수와 셀 참조도 그대로 넣을 수 있습니다.
- 행마다 값 개수가 다르면 오류로 알려 주고, 괄호 밖의 세미콜론은 지금까지처럼 인수 구분자로 동작합니다.

## 수정된 문제

- AI 패널 스크롤을 확인하는 E2E 검사가 스크롤 위치를 같은 프레임에서 읽어 간헐적으로 실패했습니다. 브라우저가 다음 프레임에 위치를 반영하므로 폴링하도록 바꿨습니다. 패널 동작 자체는 정상이었습니다.
