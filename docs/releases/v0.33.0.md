## 릴리즈 요약

v0.33.0은 편집기의 오른쪽 기능 패널을 작업에 맞게 넓히고, Workbook Agent를 이전 대화와 실행 결과를 이어서 사용하는 멀티턴 챗봇으로 확장한 릴리즈입니다. 차트를 만든 뒤 “선 차트로 바꿔줘”처럼 후속 요청하면 현재 객체의 ID와 revision을 확인해 안전한 변경 계획을 만듭니다.

데이터베이스 마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나이며, `BOOTSTRAP_ADMIN_ID`·`BOOTSTRAP_ADMIN_PASSWORD`와 Keycloak Confidential Client의 `client_secret` 설정도 그대로 사용할 수 있습니다.

## 크기 조절 가능한 기능 패널

- Workbook Agent, 자동화, 차트, 피벗, 댓글, 충돌 및 버전 이력 패널의 왼쪽 경계를 드래그해 너비를 조절할 수 있습니다.
- 키보드 `←`/`→`, `Home`/`End`와 더블 클릭 초기화를 지원합니다.
- 패널 종류별 너비를 브라우저에 저장해 다음에 다시 열 때 복원합니다.
- 작은 화면에서는 기존 반응형 동작을 유지하고, 가능한 화면 너비를 넘지 않도록 제한합니다.

## 멀티턴 Workbook Agent

- 결과 뒤에도 입력창을 유지하고 같은 `conversation_id`로 후속 요청을 이어갑니다.
- 워크북별 마지막 대화를 자동 복원하며, 대화 목록에서 이전 세션을 전환하거나 새 대화를 시작할 수 있습니다.
- 최근 대화 메시지와 최대 6개의 실행 상태·요약·변경 주소·도구 결과를 구조화된 작업 메모리로 전달합니다.
- 적용·완료된 작업과 Undo·취소·실패한 작업을 구분하고, 현재 워크북 객체 목록을 최종 상태로 취급합니다.
- 기존 차트 변경은 현재 차트 ID와 revision을 검증한 `update_chart` 도구로 계획·승인·검증·Rollback합니다.
- 결과 유형과 상태에 맞는 다음 작업을 제안하며, 추천 문구를 눌러 후속 요청을 바로 편집할 수 있습니다.
- 새 후속 요청은 같은 대화의 미승인 계획을 취소하고 최신 계획으로 대체합니다.

## 데이터 보호와 API

- 작업 메모리에는 셀 값이나 보고서 셀 내용을 저장하지 않고 변경 주소·종류와 차트/보고서 객체 메타데이터만 포함합니다.
- 현재 객체 목록에 없는 과거 객체 ID는 재사용하지 않도록 시스템 프롬프트와 서버 검증을 함께 적용합니다.
- `GET /api/v1/workbooks/{workbookId}/agent/conversations`로 사용자별 대화 목록과 최신 Run 상태를 조회할 수 있습니다.
- 대화 목록은 워크북 읽기 권한과 `ai.use`, `range.read` scope를 요구합니다.
