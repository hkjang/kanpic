## 릴리즈 요약

v0.179.0은 지난 판에서 시작한 **텍스트로 저장된 숫자** 바꾸기가 화면을 바꾸지 않게 합니다.

## 값은 맞는데 자료가 망가져 보였습니다

```
50%      →  0.5
₩5,000   →  5000
```

숫자로는 맞습니다. 그런데 사람 눈에는 **자료가 망가진 것** 으로 보입니다. 특히 백분율은 수가 100분의 1로 줄어든 것처럼 보이므로, 고쳐 준 것이 아니라 헝클어 놓은 것으로 읽힙니다.

## 표시 형식으로 옮깁니다

`₩` 와 `%` 를 표시 형식으로 옮깁니다. **칸에 담기는 값만 숫자가 되고 화면은 그대로입니다.**

```
"₩5,000"  →  값 5000     서식 ₩#,##0    화면 ₩5,000
"50%"     →  값 0.5      서식 0%        화면 50%
"12.5%"   →  값 0.125    서식 0.0%      화면 12.5%
"(500)"   →  값 -500     서식 0;(0)     화면 (500)
```

**그릴 줄 아는 서식만 적습니다.** `£` 는 화면에 앞에 붙여 그리지 못하므로 서식에 적지 않고 자릿점만 남깁니다 — 적어 두면 기호가 조용히 사라진 채로 보입니다. `"1,234원"` 의 `원` 같은 뒤에 붙는 단위도 서식 말에 없으므로 놓아줍니다.

**글자 서식(`@`)은 뗍니다.** 숫자로 바꿔 놓고 글자로 그리라고 적어 두면 바꾼 보람이 없습니다. 사람이 이미 고른 서식이 따로 있으면 건드리지 않습니다.

## 검증 결과

- 서식을 따로 보지 않고, **고른 서식이 실제로 그리는 글자** 가 원래 보이던 것과 같은지로 시험합니다. 서식만 맞고 그림이 다르면 소용이 없습니다.
- 브라우저에서 바꾼 뒤 `A3` 의 값이 `5000`, 서식이 `₩#,##0` 임을 확인합니다.
- 웹 시험 405개와 Go 시험 전체가 통과합니다.
