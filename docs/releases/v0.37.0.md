## 릴리즈 요약

v0.37.0은 **행·열 그룹화(아웃라인)** 를 추가합니다. 분기별 상세를 접어 두고 요약만 보는 긴 모델에서 쓰던 기능으로, 머리글 옆 아웃라인 여백의 `−`·`+` 상자를 눌러 접고 폅니다.

마이그레이션은 없습니다. 그룹은 시트 레이아웃과 같은 자리에 저장되므로 기존 데이터베이스도 그대로 동작합니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 행·열 그룹화

- 여러 행이나 열을 머리글로 선택하고 오른쪽 클릭 메뉴에서 **그룹화** 를 고릅니다. 묶음마다 머리글 옆 여백에 괄호와 접기 상자가 생기고, 상자는 묶음 바로 다음 행(열)에 놓입니다.
- 묶음 안에 묶음을 넣을 수 있고 **최대 8단계** 까지 중첩됩니다. 단계마다 여백이 한 칸씩 넓어지며, 아무것도 묶지 않은 시트에는 여백이 아예 생기지 않습니다.
- **그룹 해제** 는 선택 범위를 감싼 가장 안쪽 묶음만 풀어 바깥 묶음을 그대로 둡니다. 접기·펼치기도 같은 규칙으로 가장 안쪽 묶음에 적용됩니다.
- 접기 상태는 묶음 자체에 저장합니다. 숨긴 행 목록을 건드리지 않으므로 **직접 숨겨 둔 행을 펼치기가 되살리지 않습니다.**
- 행이나 열을 넣고 지우면 묶음도 수식과 같은 규칙으로 함께 움직이고, 묶음이 감싸던 행이 모두 지워지면 묶음도 사라집니다.
- 한 시트에 최대 200개의 묶음을 둘 수 있고, 한 행짜리 묶음은 만들 수 없습니다.

```http
PATCH /api/v1/sheets/{sheetId}/layout:apply
{"action":"group|ungroup|collapse|expand","axis":"row|column","start":5,"count":4,
 "expected_revision":3,"idempotency_key":"..."}
```

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. 중첩 단계 계산, 가장 안쪽 묶음을 고르는 규칙, 한 행짜리 묶음과 없는 묶음에 대한 거부, 행 삽입·삭제에 따른 이동과 소멸을 검사합니다.
- React/Vitest 35개 테스트 파일, 176개 테스트를 통과했습니다. 접힌 묶음이 숨기는 범위, 여백 너비, 접기 상자 위치를 단위 테스트로 확인합니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 90건을 통과했습니다. 실제 브라우저에서 머리글 메뉴로 묶고, 접었을 때 그 행만 사라지며, 여백의 상자를 눌러 다시 펴지는지, 위에 행을 넣으면 묶음이 따라 내려가는지 확인했습니다.
