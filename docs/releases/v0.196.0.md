## 릴리즈 요약

v0.196.0은 **폭포 차트** 를 더합니다. 손익 구조와 증감 분석에서 가장 많이 쓰는 그림입니다.

## 막대 차트로는 보여 줄 수 없습니다

매출에서 원가와 판관비를 빼 영업이익에 이르는 길을 막대 차트로 그리면 **네 개의 막대가 나란히 설 뿐** 무엇에서 무엇을 뺐는지는 보이지 않습니다.

## 이름 · 값 · 합계 여부

열을 앞에서부터 읽습니다. 일정표가 이름 · 시작 · 끝을 자리로 읽는 것과 같습니다.

```
매출      1000             0 → 1000
원가      -600          1000 →  400
판관비    -150           400 →  250
영업이익   250   TRUE       0 →  250
```

막대는 **앞줄까지의 누계에서 시작해** 값만큼 자랍니다. 셋째 칸에 `TRUE` 나 `합계` 를 적은 줄은 **바닥부터** 그립니다 — 그런 줄은 또 하나의 증감이 아니라 앞의 것을 합쳐 놓은 자리입니다.

늘어난 것과 줄어든 것과 합계를 **색으로 가릅니다.** 폭포에서 방향은 값 자체만큼 중요합니다.

## 표에 적힌 합계를 믿습니다

표에 적힌 합계가 우리가 더한 값과 달라도 **표에 적힌 값을 그립니다.** 그림이 표와 어긋나면 사람은 어느 쪽이 맞는지 알 수 없습니다.

## 곁다리로 찾은 것

차트 만들기 대화상자에 **높이 한도가 없었습니다.** 설명이 길어지면 창을 넘쳐 `차트 저장` 이 화면 밖으로 밀려 **눌리지 않습니다.** 일정표 설명도 같은 위험을 안고 있었습니다. 가운데만 흐르게 하고 머리와 단추를 붙잡아 두었습니다.

## 엑셀로 내보낼 때

엑셀에는 같은 그림이 없어 일정표처럼 빠집니다. 몇 개가 빠졌는지는 이미 있는 장치가 알려 주고, 시트의 자료는 그대로 나갑니다.

## 검증 결과

- 누계 위에 쌓이는지, 소계 뒤가 이어지는지, 표에 적힌 합계를 믿는지, 그릴 것이 없을 때 말을 하는지 따로 시험합니다.
- 브라우저에서 **원가 막대가 매출이 끝난 자리에서 시작해 바닥까지 내려오지 않는 것** 과, 합계 줄이 바닥에서 그려지는 것을 좌표로 확인합니다.
- 웹 시험 457개와 Go 시험 전체가 통과합니다.
