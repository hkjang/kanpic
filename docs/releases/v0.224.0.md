# v0.224.0

## 한국 공휴일

수식 함수 둘이 생겼습니다.

```
=KOREANHOLIDAYS(2026)          그 해 공휴일을 날짜 배열로 (대체공휴일 포함)
=KOREANHOLIDAYNAME("2026-05-25")  → "부처님오신날 대체공휴일"
```

첫 번째는 기존 `NETWORKDAYS`·`WORKDAY`·`.INTL` 의 휴일 인자에 그대로 꽂힙니다.

```
=NETWORKDAYS("2025-10-01","2025-10-10",KOREANHOLIDAYS(2025))   → 3
```

2025년 10월 첫 열흘에서 평일은 1·2·10일뿐입니다. 3일 개천절, 5~7일 추석 연휴,
8일 대체공휴일, 9일 한글날.

## 아는 것만 담는다

설·추석·부처님오신날은 음력이라 닫힌 공식이 없습니다. 한국천문연구원이 발표한
날짜를 **2020년부터 2030년까지** 표로 담았습니다. 표에 없는 해를 물으면 `#N/A`
와 함께 "표는 2020년부터 2030년까지 있습니다" 라고 답합니다. 지어내지 않습니다.

임시공휴일과 선거일은 규칙이 없으므로 지정된 것만 적었습니다 — 2020년 총선과
8월 17일, 2022년 대선·지방선거, 2023년 10월 2일, 2024년 총선과 국군의날,
2025년 1월 27일과 대선, 2026년 지방선거.

## 대체공휴일은 법이 바뀐 시점을 따른다

같은 규칙을 모든 해에 적용하면 틀립니다. 실제 달력과 맞췄습니다.

| 언제부터 | 무엇이 | 겹치면 |
|---|---|---|
| 2014년 | 설·추석 연휴, 어린이날 | 일요일·다른 공휴일 (어린이날은 토요일도) |
| 2021년 광복절 | 삼일절·광복절·개천절·한글날 | 토·일요일 |
| 2023년 | 부처님오신날·성탄절 | 토·일요일 |
| — | 신정·현충일 | 옮기지 않음 |

그래서 2022년 성탄절(일요일)에는 대체공휴일이 없고 2023년부터 생깁니다.
2025년 5월 5일은 어린이날과 부처님오신날이 겹쳐 6일 하루만 쉽니다. 2028년
추석은 개천절과 겹쳐 10월 5일이 대체공휴일입니다.

## `NETWORKDAYS.INTL` 이 휴일 범위를 거절하고 있었다

새 함수를 꽂아 보다가 나왔습니다. `NETWORKDAYS.INTL(시작, 끝, 1, A1:A10)` 은
`#VALUE!` 였습니다. 평가기는 범위와 배열을 낱개 값으로 펼쳐 넘기는데, `.INTL`
은 인자 수를 넷으로 못 박아 놓아 휴일이 둘만 돼도 "인자 수가 잘못됐다" 며
거절했습니다. `NETWORKDAYS` 는 이미 넷째부터를 전부 휴일로 읽고 있었습니다.
같게 고쳤습니다. `WORKDAY.INTL` 도 함께입니다.
