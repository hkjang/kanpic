## 릴리즈 요약

v0.62.0은 **정렬이 표의 일부만 건드리던 두 가지 문제**를 고칩니다. 이번 주에 선택 요약·분할 경고·중복 삭제에서 잡은 것과 같은 원인 — "화면에 보이는 범위 = 작업 범위" 라는 가정 — 의 마지막 자리입니다.

마이그레이션은 없습니다. 서버 변경도 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 고친 문제

**1. 열 머리글 정렬이 화면에 불러온 행까지만 정렬했습니다.** 정렬 범위를 그리드가 들고 있는 셀에서 계산했기 때문입니다. 400행짜리 표를 열 머리글에서 정렬하면 범위가 `A1:B22` 로 잡혀 앞의 21행만 자리를 바꾸고 나머지는 그대로 남았습니다. 위쪽만 보면 정렬된 것처럼 보이는 것이 특히 나쁩니다. 이제 서버가 알고 있는 시트 사용 범위에서 표를 찾아 정렬합니다.

**2. 표의 한 열만 선택하고 정렬하면 값의 짝이 어긋났습니다.** `이름·부서·점수` 표에서 이름 열만 선택해 정렬하면 이름만 순서가 바뀌고 부서·점수는 제자리에 남아, 이름이 남의 부서·점수와 짝지어졌습니다. 값이 사라지지 않고 **틀린 조합으로 남기 때문에** 알아채기 어렵습니다.

## 새로운 기능

정렬 전에 **정렬 범위 확인** 창이 뜹니다.

- 대상 범위와 정렬될 행 수, 값 예시를 보여 줍니다.
- 표의 일부만 선택한 상태라면 **표 전체 정렬**(기본)과 **선택 범위만 정렬** 중에서 고르고, 후자에는 "다른 열은 그대로 있어 값의 짝이 어긋납니다" 를 함께 표시합니다. 한 열만 정렬하는 선택지를 없애지는 않았습니다. 다만 모르고 하는 일이 아니게 만들었습니다.
- 셀 하나만 선택한 상태(커서만 있는 상태)에서는 선택지를 묻지 않고 표 전체를 정렬합니다.
