## 릴리즈 요약

v0.44.1은 큰 시트에서 **선택 범위 요약과 열 필터가 잘못된 값을 보여 주던 문제**를 고칩니다. 두 기능 모두 화면에 불러온 셀만 보고 계산하고 있었는데, 그리드는 보이는 행만 불러오므로 수천 행을 선택하면 합계가 실제와 크게 달랐습니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 수정된 문제

- **선택 범위 요약이 화면에 보이는 행만 더했습니다.** 5,000행짜리 열을 선택하면 합계 25억 대신 1,800만이, 개수 5,000 대신 39가 표시됐습니다. 이제 선택한 범위 전체를 서버에서 읽어 계산합니다. 읽는 동안에는 **계산 중…** 으로 표시해 틀린 숫자를 잠깐이라도 보여 주지 않습니다.
  - 선택이 바뀔 때마다 읽지 않고 잠시 멈춘 뒤 한 번만 읽습니다. 10만 셀을 넘는 선택은 셀 개수만 표시합니다.
- **열 머리글 필터가 화면에 보이는 값만 나열했습니다.** 시트 아래쪽에만 있는 값은 목록에 없어 그대로 걸러졌습니다. 이제 필터 범위 전체를 서버에서 읽어 목록을 만들고, 읽는 동안 **값을 읽는 중…** 을 표시합니다.

두 문제 모두 화면에 보이지 않는 데이터를 조용히 빠뜨리는 종류였습니다. 5,000행 워크북으로 두 경우를 재현하고, 400행 시트에서 화면 밖 값이 요약과 목록에 들어오는지 확인하는 회귀 테스트를 추가했습니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. 5,000행·2만 셀 워크북에서 열 전체 참조 수식과 QUERY 집계, 한 셀 수정에 따른 재계산이 각각 0.2초 안에 끝나는 것도 함께 확인했습니다.
- React/Vitest 38개 테스트 파일, 203개 테스트를 통과했습니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 105건을 통과했습니다. 화면 밖까지 뻗은 선택의 합계와 개수가 서버 값과 일치하는지, 시트 맨 아래에만 있는 값이 필터 목록에 나타나고 실제로 걸러지는지 확인합니다.
