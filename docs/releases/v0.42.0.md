## 릴리즈 요약

v0.42.0은 **열 머리글 필터 버튼**을 추가합니다. 필터 뷰가 켜져 있으면 열 머리글마다 깔때기 버튼이 생기고, 눌러서 그 열의 값을 체크하는 것만으로 거를 수 있습니다. 지금까지는 같은 일을 하려면 필터 대화상자를 열어 조건을 직접 적어야 했습니다.

마이그레이션은 없습니다. 저장 형태는 기존 필터 뷰의 `values` 조건 그대로이며, 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 열 머리글 필터 버튼

- 필터 뷰 범위의 **열 머리글마다 깔때기 버튼** 이 그려집니다. 조건이 걸린 열은 진하게 표시되므로 어디가 걸러지고 있는지 한눈에 보입니다.
- 값은 **많이 나온 순** 으로 건수와 함께 나옵니다. 빈 셀은 `(빈 값)` 으로 묶여 목록 맨 끝에 모입니다.
- 검색창으로 목록을 좁힌 뒤 **전체 선택 / 선택 해제** 를 누르면 **검색 결과에만** 적용됩니다. 값이 많은 열에서 원하는 몇 개만 남길 때 쓰는 방식입니다.
- 모든 값을 다시 선택하면 그 열의 조건이 사라집니다. 필터는 실제로 제한하는 것만 담습니다.
- 메뉴 위쪽의 **오름차순 / 내림차순 정렬** 은 머리글 행을 남겨 두고 데이터 영역만 정렬합니다.
- 값이 하나도 남지 않는 상태로는 적용할 수 없습니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다.
- React/Vitest 37개 테스트 파일, 199개 테스트를 통과했습니다. 값 목록 집계와 정렬(빈 값은 맨 끝), 조건이 없을 때 전부 선택으로 보이는 규칙, 모두 선택 시 조건을 지우는 규칙, 다른 열 조건을 건드리지 않는지를 단위 테스트로 확인합니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 99건을 통과했습니다. 실제 브라우저에서 머리글 버튼으로 값을 골라 행이 걸러지는지, 다시 열었을 때 선택 상태가 유지되는지, 검색으로 좁힌 뒤 전체 선택이 그 결과에만 적용되는지 확인했습니다.
