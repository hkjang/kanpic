## 릴리즈 요약

v0.33.1은 Workbook Agent를 버튼 중심 작업 화면에서 대화가 중심인 멀티턴 채팅 화면으로 다듬고, 편집기의 모든 오른쪽 기능 패널이 화면 크기와 관계없이 같은 너비 조절 체계를 사용하도록 완성한 UX 개선 릴리즈입니다.

데이터베이스 마이그레이션과 API 변경은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나이며, `BOOTSTRAP_ADMIN_ID`·`BOOTSTRAP_ADMIN_PASSWORD`와 Keycloak Confidential Client의 `client_secret` 설정도 그대로 사용할 수 있습니다.

## 채팅 중심 Workbook Agent

- 패널 아래에 입력창을 고정하고 `Enter`로 전송, `Shift+Enter`로 줄바꿈하는 일반적인 채팅 흐름을 제공합니다.
- 첫 화면의 작업 유형 버튼을 제거하고 기본 자동 Agent가 의도를 판단하도록 했습니다. 수식·정제·분석 등 유형을 고정해야 할 때만 간결한 선택 메뉴를 사용합니다.
- 사용자 메시지, Agent 생각 중 상태, 이전 응답과 실행 계획이 하나의 대화 흐름으로 이어지며 새 응답이 도착하면 최신 메시지로 이동합니다.
- 대화 목록과 새 대화 기능을 헤더에 배치하고, 패널을 다시 열었을 때 마지막 대화를 복원합니다.
- “선택 범위로 막대 차트를 만들어줘” 다음에 “막대 차트를 선 차트로 바꿔줘”처럼 같은 대화의 문맥과 현재 워크북 객체를 활용하는 후속 요청을 지원합니다.
- 변경 작업은 기존과 동일하게 계획·Diff·도구 호출을 검토하고 승인해야 적용되며 ChangeSet 단위 Undo를 지원합니다.

## 모든 오른쪽 패널의 공통 너비 조절

- AI 도우미, 자동화, 차트, 피벗, 댓글, 편집 충돌 및 버전 이력의 기본 너비와 표시 이름을 하나의 패널 레지스트리에서 관리합니다.
- 왼쪽 경계를 드래그하거나 `←`/`→`, `Home`/`End`로 너비를 조절하고 더블 클릭으로 패널별 기본 너비를 복원합니다.
- 조절 중 현재 픽셀 너비를 표시하며, 각 패널의 선택 너비를 브라우저에 독립적으로 저장합니다.
- 최대 너비를 960px까지 확장하고 중간 화면 폭에서 AI·댓글·충돌·버전 패널을 숨기던 이전 반응형 규칙을 제거했습니다.
- 720px 이하에서는 화면을 침범하지 않는 제한 너비를 적용하고 드래그 핸들을 숨깁니다.

## 오프라인 설치

이 릴리즈는 웹 자산과 서버 바이너리를 포함한 Docker 이미지 아카이브로 제공됩니다.

```bash
sha256sum -c kanpic-v0.33.1.tar.gz.sha256
gzip -dc kanpic-v0.33.1.tar.gz | docker load
docker run --rm -p 8080:8080 \
  -e POSTGRES_DSN='postgres://kanpic:password@postgres.internal:5432/kanpic?sslmode=require' \
  kanpic:v0.33.1
```

- 필수 런타임 환경 변수: `POSTGRES_DSN`
- Redis 및 외부 인터넷 연결: 불필요
- 관리자 초기 로그인을 보호하려면 `BOOTSTRAP_ADMIN_ID`와 `BOOTSTRAP_ADMIN_PASSWORD`를 함께 지정합니다.
- Keycloak Confidential Client를 사용하면 `auth.oidc.client_secret`을 설정합니다.
- 무결성 검증 파일: `kanpic-v0.33.1.tar.gz.sha256`
