## 핵심 변경

- 선택 범위에서 막대, 선, 영역, 원형, 분산, 히스토그램을 만드는 서버 권위 네이티브 차트를 추가했습니다.
- 차트 정의는 PostgreSQL에 저장되고 워크북 버전, revision, idempotency key를 사용합니다. 셀 값이나 수식 결과가 바뀌면 최신 데이터가 즉시 반영됩니다.
- 차트를 시트 위에서 자유롭게 이동하고 크기를 조절할 수 있으며 SVG와 PNG로 내보낼 수 있습니다.
- 제목, 원본 시트와 A1 범위, 머리글·항목 이름, 범례 위치, X/Y축 제목과 크기를 차트 편집 화면에서 관리합니다.
- 원본 범위는 최대 10,000셀, 워크북당 차트는 최대 100개로 제한해 과도한 조회와 렌더링을 방지합니다.
- 차트 제목과 계열·항목명은 HTML로 해석하지 않고 SVG 텍스트로 렌더링합니다.

## 데이터 내구성과 버전 관리

- 차트 생성·수정·삭제는 워크북의 서버 버전을 증가시키고 공동 편집자에게 최신 버전을 전파합니다.
- 차트는 워크북 스냅샷과 복원, 워크북·시트 복제에 포함됩니다.
- 행·열 삽입 또는 삭제 시 원본 A1 범위가 함께 이동합니다. 원본 전체나 원본 시트가 삭제되면 차트 정의를 보존하고 `#REF!` 상태로 표시합니다.
- 수정과 삭제에 expected revision을 적용해 오래된 화면에서 발생한 동시 변경을 거부합니다.
- 같은 idempotency key로 차트를 다시 생성해도 중복 엔터티를 만들지 않습니다.
- 차트 데이터 조회는 저장된 계산 결과를 포함한 최신 셀 블록과 동일한 워크북 버전을 반환합니다.

## 사용자 화면

- 편집기 오른쪽 아래에 차트 패널 진입 버튼을 추가했습니다.
- 차트 패널에서 현재 시트의 차트 목록과 revision을 확인하고, 원본 범위로 이동하거나 설정을 다시 열 수 있습니다.
- 차트에는 접근 가능한 SVG 이미지 이름과 막대·원형·분산 데이터 점 설명을 제공합니다.
- 원본이 손상되었거나 숫자 데이터가 없을 때 명시적인 빈 상태를 표시합니다.
- 개인화 화면의 API 키 관리에 이름·scope·만료 시점 수정 기능을 추가했습니다. 만료 시점을 다시 ‘없음’으로 변경할 수도 있습니다.
- 새 에이전트 키의 기본 scope에 `chart.*`를 포함했습니다.

## REST API 및 MCP

- REST: `GET|POST /api/v1/workbooks/{workbookId}/charts`
- REST: `GET|PATCH|DELETE /api/v1/charts/{chartId}`
- REST: `GET /api/v1/charts/{chartId}/data`
- MCP: `spreadsheet.chart.list|get|data`
- MCP: `spreadsheet.chart.create|update|delete`
- 읽기 작업은 `chart.read`, 변경 작업은 `chart.write` scope를 검사하며 API 키에는 MCP 사용 시 `mcp.use`도 필요합니다.
- REST와 MCP는 동일한 저장소, 유효성 검사, revision 및 idempotency 계약을 공유합니다.

## 검증

- 전체 Go 단위 테스트와 실제 PostgreSQL 5432 통합 테스트를 통과했습니다.
- 메모리·PostgreSQL 저장소에서 차트 CRUD, 멱등성, revision 충돌, 실시간 수식 결과, 분산형 X/Y 데이터, 구조 변경, 스냅샷 복원과 복제를 검증했습니다.
- REST와 MCP의 차트 계약, scope 및 오류 응답 일치를 검증했습니다.
- React/Vitest 50개 테스트와 TypeScript/Vite 프로덕션 빌드를 통과했습니다.
- Playwright 브라우저 E2E에서 네이티브 차트 생성·갱신 및 API 키 생성·수정·회전·폐기를 검증했습니다.
- 릴리스 Docker 이미지의 자동 마이그레이션, `/healthz`, 빌드 버전과 오프라인 `docker load`를 검증했습니다.

## 업그레이드 참고

- 서버 시작 시 `008_charts.sql`이 자동 적용되어 차트 정의와 조회용 인덱스를 생성합니다.
- 필수 런타임 환경 변수는 기존과 동일하게 `POSTGRES_DSN` 하나이며 Redis와 외부 인터넷은 필요하지 않습니다.
- 기존 API 키로 차트 REST 또는 MCP 도구를 사용하려면 개인화 화면에서 `chart.read` 또는 `chart.write` scope를 추가하거나 키를 회전해야 합니다.
- 릴리스 태그에 대응하는 `docs/releases/vX.Y.Z.md`가 없거나 비어 있으면 패키지 게시가 실패하도록 릴리스 파이프라인을 강화했습니다.
