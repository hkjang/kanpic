## 릴리즈 요약

v0.197.0은 **함수 이름만 적어도** 넘길 수 있게 합니다.

## 사람이 쓰는 모양이 이쪽입니다

엑셀은 `=MAP(A1:A3,ABS)` 를 받아 줍니다. `LAMBDA(v,ABS(v))` 를 줄여 적은 것입니다. kanpic은 `#NAME?` 을 냈습니다.

```
=MAP(A1:A100, ABS)      전에는 #NAME?: unknown name ABS
=BYROW(A1:C10, SUM)     전에는 #NAME?: unknown name SUM
```

괄호 없이 적힌 이름이 카탈로그에 있는 함수면 **그 함수를 가리키는 값** 으로 읽습니다. 이름 있는 수식도 같이 봅니다 — 사람이 만든 함수라고 다를 이유가 없습니다.

`MAP` · `BYROW` · `BYCOL` · `REDUCE` · `SCAN` 이 모두 함께 받게 됩니다.

## 무엇이 먼저인가

같은 이름의 **이름 범위** 가 있으면 그쪽이 먼저입니다. 사람이 `SUM` 이라는 이름 범위를 만들어 두었다면 그것을 뜻했을 것입니다.

칸에 `=SUM` 이라고 적은 것은 예전과 똑같이 `#NAME?` 입니다. 오류가 나는 **자리** 도 그대로 두었습니다 — 처음에는 값으로 돌려주게 만들었는데, 그러면 오류가 `result.Error` 가 아니라 `result.Value` 로 옮겨 가 위쪽에서 오류로 보지 않게 됩니다. 벌거벗은 `LAMBDA` 를 막는 자리가 이미 있어 그 옆에 두었습니다.

## 왜 지금인가

`GROUPBY(범위, 값, SUM)` 의 셋째 인수가 이 꼴입니다. 먼저 만들어 두지 않으면 GROUPBY를 넣어도 사람이 쓰는 모양 그대로는 쓸 수 없습니다.

## 검증 결과

- 줄여 적은 것과 `LAMBDA` 로 적은 것이 같은 답을 내는지, 칸에 홀로 적으면 여전히 `#NAME?` 인지, 같은 이름의 이름 범위가 이기는지 따로 시험합니다.
- 웹 시험 457개와 Go 시험 전체가 통과하고, `gofmt` 도 확인했습니다.
