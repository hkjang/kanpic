## 릴리즈 요약

v0.129.1은 **인쇄 영역이 엑셀로 나갔다 오면 사라지던 것** 을 고칩니다. 앞 판에서 가져오기만 하고 내보내기를 빼놓은 자리입니다.

## 절반만 이었다

v0.129.0에서 인쇄 영역을 넣으며 **엑셀 파일에서 가져오는 쪽** 만 이었습니다. 내보내는 쪽을 적지 않아, kanpic에서 정한 인쇄 영역이 XLSX로 나가는 순간 사라졌습니다.

```
kanpic 에서 A1:B2 로 정함
  → XLSX 로 내보냄      인쇄 영역 없음
  → 다시 가져옴          인쇄 영역 없음
```

파일은 열리고 표도 그대로여서 **없어진 줄 모릅니다.** 인쇄할 때가 되어서야 온 시트가 종이에 나옵니다.

## 고친 것

내보내기가 시트 배치를 적는 자리에서 `_xlnm.Print_Area`를 함께 적습니다. 시트에 걸린 이름이므로 `Scope`를 시트로 둡니다.

```xml
<definedName localSheetId="0" name="_xlnm.Print_Area">Sheet1!$A$1:$B$2</definedName>
```

## 검증 결과

- 실제로 내보낸 파일을 열어 이름 정의가 들어 있는지 보았고, 그 파일을 **되가져와** `A1:B2`가 그대로인지 확인했습니다.
- 왕복 시험을 두었습니다. 내보내기를 빼면 걸립니다.
- 인쇄 영역이 **이름 목록에 섞여 돌아오지 않는지** 도 함께 봅니다. 이름이 아니라 시트의 성질이기 때문입니다.
- Go 시험 전체와 웹 시험 376개가 통과합니다.
