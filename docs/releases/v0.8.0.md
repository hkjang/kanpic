## 핵심 변경

- UI, REST, MCP와 XLSX가 공유하는 서버 권위 셀 서식 모델을 도입했습니다.
- 숫자·통화·백분율·날짜·시간·사용자 지정 표시 형식을 Canvas에서 렌더링합니다.
- 가로·세로 정렬, 텍스트 넘침·자르기·자동 줄바꿈, -90°~90° 회전을 지원합니다.
- 가는 선·중간 선·굵은 선·파선·점선·이중선과 색상을 지원하며, 전체·외곽·내부·가로·세로·개별 면 테두리를 한 번의 원자적 작업으로 적용합니다.
- 서식 대화상자에서 선택 범위의 표시 형식과 테두리를 적용하거나 전체 서식을 지울 수 있습니다.
- 범위 서식은 값·수식을 보존하고 멱등성, 충돌 탐지, 버전 이력과 Undo에 포함됩니다.
- XLSX Import/Export가 글꼴·색상·채우기·정렬·줄바꿈·표시 형식·테두리를 공통 모델로 정규화해 왕복 변환합니다.
- `spreadsheet.range.format` MCP 도구가 일반 style patch와 원자적 border 명령을 모두 제공합니다.
- batch, paste, fill, REST, WebSocket과 MCP에서 전달되는 전체 셀 서식을 서버에서 검증합니다.

## 검증

- 전체 Go 단위 테스트 및 실제 PostgreSQL 통합 테스트 통과
- React/Vitest 41개 테스트와 TypeScript/Vite 프로덕션 빌드 통과
- Playwright 22개 브라우저 E2E 시나리오 통과
- XLSX 공통 서식 왕복, 외곽 테두리 원자 저장, 값·수식 보존과 PostgreSQL 영속화 검증

## 업그레이드 참고

- 별도 데이터베이스 마이그레이션은 필요하지 않습니다.
- 기존 flat style 속성과 `wrap` 값은 계속 읽으며, 새 텍스트 배치 설정은 `text_mode`로 저장됩니다.
- `spreadsheet.range.format`의 기존 `style` 요청은 그대로 호환됩니다. 새 `border` 객체는 선택 사항입니다.
