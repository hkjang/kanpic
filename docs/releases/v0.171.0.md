## 릴리즈 요약

v0.171.0은 **한국에서 쓰는 번호** 를 다루는 함수 넷을 더합니다. 엑셀에도 구글 시트에도 없어, 지금까지는 매크로를 짜거나 손으로 확인하던 자리입니다.

## 넷

```
=ISBIZNO("220-81-62517")      사업자등록번호 검사 숫자 → TRUE
=ISCORPNO("110111-0000002")   법인등록번호 검사 숫자 → TRUE
=FORMATBIZNO("2208162517")    → 220-81-62517
=MASKRRN("900101-1234567")    → 900101-1******
```

하이픈은 있어도 없어도 됩니다. 거래처 명단의 사업자번호를 한 번에 훑을 때 씁니다.

## 주민등록번호는 가리기만 합니다

**검증 함수는 두지 않았습니다.** 2020년 10월부터 새로 매기는 번호는 뒷자리를 임의로 만들어, **검사 숫자가 맞지 않아도 진짜 번호** 입니다. 검증 함수를 두면 멀쩡한 번호를 틀렸다고 말하게 되는데, 그것은 없느니만 못합니다. 시험에도 그 함수가 생기지 않았는지 적어 두었습니다.

`=MASKRRN` 은 열세 자리가 아니면 **오류를 냅니다.** 가릴 수 없는 것을 그대로 돌려주면, 가린 줄 알았던 자리에 번호가 그대로 남기 때문입니다.

## 검산

검사 숫자 셈은 Go 로 짜고 **Python 으로 따로 확인했습니다.** 제 코드를 제 코드로 확인하면 뜻이 없습니다.
