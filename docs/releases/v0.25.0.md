## 릴리즈 요약

v0.25.0은 AI 도우미를 쓸 수 있게 만듭니다. 패널이 **스크롤되지 않던 문제**를 고치고, **사용 가이드**와 **모델에 보내는 내용 전문 보기**를 넣었습니다. 점검 중 발견한 **AI 접근 권한 결함**도 함께 고쳤습니다. 이 결함은 공유받지 않은 사용자가 다른 사람의 워크북 셀을 AI 경로로 읽을 수 있는 문제였습니다.

필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나이며 새 마이그레이션은 없습니다.

## 보안 수정: AI 경로의 워크북 접근 통제

- `POST /api/v1/ai/actions:plan`은 워크북을 **요청 본문**으로 지정합니다. 권한 미들웨어는 URL에서 대상을 찾기 때문에 이 경로에는 워크북 단위 검사가 걸리지 않았고, 공유받지 않은 계정도 워크북 ID만 알면 선택 범위의 셀을 AI 계획 응답으로 받아 볼 수 있었습니다.
- 이제 두 AI 경로 모두 요청 본문의 워크북에 대해 읽기 권한을 확인하고, 권한이 없으면 403을 반환합니다. 뷰어 공유만 있어도 계획과 미리보기는 사용할 수 있고, 적용은 기존대로 편집 권한이 필요합니다.
- 회귀 테스트를 Go와 E2E 양쪽에 추가했습니다.

## 패널이 스크롤됩니다

- 스크롤 영역이 남은 높이를 차지하지 않아 내용이 길어지면 아래쪽이 잘리고 스크롤바도 생기지 않았습니다. 이제 패널 높이에 맞춰 스크롤됩니다.

## 사용 가이드

- 패널 오른쪽 위 **?** 버튼에서 진행 순서(범위 선택 → 작업 선택 → 계획 검토 → 승인/Undo), **전송되는 항목과 전송되지 않는 항목**, 모델이 할 수 없는 일을 설명합니다. AI가 꺼져 있어도 열어 볼 수 있습니다.
- 작업 유형은 드롭다운 대신 카드 6개로 바뀌었고 각각 **읽기 전용/변경 제안** 표시와 한 줄 설명이 붙습니다. 유형을 고르면 그 유형에 맞는 예시 요청이 나타나고 누르면 입력창에 채워집니다.
- 기본 작업 유형을 읽기 전용인 **범위 요약**으로 바꿨습니다.

## 모델에 보내는 내용 보기

- **모델에 보내는 내용 보기**를 열면 이번 요청의 **시스템 프롬프트 전문과 전달 데이터(JSON)** 를 그대로 보여 줍니다. 모델, 셀 개수, temperature, max_tokens도 함께 표시하고 각 블록을 복사할 수 있습니다.
- 실제 Gateway 요청과 **같은 빌더**로 생성하므로 화면과 실제 전송 내용이 어긋날 수 없습니다.
- 열기 전에는 아무것도 읽지 않습니다. Gateway를 호출하지 않으므로 AI가 꺼진 상태에서도 관리자가 문구를 검토할 수 있습니다.

## 그 밖의 사용성 개선

- 선택 범위의 **셀 수**를 패널에 표시하고, 상한을 넘으면 서버 오류를 기다리지 않고 미리 알려 주며 실행 버튼을 잠급니다.
- 요청 입력창에 **글자 수 표시**와 `Ctrl/⌘ + Enter` 실행을 추가했습니다.
- 계획을 기다리는 동안 **경과 시간(초)** 을 표시합니다.
- 계획 화면에 보낸 요청 문장을 함께 보여 주고, **같은 요청 고쳐 쓰기** 로 유형과 문장을 그대로 불러와 수정할 수 있습니다.
- 이상치 발견 항목에 심각도별 색을 입혔습니다.

## REST API

```http
POST /api/v1/ai/prompt:preview
{"workbook_id":"…","sheet_id":"…","range":"A3:F9","mode":"clean","request":"공백 정리"}
```

워크북 읽기 권한이 필요하고 Gateway를 호출하지 않으며, 시스템 프롬프트·전달 데이터·모델·셀 수·temperature·max_tokens를 반환합니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. 공유받지 않은 계정이 계획과 미리보기에서 403을 받고 뷰어는 통과하는지 확인합니다.
- React/Vitest 29개 테스트 파일, 133개 테스트를 통과했습니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 69건을 통과했습니다. 실제 브라우저와 PostgreSQL에서 패널 스크롤, 가이드 내용, 프롬프트 전문과 전달 데이터, 셀 상한 경고와 실행 잠금, 권한 없는 워크북의 403을 확인했습니다.

## 업그레이드 참고

- AI 테스트가 전역 설정을 공유하므로 E2E의 AI 테스트를 한 파일(`e2e/ai.spec.ts`)로 모았습니다. Playwright가 파일을 병렬로 실행하면서 서로의 설정을 덮어쓰던 문제를 없앴습니다.
- 워크북을 공유받지 않은 계정의 AI 계획 요청은 이제 403입니다. 자동화 스크립트가 이 경로를 쓰고 있었다면 해당 계정에 공유를 부여해야 합니다.
