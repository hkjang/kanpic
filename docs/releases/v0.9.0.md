## 핵심 변경

- 서버 권위 워크북 통합 검색을 추가했습니다. 값과 수식을 대소문자 구분 없이 검색하고, 페이지 단위 결과에서 다른 시트의 원거리 셀로 즉시 이동할 수 있습니다.
- 셀·범위 댓글 스레드와 답글, 자신의 메시지 수정·삭제, 스레드 해결·재열기를 편집기 오른쪽 패널에 추가했습니다.
- `@사용자ID`와 `@이메일` 멘션을 추출해 개인 알림을 만들고, 상단 알림 메뉴에서 해당 워크북·시트·범위·댓글로 이동할 수 있습니다.
- 댓글 및 답글 생성은 idempotency key로 중복을 차단하고, 메시지 수정과 스레드 상태 변경은 revision을 확인해 동시 수정 충돌을 막습니다.
- 행·열 삽입 및 삭제 시 댓글과 멘션 알림의 범위를 함께 이동합니다. 연결 범위가 완전히 삭제되면 대화는 보존하고 위치를 `#REF!`로 표시합니다.
- 댓글 본문은 HTML로 해석하지 않고 일반 텍스트로 렌더링합니다.
- 댓글 변경을 `comment.changed` WebSocket 이벤트로 전달해 공동 편집자의 패널과 멘션 알림을 갱신합니다.
- REST 댓글·알림 계약 전체를 `spreadsheet.comment.*`와 `spreadsheet.notification.*` MCP 도구 10개로 제공합니다.
- 수동 GitHub 릴리즈 스크립트도 버전별 릴리즈 노트를 생성하여 `--notes-file`로 게시하도록 수정했습니다.

## API 및 MCP

- REST: `GET|POST /api/v1/workbooks/{workbookId}/comments`
- REST: `GET|PATCH|DELETE /api/v1/comments/{commentId}`
- REST: `POST /api/v1/comments/{commentId}/replies`
- REST: `PATCH|DELETE /api/v1/comment-messages/{messageId}`
- REST: `GET /api/v1/me/notifications`, `PATCH /api/v1/me/notifications/{notificationId}`
- MCP: `spreadsheet.workbook.search`
- MCP: `spreadsheet.comment.list|get|create|reply|resolve|delete`
- MCP: `spreadsheet.comment.message.update|delete`
- MCP: `spreadsheet.notification.list|mark_read`

## 업그레이드 참고

- 서버 시작 시 `007_comments.sql`이 자동 적용되어 댓글, 메시지와 멘션 알림 테이블 및 인덱스를 생성합니다.
- 필수 런타임 설정은 기존과 동일하게 `POSTGRES_DSN` 하나이며 Redis는 필요하지 않습니다.
- 기존 개인 API 키로 댓글 API나 MCP 도구를 사용하려면 개인화 화면에서 `comment.read` 또는 `comment.write` scope를 추가하거나 키를 회전해야 합니다.
- 댓글 변경은 셀 데이터와 독립적으로 저장되므로 워크북 버전 번호를 증가시키지 않습니다.
