## 릴리즈 요약

v0.66.0은 **인쇄가 숨겨진 행까지 출력하던 문제**를 고칩니다. 필터로 3행만 남겨 놓고 인쇄하면 걸러 낸 행이 전부 종이에 나왔습니다. 방금 본 화면과 다른 문서를 손에 들게 되는 셈입니다.

마이그레이션은 없습니다. 서버 변경도 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 고친 문제

인쇄 문서는 사용 범위의 모든 행을 그대로 표로 만들고 있었습니다. 화면에서 행이 사라지는 세 가지 경로 — **필터, 행 숨기기, 접은 그룹** — 중 어느 것도 반영하지 않았습니다.

세 가지 모두 읽는 사람에게는 같은 뜻입니다: 그 행은 지금 보고 있는 화면에 없습니다. 이제 셋 다 인쇄에서 빠집니다. 어제 넣은 부분합으로 소계만 남기고 접은 보고서를 그대로 인쇄할 수 있습니다.

행 번호는 원래 번호를 유지합니다(2, 5, 8 …). 인쇄물을 시트와 대조할 수 있어야 하기 때문입니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다.
- React/Vitest 41개 테스트 파일, 234개 테스트를 통과했습니다. 새 단위 테스트 3건은 숨긴 행 제외, 원래 행 번호 유지, 숨긴 행이 없을 때 전부 인쇄를 확인합니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 130건을 통과했습니다(전체 스위트 2회 연속). 새 테스트 2건은 필터로 가린 행과 접은 그룹 안의 행이 인쇄 문서에 없는지 실제 브라우저에서 확인합니다.
- 고치기 전 상태를 브라우저로 먼저 재현했습니다. 서울만 남기는 필터를 걸고 인쇄하니 부산·대구·광주가 모두 문서에 있었습니다.
