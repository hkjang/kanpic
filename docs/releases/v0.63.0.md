## 릴리즈 요약

v0.63.0은 **자동 합계가 화면에 보이던 행만 더하던 문제**를 고칩니다. 이번 주 내내 같은 원인을 쫓았고 — "화면에 불러온 범위 = 작업 범위" — 이번이 다섯 번째이자 마지막으로 확인된 자리입니다.

마이그레이션은 없습니다. 서버 변경도 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 고친 문제

400행짜리 숫자 열의 바로 아래 칸에서 `Alt + =` 를 누르면 `=SUM(A384:A400)` 이 들어갔습니다. 그리드가 들고 있던 17행만 거슬러 올라간 것입니다. 결과는 400이 아니라 17이고, 수식 자체는 멀쩡해 보이므로 틀린 줄 알기 어렵습니다.

이제 열 내용을 서버에서 읽어 숫자 구간의 진짜 시작을 찾습니다. 같은 표에서 `=SUM(A1:A400)` 이 들어가고 결과는 400입니다.
