## 릴리즈 요약

v0.47.0은 **슬라이서**를 더합니다. 시트 위에 놓인 값 버튼 묶음으로, 필터 메뉴가 어디 있는지 모르는 사람도 누르기만 하면 데이터를 거를 수 있습니다. 대시보드처럼 만들어 놓은 워크북을 남에게 넘길 때 가장 아쉬웠던 부분입니다.

마이그레이션은 없습니다. 슬라이서는 시트 레이아웃(`sheets.properties`)에 저장됩니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 새로운 기능

- **데이터 › 슬라이서 추가**: 선택한 열의 값 목록을 카드로 띄웁니다. 값마다 개수가 함께 보이고, 카드 아래에는 몇 개 값이 표시 중인지 요약됩니다. 시트에 필터 보기가 없으면 데이터 범위로 하나 만들지 물어본 뒤 놓습니다.
- **필터 보기를 대신하지 않고 조작합니다.** 카드에서 값을 끄면 그 열의 필터 조건이 바뀌고, 행은 지금까지와 똑같은 방식으로 숨겨집니다. 열 머리글 깔때기 메뉴와 카드가 항상 같은 상태를 가리키므로 필터가 두 벌 생기지 않습니다.
- **배치**: 머리글을 끌어 옮기고 오른쪽 아래 핸들로 크기를 조절합니다. 위치와 크기는 시트 레이아웃 revision으로 저장되어 공동 편집자에게 같게 보입니다.
- **값 목록은 서버에서 읽습니다.** 화면에 불러온 셀만으로 목록을 만들면 스크롤 밖의 값이 조용히 빠집니다. 필터 범위 전체를 읽어 목록을 만듭니다.
- 행·열을 삽입·삭제·이동하면 슬라이서가 가리키는 열도 함께 움직이고, 그 열이 삭제되면 슬라이서도 함께 사라집니다. 한 시트에 최대 24개입니다.

REST `PATCH /api/v1/sheets/{sheetId}/layout:apply` 가 `slicer_add`, `slicer_update`, `slicer_remove` 액션을 받습니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. 새 단위 테스트는 슬라이서가 옮긴 열을 따라가고, 그 열이 삭제되면 함께 사라지며, 값 목록을 보여 줄 수 없을 만큼 작은 크기는 거부되는지 확인합니다.
- React/Vitest 39개 테스트 파일, 209개 테스트를 통과했습니다.
- TypeScript 타입 검사와 Vite 프로덕션 빌드를 통과했습니다.
- Playwright E2E 110건을 통과했습니다. 새 테스트는 브라우저에서 슬라이서를 만들어 값을 끈 뒤, 서버의 필터 보기 조건과 남은 행 수가 카드 표시와 일치하는지 확인하고, 열을 옮겨도 슬라이서가 같은 열을 가리키는지 확인합니다.
- 실제 브라우저에서 지역·제품·매출 표에 슬라이서를 올려 눈으로 확인했습니다.
