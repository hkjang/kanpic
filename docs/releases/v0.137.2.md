## 릴리즈 요약

v0.137.2는 **승인 화면의 계획 목록이 실제로 하는 일과 다른 말을 적던 문제** 를 고칩니다.

## 차트를 만든다고 적혀 있었습니다

Workbook Agent 계획을 승인하기 전에 보는 번호 매긴 목록이 있습니다. 사람이 "이걸 해도 되는가" 를 판단하는 곳입니다.

그 목록이 **모르는 도구를 모두 "차트 소스 검증 후 워크북에 차트 생성" 이라고 적고 있었습니다.** v0.134.0 부터 더한 다섯 도구 — 피벗, 조건부 서식, 입력 규칙, 필터 보기, 정렬 — 가 전부 차트를 만든다고 표시됐습니다.

사람은 화면이 말하는 것을 믿고 승인합니다. 차트를 만든다고 적힌 것을 승인했는데 자료가 정렬되는 것은 시킨 일이 아닙니다.

## 도구마다 제 말을 적습니다

```
3. 원본을 그대로 두고 피벗으로 요약 생성          create_pivot
3. 줄을 지우지 않고 조건에 맞는 줄만 보이게 설정   create_filter_view
3. 수식과 서식을 함께 옮기며 범위의 줄 재배열      sort_range
```

모르는 도구에는 **아무 말도 지어내지 않습니다.** 도구 이름을 그대로 적습니다. 앞으로 도구를 더해도 잘못된 설명이 붙지 않습니다.

## 검증 결과

- 다섯 도구 모두 설명에 "차트" 가 들어가지 않고, 서로 다른 설명을 쓰는지 확인합니다.
- 고치기 전 코드에서는 다섯 개 모두 차트라고 적혀 이 시험이 실패합니다.
- Go 시험 전체, 통합 시험 전체와 웹 시험 382개가 통과합니다.
