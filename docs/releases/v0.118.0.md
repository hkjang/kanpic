## 릴리즈 요약

v0.118.0은 두 가지를 고칩니다. **거래마다 한 줄인 표** 를 항목별 합계로 묶어 그리고, 실패했을 때 사용자에게 보여 주는 말과 로그에 남기는 말을 갈랐습니다.

마이그레이션은 없습니다.

## 스프레드시트의 보통 모습은 요약이 아니다

지금까지는 이미 정리된 표만 제대로 다뤘습니다. 부서 셋에 줄 셋인 표는 막대 셋을 그렸지만, **지점이 스물네 번 반복되는 거래 원본** 은 그냥 표가 되었습니다. 스물네 줄 중 열 줄만 실린 표 한 장. 슬라이드로서 아무 말도 하지 않습니다.

그런데 그것이 스프레드시트의 보통 모습입니다. 항목마다 한 줄이 아니라 사건마다 한 줄입니다.

이제 같은 항목이 여러 줄에 나오면 **합계로 묶어** 그립니다. 스물네 줄의 거래는 지점 네 개의 막대가 되고, 핵심 지표도 합계 기준이 됩니다 — 한 건의 최고 매출이 아니라 지점의 최고 매출입니다.

슬라이드에는 **"24행을 지점별로 합쳤습니다"** 라고 적습니다. 적지 않으면 읽는 사람은 그것을 원본 줄로 읽습니다.

**비율은 합치지 않습니다.** 108% + 91% + 103% 은 어떤 질문의 답도 아닙니다. 첫 측정값이 달성률이나 증감이면 원본 그대로 둡니다. 항목마다 이미 한 줄인 표도 그대로 둡니다 — 묶을 것이 없습니다.

만들다 잡은 것: 합쳤다고 적어 놓고 추이 차트는 원본 줄을 그리고 있었습니다. 글과 그림이 서로 다른 말을 하는 상태였고, 어떤 종류의 그림이든 묶은 값을 그리도록 고쳤습니다.

## 조사가 틀리면 기계가 쓴 티가 난다

표지 첫 줄에 **"영업2이(가) 매출 770로 가장 높습니다"** 가 나오고 있었습니다.

한국어 조사는 앞말의 받침에 따라 갈리고, 숫자는 **읽는 소리** 로 판단해야 합니다. 2는 "이" 라서 받침이 없고 1은 "일" 이라서 받침이 있으므로 같은 자리에 서로 다른 조사가 옵니다. `로`/`으로` 는 ㄹ 받침을 받침 없는 것처럼 다룹니다.

> 영업2**가** 매출 770**으로** 가장 높습니다.
> 영업1**이** 매출 1100**으로** 가장 높습니다.

`10%` 도 조심해야 합니다. `%` 를 떼고 0을 보면 "으로" 가 되지만, 실제로는 "십 퍼센트" 라서 "로" 입니다. 읽어서 말이 되는 기호는 그 소리로 판단합니다.

끝소리를 알 수 없으면 `이(가)` 대신 열린 형태를 씁니다. 괄호 낀 조사는 기계가 쓴 티가 가장 많이 나는 자리입니다.

## 실패했을 때 누구에게 무엇을 말하는가

프레젠테이션 서비스가 응답하지 않을 때 화면에 이런 것이 나왔습니다.

```
presentation service failed: ptium POST /api/v1/presentations:
Post "http://10.0.3.14:8080/api/v1/presentations": dial tcp ... connection refused
```

운영자에게는 정확히 필요한 말이고, 워크북을 읽을 수 있다는 것이 **사내 서비스 주소를 알아도 된다는 뜻은 아닙니다.** 게다가 한국어 화면에 영어 Go 오류가 그대로 나오고 있었습니다.

이제 둘을 가릅니다. 자세한 것은 로그로 가고, 화면에는 어느 쪽 문제인지만 나갑니다.

| 상황 | 화면에 나가는 말 |
| :--- | :--- |
| 연결 실패 | 프레젠테이션 서비스에 연결하지 못했습니다. 관리자에게 문의하세요. |
| 401·403 | 프레젠테이션 서비스가 인증을 거부했습니다. 관리자에게 문의하세요. |
| 5xx | 프레젠테이션 서비스에 오류가 발생했습니다. |
| 4xx (서비스가 이유를 말한 경우) | 프레젠테이션 서비스가 요청을 거절했습니다: *(서비스가 한 말)* |

마지막 줄이 중요합니다. **덱에 대해 서비스가 한 말은 대개 가장 쓸모 있는 문장** 이고, 주소와 달리 감출 이유가 없습니다 — "the selected template does not exist" 는 누른 사람이 고칠 수 있는 문제입니다.

## 검증 결과

- 지점이 반복되는 스물네 줄이 지점 네 개의 막대가 되는지, 핵심 지표가 합계 기준인지 봅니다.
- 비율 열은 합치지 **않는지**, 이미 요약된 표는 그대로 두는지 봅니다.
- 묶은 추이 차트가 슬라이드가 적은 대로 묶은 값을 그리는지 봅니다.
- 조사를 표로 시험합니다 — 숫자 0~9, 한글 받침, 영문, `%`.
- 연결 실패 메시지에 주소가 들어가지 않는지, 그러면서 로그에는 남는지 확인합니다. 인증 거부는 서비스가 한 말을 되풀이하지 않고, 4xx는 되풀이합니다.
- 실제로 도는 Ptium을 상대로 거래 원본 범위를 만들어 지점별 합계 막대가 나오는 것과, 서비스를 끄거나 키를 틀리게 두었을 때 나오는 문장을 확인했습니다.
- `go vet ./...`, `go test ./...`, PostgreSQL 통합 테스트, React/Vitest, TypeScript 타입 검사, Vite 프로덕션 빌드, Playwright E2E를 통과했습니다.
