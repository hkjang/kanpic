## 릴리즈 요약

v0.76.0은 **오류 셀이 스스로 이유를 말하게 합니다.** 지금까지 수식이 실패하면 셀에 `#VALUE!` 같은 코드만 찍혔습니다. 무엇이 잘못됐는지도, 어떻게 고치는지도 화면 어디에도 없었습니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 오류 셀에 이유와 다음 조치

오류 셀에 **마우스를 올리면** 무엇이 잘못됐고 다음에 무엇을 확인해야 하는지가 뜹니다. 메모를 보여 주던 자리와 같은 방식이되, 색으로 구분합니다.

**셀을 선택하면** 수식 입력창 오른쪽 끝에 같은 내용이 한 줄로 표시되고, 마우스를 올리면 자세한 조치가 나옵니다. 마우스로만 볼 수 있게 두면 키보드로 다니는 사람에게는 없는 것과 같기 때문에 두 곳 모두에 둡니다.

열 개 코드 전부에 뜻과 확인할 것을 붙였습니다. 예를 들어 `#DIV/0!` 은 "0으로 나눴습니다 / 나누는 값이 비어 있거나 0인지 확인하세요. `=IFERROR(A1/B1, "")` 로 감싸면 빈 칸으로 둘 수 있습니다" 로 나옵니다.

## 오류 코드 목록이 두 곳에 있던 문제

엔진에는 오류 코드 목록이 **두 군데 따로** 있었습니다. 수식 안에 `#REF!` 같은 코드를 직접 쓸 때 읽는 목록과, 계산 결과가 오류인지 판정하는 목록입니다. 지금까지 어긋나지 않은 것은 운이었습니다.

하나로 합치고, 새 코드가 생기면 제품의 한국어 설명도 함께 늘어나도록 테스트로 묶었습니다. 코드는 늘었는데 설명이 없으면 사용자는 다시 아무것도 모르는 자리로 돌아갑니다.
