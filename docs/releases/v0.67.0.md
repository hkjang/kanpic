## 릴리즈 요약

v0.67.0은 **XLSX 내보내기가 시트 배치를 함께 담도록** 합니다. 지금까지 내보내기는 값·수식·서식·병합만 옮겼습니다. 숨긴 행, 열 너비, 틀 고정, 접은 그룹은 전부 사라져, 엑셀에서 연 파일이 kanpic에서 보던 시트와 다른 모양이었습니다.

마이그레이션은 없습니다. 필수 런타임 환경 변수는 계속 `POSTGRES_DSN` 하나입니다.

## 함께 담기는 것

| kanpic | XLSX |
| :--- | :--- |
| 숨긴 행·열 | 숨김 상태 그대로 |
| 행 높이·열 너비 | 픽셀을 엑셀 단위(포인트·문자 폭)로 환산 |
| 고정 창 | 틀 고정 |
| 행·열 그룹 | 아웃라인 수준(접은 그룹은 숨김까지) |

어제 인쇄에서는 숨긴 행을 **뺐지만**, 파일에는 **담되 숨김으로 표시**합니다. 인쇄물은 지금 보고 있는 화면이고, 파일은 데이터 원본입니다. 파일에서 행을 빼 버리면 받는 사람이 되살릴 방법이 없습니다.

## 검증 결과

- `go vet ./...`와 `go test ./...`를 통과했습니다. 새 테스트는 내보낸 파일을 다시 열어 숨김 상태, 열 너비(208px → 약 29문자), 행 높이(48px → 36포인트), 아웃라인 수준, 틀 고정을 확인합니다. 머리글 행이 그룹에 딸려 들어가지 않는지도 함께 봅니다.
- 테스트가 실제로 이 기능을 지키는지 확인하려고 배치 적용 호출을 빼 보았고, `hidden row exported as visible` 로 실패했습니다.
- 실제 서버에서 파일을 내려받아 압축을 풀고 `sheet1.xml` 을 직접 확인했습니다. 숨김 속성, `<pane>`, 열 너비 29가 모두 들어 있습니다.
- React/Vitest 234개 테스트, TypeScript 타입 검사, Vite 프로덕션 빌드, Playwright E2E 130건을 통과했습니다.
