## 한글은 두 바이트입니다

```
=LEN("한글")   ->  2
=LENB("한글")  ->  4
```

엑셀이 한글과 한자를 두 바이트로 셉니다. 자리를 바이트로 세는 `LEFTB`, `RIGHTB`, `MIDB`, `FINDB`, `SEARCHB`, `REPLACEB` 도 함께 더했습니다. 고정 폭으로 만든 예전 시스템의 자료를 다룰 때 필요한 것들입니다.

**두 바이트짜리 글자의 가운데가 잘리면 그 반쪽을 공백 하나로 바꿉니다.** 반쪽 글자를 낼 수는 없기 때문입니다.

```
=LEFTB("한글", 1)  ->  " "
=LEFTB("한글", 3)  ->  "한 "
=MIDB("한국어", 2, 2)  ->  "  "
```

붙여넣은 글에 전각 숫자가 섞여 숫자로 읽히지 않을 때는 `=ASC` 로 반각으로 바꿉니다. 반대는 `=JIS`(또는 `=DBCS`)입니다.

## 주말이 토·일이 아닌 곳도 있습니다

`=NETWORKDAYS.INTL`, `=WORKDAY.INTL` 은 주말을 숫자(`1`~`7`, `11`~`17`)로 고르거나 월요일부터 일곱 글자로 적습니다.

```
=NETWORKDAYS.INTL("2018-01-01","2018-01-31")            ->  23   토·일
=NETWORKDAYS.INTL("2018-01-01","2018-01-31", 11)        ->  27   일요일만
=NETWORKDAYS.INTL("2018-01-01","2018-01-31", "0000011") ->  23
```

일곱 자리가 모두 `1` 이면 일할 날이 없으므로 `#VALUE!` 입니다.

## 로마 숫자는 얼마나 짧게 적을지 고릅니다

```
=ROMAN(499)    ->  CDXCIX
=ROMAN(499,1)  ->  LDVLIV
=ROMAN(499,2)  ->  XDIX
=ROMAN(499,3)  ->  VDIV
=ROMAN(499,4)  ->  ID
```

규칙을 이 다섯 값 하나로만 알고 있었는데, 세워 본 규칙 — **빼는 글자를 얼마나 멀리서 가져오느냐** — 으로 다섯 가지가 모두 맞았습니다. `=ARABIC` 은 짧게 적은 꼴도 되읽습니다.
