왜 kanpic 인가?

기존 외산 SaaS와 오픈소스의 한계를 한 번에 해결하는 4대 엔터프라이즈 차별성

100% 완전 폐쇄망 (Air-Gapped)

사외 인터넷 연결이 완전히 차단된 에어갭 환경에서도 외부 통신 없이 독립 실행됩니다. 외부 데이터 유출 우려를 100% 근절합니다.

Redis-Free 인프라 TCO 절감

Redis, RabbitMQ 등 복잡한 서드파티 미들웨어 없이 PostgreSQL 1개만으로 동작하는 단일 바이너리 구조로 운영 TCO를 70% 절감합니다.

Canvas 2D 초고속 그리드

HTML DOM의 렌더링 한계를 극복한 Canvas 2D 그래픽 엔진으로 10만 행 이상의 셀 데이터도 60fps 무지연 스크롤과 편집을 지원합니다.

Model Context Protocol (MCP)

Anthropic MCP 표준 `/mcp` HTTP JSON-RPC 2.0 엔드포인트를 탑재하여 사내 LLM 에이전트가 데이터 읽기/쓰기 및 수식을 자율 제어합니다.

Keycloak OIDC PKCE SSO

사내 계정 관리 시스템(Keycloak)과 연동하여 2FA/SSO 중앙집중식 권한 관리 및 SHA-256 개인 API 키 관리 기능을 제공합니다.

Data Validation (유효성 검사)

목록 드롭다운 칩(Chip), 범위 및 Custom Formula 검증과 `Reject Input` 차단 옵션을 탑재하여 데이터 오입력을 사전 차단합니다.

엔터프라이즈 핵심 기능 시뮬레이션

탭을 클릭하여 kanpic의 주요 모듈 동작 방식을 확인해보세요.

Canvas 2D 그리드 & 실시간 수식 파서

Go 기반 백엔드가 브라우저와 동기화되어 고성능 수식 연산을 즉시 수행합니다.

  • 수학/통계/텍스트/논리 함수 지원 (`SUM`, `AVERAGE`, `IF`, `CONCAT`)
  • Goroutine Worker Pool을 통한 셀 수식 병렬 재계산
  • MS Excel 단축키 (`Ctrl+C/V`, `Shift+방향키`) 100% 호환
// 수식 계산 시뮬레이션 예시
A1: 1500 | B1: 2500
C1: =SUM(A1:B1) -> 4000
D1: =IF(C1>=3000, "목표 달성", "미달") -> "목표 달성"

데이터 유효성 검사 (Data Validation)

승인되지 않은 잘못된 값 입력을 셀 수준에서 차단하여 정합성을 보장합니다.

  • 드롭다운 칩 (Chip Style Validation)으로 클릭 한 번에 입력
  • `Reject Input = True` 설정으로 잘못된 값 입력 시 즉시 차단
  • 경고 뱃지 및 상세 오류 툴팁 표시
승인 대기 불량 (Reject)

규칙 위반 입력 시: "오류: 0 이상의 숫자만 입력 가능합니다."

비파괴 필터 뷰 & 타임스탬프 버전 복원

타 사용자에게 방해를 주지 않는 필터 탐색과 원클릭 상태 복원을 제공합니다.

  • 팀원의 화면 행 순서를 바꾸지 않는 개인별 비파괴 필터 뷰
  • 워크북 변경 델타 타임스탬프 이력 자동 기록
  • 실수로 삭제된 수식/데이터 원클릭 복원

🕒 2026-07-31 15:10 — 이수진 연구원 (MCP AI 수식 자동 생성)

Model Context Protocol (MCP) AI 연동

HTTP JSON-RPC 2.0 표준 엔드포인트를 통해 사내 AI 모델과 자율 연동됩니다.

  • `/mcp` 엔드포인트 지원 및 `mcp.use` 보안 스코프 적용
  • AI 에이전트의 자동 데이터 요약, 수식 생성, 이상치 검출
  • Python / Curl 스크립트 기반 파이프라인 자동화
